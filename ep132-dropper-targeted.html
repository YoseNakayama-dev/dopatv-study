#32 ・ 第2章 情報セキュリティにおける脅威

ドロッパと標的型攻撃 侵入から外への持ち出しまで

  1. ドロッパは内部に持つ別のマルウェアを書き出して実行する。自身は悪質な動作が少なく、検出されにくい。
  2. 標的型攻撃は特定の組織や人を狙い、長期間続きやすく、既知の対策を回避するよう作り込まれる。
  3. 対策は入口・内部・出口で重ねる。入口だけでは防ぎきれないので、検知後の対応手順も用意する。
用語 8クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題標的型攻撃への対策として、適切なのは？

    1. 多層で、侵入を前提に備える

    2. 送信元は偽装でき、乗っ取りもある

    3. すり抜ける攻撃が、内部で動く

    4. 長期間続き、ログが経路の手がかり

  2. 標的型攻撃への備えとして、外部への通信先を制限している。ドロッパについての評価として最も適切なものはどれか。

    1. 外部から取得するのはダウンローダ。ドロッパは内部に持つものを書き出す。

    2. 正解。外部取得がないので、通信先の制限だけでは足りない場合がある。

    3. ドロッパ自体は悪質な動作が少なく、検出されにくい。

    4. ダウンローダは外部から取得する点が違う。対策を考える上でも区別が要る。

  3. 訓練と添付ファイルの取扱い規則を整えたので、内部と出口の対策は省略したい、という提案があった。評価として最も適切なものはどれか。

    1. 入口だけでは防ぎきれない。訓練を受けても、すり抜ける攻撃は起こりうる。

    2. 送信元は偽装でき、乗っ取られた正規の送信元もある。送信元の確認だけでは見分けられない。

    3. 正解。入口をすり抜けたものは内部で動く。内部と出口で被害を小さくし、検知後の手順も用意する。

    4. 内部の対策（挙動監視・最小権限・分離）も重ねる層の1つ。出口だけでは足りない。

  4. 侵入された端末が、外部の指令サーバ（C&C）と通信して遠隔操作されることを抑えたい。最も適切な対策はどれか。

    1. 入口の対策。すでに侵入された後の遠隔操作を止める手段ではない。

    2. 入口の対策。侵入後の通信には効かない。

    3. 入口の対策。侵入後の通信を止める手段ではない。

    4. 正解。出口の対策として、指令サーバへの通信を止める。

  5. 添付ファイルの検査で、悪質な動作が見つからなかった。ドロッパの性質をふまえた、この結果の扱いとして最も適切なものはどれか。

    1. ドロッパ自体は悪質な動作が少なく検出されにくい。無検出を安全の証拠にはできない。

    2. 正解。ドロッパは悪質な動作が少なく、検出されにくい。

    3. 外部から取得するのはダウンローダ。ドロッパは内部に持つものを書き出す。

    4. 「必ず検出できる」という根拠はない。言い過ぎの断定である。

  6. パターンファイルの更新だけを徹底している組織の、標的型攻撃への備えの評価として最も適切なものはどれか。

    1. 既知の対策に検出されにくいよう作り込まれる。更新の徹底だけでは防げない。

    2. 長期間続きやすい。検知後の対応手順も用意する。

    3. 正解。既知の対策を回避するよう作られるので、入口・内部・出口で重ねて備える。

    4. 特定の組織や人を狙い、相手に合わせて仕立てる攻撃である。

頭の中で考える

  1. 標的型攻撃で「入口だけでは防ぎきれない」と言われる理由と、入口を抜けられた後の備えを、頭の中で説明してみよう。

    答えを開く

    標的型攻撃は相手に合わせて仕立てられ、既知の対策に検出されにくいよう作り込まれるため、入口をすり抜ける場合がある。内部では挙動監視（EDR）・最小権限・ネットワークの分離、出口では外部通信の監視と制限で被害を小さくし、検知後の対応手順も用意する。

    思い浮かんだ要素にチェック

  2. 検知した指令サーバ（C&C）への通信を遮断した。これだけで対応を終えてよいかを、侵入の流れをふまえて説明してみよう。

    答えを開く

    終えてよいとは言えない。通信の遮断は出口の対策で、すでに侵入した端末や、内部調査・横展開で他の端末へ広がった影響は残りうる。検知後の対応手順に沿って、影響範囲を調べて対処する。

    思い浮かんだ要素にチェック
