#60 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

ログ分析の効果と限界 残し方と守り方で価値が決まる

  1. 効果は、早期の検知、原因と影響範囲の特定、証跡、抑止と設定の見直し。記録があってこそ成り立つ。
  2. 限界は、出力設定のない操作は残らないこと、消去や改ざん、量による見落とし、暗号化通信の中身。
  3. 対策は、発生時の別保管先への転送、出力設定の確認、アラートでの絞り込み、訓練、取得対象の見直し。
用語 10クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題ログ分析の限界として、適切なのは？

    1. 出力設定のない操作は残らない

    2. 改ざんされると戻せるとは限らない

    3. 量が増えると見落としやすい

    4. アラートで早期の検知にも使う

  2. 暗号化された通信の内容を、通信の記録から調べることについて、適切な説明はどれか。

    1. 暗号化された通信は、通信の記録に中身までは残らないことが多い。

    2. 正解。暗号化された通信は、通信の記録に中身までは残らないことが多く、ログ分析の限界のひとつになる。

    3. 期間を延ばしても、記録されていない中身は残らない。

    4. 相関分析は複数のログを突き合わせて一連の動きをたどるもので、記録にない中身を復元するものではない。

  3. 毎日大量のログが出力され、担当者が目視で確認しているが、重要な兆候が埋もれている。改善として適切なものはどれか。

    1. 量が多いと人手では見切れず見落としが出る。項目を増やすと、確認する量はさらに増える。

    2. 転送と書き換えにくい領域は、消去や改ざんへの対策。量による見落としには、絞り込みが要る。

    3. 正解。量による見落としには、相関ルールやアラートで見る対象を絞り込む。

    4. 絞り込みがないと兆候が埋もれる。自動化で絞り込み、最終的な判断と対応は人が行う。

  4. 半年前にシステムを変更して新機能を追加したが、ログの取得設定は変更前のままだった。調査で新機能の操作が追えなかった。今後の運用として適切なものはどれか。

    1. 出力の設定をしていない操作は、期間を延ばしてもログに残らない。

    2. 出力設定を後から有効にしても、それ以前の操作は記録されていない。必要な操作が残る設定かは事前に確かめておく。

    3. 転送は消去や改ざんへの対策。出力設定のない操作は、転送してもログに残らない。

    4. 正解。取得する対象はシステムの変更に合わせて定期的に見直し、必要な操作が残る設定かを事前に確かめる。

  5. 漏えいの疑いが出たため、被害がどこまで及んだかを調べる。ログ分析で期待できることとして適切なものはどれか。

    1. ログは記録して検知・調査に使うもので、不正アクセスそのものを遮断する仕組みではない。効果は早期の検知による被害の拡大の抑制など。

    2. 正解。事故のあとは、記録をもとに原因と影響範囲を特定できる。記録が残っていることが前提。

    3. 記録が残ると知らせることで、不正を抑える効果もある。

    4. ログ分析は設定の見直しに使うもので、見直しの代わりにはならない。再発が起きなくなるとも言えない。

  6. ログ基盤を整備し、収集と保管は運用できている。ただ、実際の調査で必要な記録が足りるかは確認していない。追加の対策として適切なものはどれか。

    1. 容量を増やしても、必要な操作が記録される設定かは分からない。足りるかは訓練で確かめる。

    2. インシデントの最中に不足が分かっても、記録されなかった操作は取り戻せない。実際の調査を想定した訓練で事前に確かめる。

    3. 正解。実際の調査を想定した訓練で、ログが足りるかを確かめる。

    4. 量が多いと見落としが出るため、相関ルールやアラートは見る対象を絞り込むために使う。

頭の中で考える

  1. 侵入者にログを消去・改ざんされることへの対策を、限界の原因と結びつけて、頭の中で説明してみよう。

    答えを開く

    ログが侵入された機器だけに残っていると、侵入者に消されたり書き換えられたりしうる。発生時に別の保管先へ転送し、追記のみなど書き換えにくい領域も使う。

    思い浮かんだ要素にチェック

  2. ログを大量に取得しているのに、調査で必要な操作の記録が無かった。考えられる原因と、見直す点を頭の中で説明してみよう。

    答えを開く

    出力の設定をしていない操作は残らない。必要な操作が残る設定かを事前に確かめ、取得対象をシステムの変更に合わせて定期的に見直す。実際の調査を想定した訓練で、ログが足りるかも確かめる。

午後問題にチャレンジ

Webサーバ侵害の調査記録（ダミー）
侵害されたWebサーバのログは、ある時刻以降が空白だった
ログの保存先は、そのWebサーバ自身の内蔵ディスクのみ
FWのログには、同時刻の、そのサーバから外部への通信が残る
保管期間は1年。該当日は、その期間内にある
要件: 侵害されても、消去や改ざんの影響を受けず記録を残す

ログの保全として、適切なのは？

答えを開く

ログを発生時に、別のログ専用サーバへ転送して保存する

よくある誤答

  • ログの保管期間をさらに延ばして、長期間残すようにする … 期間は1年で、該当日はその期間内
  • 出力するログの項目を増やして、より詳細に残すようにする … 保存先は同じサーバのままで、要件を満たさない

本で読む

  • 5.10.2 ログ分析による効果及び限界

効果が記録の有無に左右されること、四つの限界とそれぞれの対策の対応づけ、転送・設定確認・絞り込み・訓練の役割の違いを確かめながら読む。
