#70 ・ 第6章 情報セキュリティ対策技術（2）アクセス制御と認証

SSOの概要 一度の認証で全部使う

  1. SSOは一度の認証で複数のシステムを使え、認証回数とパスワード数が減り、ID管理と認証強化を集約できる。
  2. 認証が破られると全システムに影響し、基盤が止まると全システムが使えない。離席や盗難、対象外のシステムにも注意。
  3. 対策は多要素認証、認証基盤の冗長化、有効時間の制限とログアウトの徹底、重要な操作での追加認証。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題SSOの導入時の注意として、適切なのは？

    1. 停止すると全システムが使えない

    2. 有効時間とログアウトの管理が必要

    3. 集中する分、認証を強化する

    4. ID管理も集約できる

  2. SSOを導入した社内で、認証基盤が停止すると全システムにログインできなくなる点が課題になった。対策として最も適切なものはどれか。

    1. 正解。認証基盤を二重化して、止まりにくくする。

    2. 多要素認証は認証を強くする対策で、基盤の停止は防げない。停止には冗長化で備える。

    3. 認証の有効時間は限り、ログアウトを徹底させるのが対策で、長くする運用は離席や盗難のリスクを増やす。

    4. SSOの対象外のシステムを増やしても、SSO対象のシステムは認証基盤が止まれば使えなくなる。対象外のシステムは従来の認証が残るだけで、別に守る必要がある。停止への対策は認証基盤の冗長化である。

  3. SSOの利用者が離席中に画面を放置したり、認証済みの端末を盗まれたりする事態に備えたい。対策として最も適切なものはどれか。

    1. 多要素認証は認証を強くする対策。離席や端末の盗難では認証済みの状態が使われうるため、有効時間の制限とログアウトの徹底が要る。

    2. 冗長化は認証基盤の停止への対策で、認証済みの状態が使われ続けるのは防げない。

    3. SSOでパスワードの数は減るが、離席や端末の盗難で認証済みの状態が使われうる点は残る。

    4. 正解。有効時間を限りログアウトを徹底させ、重要な操作では追加で認証を求める。

  4. SSOの導入時、旧式の業務システム1つをSSOの対象外にした。このシステムの扱いとして最も適切なものはどれか。

    1. SSOの対象外のシステムには従来の認証が残り、別に守る必要がある。

    2. 正解。対象外のシステムには従来の認証が残るので、別に守る。

    3. 対象外のシステムには従来の認証が残る。認証基盤の停止で全システムが使えなくなるのは、SSOの対象のシステムである。

    4. SSOの対象外のシステムは別に守る必要があり、SSOの多要素認証には含まれない。

  5. 五つの社内Webシステムが個別のパスワードで認証し、利用者が同じパスワードを使い回している。SSO導入で期待できる効果として最も適切なものはどれか。

    1. 正解。利用者の認証の回数とパスワードの数が減り、使い回しも減らせる。

    2. SSOでは認証が破られると全システムに影響する。個別に認証していたときのような分離は期待できない。

    3. SSOでも認証は必要で、集中する分、多要素認証などで認証を強化する。

    4. SSOでは、ID管理と認証の強化を一か所に集約できる。

  6. パスワードだけで認証するSSOを運用中、そのパスワードが漏えいした。影響と対策の組合せとして最も適切なものはどれか。

    1. SSOでは認証が破られると全システムに影響する。システムごとにパスワードを変えるのは、一度の認証で複数を使うSSOの前提と合わない。

    2. 冗長化は認証基盤の停止への対策。認証が破られる点には、多要素認証で備える。

    3. ログアウトの徹底は離席や盗難への対策。パスワードが漏れても破られにくくするのは多要素認証である。

    4. 正解。SSOの認証を多要素認証にして強くする。

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. SSOの利点と注意点が、どちらも「認証の集中」から生じる理由を、頭の中で説明してみよう。

    答えを開く

    認証を一か所に集約するので、利用者の認証回数とパスワード数が減り、ID管理と認証強化も集約できる。一方、その認証が破られると全システムに影響し、基盤が止まると全システムが使えなくなる。対策は、多要素認証で強くし、冗長化で止まりにくくすること。

  2. SSOで認証済みの端末が、離席中に他人に使われた。起きていることと対策を、頭の中で説明してみよう。

    答えを開く

    離席や端末の盗難では、認証済みの状態がそのまま使われうる。認証の有効時間を限り、ログアウトを徹底させ、重要な操作は追加で認証を求める。

社内システムの認証見直しに関する調査記録（ダミー）
現状: 五つの社内Webシステムが、個別のパスワードで認証する
利用者は覚えきれず、同じパスワードを使い回している
各システムは、外部の認証基盤の結果を受け入れる設定ができる
要件: 認証の回数を減らし、認証の強さは一か所で高めたい

要件を満たす方法として、適切なのは？

答えを開く

共通の認証基盤で認証を集約してSSOにし、その認証を多要素認証にする

よくある誤答

  • 全システムのパスワードを、同じ値にそろえる … 各システムで入力が要り、認証の回数が減らない
  • SSOにするが、認証はパスワードのみとする … 認証の強さを高める要件を満たさない
