#44 ・ 第4章 情報セキュリティマネジメントの実践

リスク対応手法の種類 低減・回避・移転・保有の選び方

  1. リスク対応は低減・回避・移転・保有の4種類。版により修正・共有と呼ぶこともある。
  2. 限界: 低減は残留リスクが残り、回避は成果も失う。移転しても信用や説明責任は残りうる。
  3. 影響・可能性・費用で選び、組み合わせて理由を記録する。基準超えの保有は所有者が例外承認。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題リスク回避の例として、適切なのは？

    1. 損失の負担を分ける（移転）

    2. 可能性を下げる（低減）

    3. 原因となる活動をやめる

    4. 対策しないと決める（保有）

  2. リスク対応の記録に「リスクが基準を超えたため、利用者の少ない旧機能の提供を終了した」とある。この対応の手法と、その代償の組合せとして最も適切なものはどれか。

    1. 正解。原因となる活動をやめるのが回避で、その活動で得られる成果も失う。

    2. 低減は可能性や影響を小さくする対応。活動そのものをやめる今回の対応とは違う。

    3. 移転は損失の負担を他者と分ける対応。機能を終了しただけでは負担を分けていない。

    4. 保有は追加の対策をしないと決めること。機能を終了しているので対策をしていないわけではない。

  3. 個人情報を扱う業務を委託し、契約で損害の分担を定めた。担当者は「責任は全て委託先に移ったので、自組織の対応は不要」と報告した。この報告への評価として最も適切なものはどれか。

    1. 全部は渡せない。信用や説明責任は自組織に残りうる。

    2. 正解。移転は契約の範囲で損失を分担するだけで、信用や説明責任は自組織に残りうる。

    3. 移転と回避は別の手法。回避は原因の活動をやめる対応で、委託してもリスクは無くならない。

    4. 委託先との契約は移転の例。契約の範囲で分担できるので「全て負う」は言い過ぎ。

  4. 社内向け備品管理表の閲覧設定に、影響が小さく、受容基準を超えない不備が見つかった。直すための対策費用は、リスクの大きさに見合わない。対応として最も適切なものはどれか。

    1. 低減でもゼロにはならず残留リスクは残る。費用が見合わないのに優先する根拠はない。

    2. 回避は成果も失う。影響が小さいのに利用をやめるのは釣り合わない。

    3. 移転は影響が大きく可能性が低い場合の選択肢。影響が小さい場合の目安ではない。

    4. 正解。影響が小さく費用が見合わないなら保有を検討する。選んだ理由を記録する。

  5. あるリスクは基準を超えているが、対策費用が予算を超えるため、追加の対策はしないことになった。扱いとして最も適切なものはどれか。

    1. 受容は許容できるという判断で、基準を超えるものには当てはまらない。基準超えの保有は例外承認が要る。

    2. 「必ず」は言い過ぎ。基準超えでも、理由を記録して例外として承認すれば保有できる。

    3. 正解。基準を超えるリスクを保有するときは、理由を記録し、リスク所有者が例外として承認する。

    4. 例外として承認するのはリスク所有者。担当者の判断だけでは足りない。

  6. 全ての脆弱性を修正し、バックアップも整えた。担当者は「これでリスクはゼロになった」と報告した。この評価として最も適切なものはどれか。

    1. 低減してもゼロにはならず、残留リスクが残る。

    2. 正解。低減には限界があり、残留リスクが残る。効果は対策の種類と運用の質しだい。

    3. 脆弱性の修正やバックアップは低減の例。回避は原因の活動をやめる対応。

    4. 移転でも全部は渡せない。契約の範囲で分担するだけで、信用や説明責任は残りうる。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 委託先と契約すればリスクの責任まで渡せる、と言えない理由を、頭の中で説明してみよう。

    答えを開く

    移転は損失の負担を契約の範囲で分担するだけで、全部は渡せない。損失が分担できても、信用や説明責任は自組織に残りうる。

  2. 基準を超えるリスクを、費用の都合で保有する場合に必要な手続きと、受容との違いを、頭の中で説明してみよう。

    答えを開く

    保有はリスクの大きさを理解した上で追加の対策をしないと決めること。基準を超えるなら、理由を記録し、リスク所有者が例外として承認する。受容は許容できるという判断で、保有とは別の概念。
