#42 ・ 第4章 情報セキュリティマネジメントの実践

詳細リスク分析・評価の手順 ベースラインとの使い分け

  1. 進め方はベースライン・詳細リスク分析・組合せ。費用と精度のバランスで選ぶ。
  2. 詳細は、資産・脅威・既存の管理策と脆弱性の特定、リスクの算定、受容基準と比べる評価の順。
  3. 定量はALE＝1回の損失額×年間の発生回数。手間がかかり見積もりは不確実なので、前提を明示する。

  1. 動画で出た問題ベースラインアプローチの特徴として、適切なのは？

    1. 標準的な基準に照らす

    2. それは詳細リスク分析の説明

    3. 基準に沿って、対策を選ぶ

    4. 固有のリスクは見落としうる

  2. 顧客DBについて、1回の損失額は2000万円、不正アクセスの発生は年0.5回と見積もった。受容基準は「年間予想損失額が800万円を超えたら対応する」である。適切な判断はどれか。

    1. 年間予想損失額は、1回の損失額に年間の発生回数を掛けて求める。割ってはいけない。

    2. 正解。2000万円 × 0.5回 = 1000万円で、基準の800万円を超えるので対応する。

    3. 頻度だけでは決めない。基準は年間予想損失額なので、金額を基準と比べる。

    4. 2000万円は1回の損失額。発生回数を掛けて算定した値を基準と比べる。

  3. 社内に多数のシステムがあり、すべてに詳細リスク分析を行う工数はない。顧客情報DBと決済システムは特に重要である。進め方として適切なのはどれか。

    1. ベースラインだけでは、組織固有のリスクを見落としうる。重要な資産には詳細な分析を加える。

    2. 適用が逆になっている。重要・高リスクの資産こそ詳細リスク分析を行う。

    3. 正解。組合せアプローチ。全体にベースライン、重要・高リスクの資産は詳細に行う。

    4. 費用と精度のバランスで選ぶ。全部を詳しく行うとは限らない。

  4. 詳細リスク分析の手順のうち、「リスク特定」にあたる作業の組合せとして適切なのはどれか。

    1. 算定と評価は、リスク特定のあとの段階。

    2. 算定と、受容基準との比較による評価は、リスク特定には含まれない。

    3. リスクの算定と評価は、特定のあとの段階。

    4. 正解。資産、脅威、既存の管理策と脆弱性の特定までがリスク特定。そのあとに算定、評価が続く。

  5. 金額の算出根拠が乏しい資産について、リスクを高・中・低の段階で表し、リスクマトリックスで比較した。この方法の説明として適切なのはどれか。

    1. 金額などの数値で見積もるのが定量的。段階で表す方法ではない。

    2. 正解。高・中・低の段階やリスクマトリックスは定性的な方法。見積もりの不確実さへの注意は同じ。

    3. ベースラインは、進め方（アプローチ）の名前。見積もりの表し方とは別の話。

    4. 受容基準は対応の要否を決める線引き。段階で表すのは、リスクの見積もりの表し方。

  6. 3年前に算定した年間予想損失額を、前提を確認せずに今年の評価にもそのまま使おうとしている。評価として適切なのはどれか。

    1. 見積もりの値は不確実なので、前提を明示して見直し続ける。

    2. 前提を省くと、値の確からしさを確かめられなくなる。前提は明示する。

    3. 正解。見積もりの値は不確実なので、前提を明示し、見直し続ける。

    4. 不確実さは前提の明示と見直しで扱う。感覚だけで決めるのは適切でない。

頭の中で考える

  1. 「重要な資産だけ詳細に分析し、ほかはベースライン」という進め方の利点と注意点を、頭の中で説明してみよう。

    答えを開く

    全体にベースラインを使うので手間が少なく、重要・高リスクの資産には詳細リスク分析を行うので、組織固有のリスクの見落としを減らせる。費用と精度のバランスで選ぶ。ベースラインだけの資産には、固有のリスクの見落としが残りうる。

    思い浮かんだ要素にチェック

  2. 年間予想損失額と受容基準を使って、対応の要否を決める流れを、頭の中で説明してみよう。

    答えを開く

    1回の損失額に年間の発生回数を掛けて年間予想損失額を算定する。受容基準（これ以下なら受容できる線引き）と比べ、超えたら対応する。値は不確実なので、前提を明示して見直す。

午後問題にチャレンジ

顧客DBのリスク評価記録（ダミー）
対象: 顧客DB（ダミー）。漏えい時の損失は、1回6000万円
脅威: 外部からの不正アクセス。発生は年0.1回（10年に1回）
脆弱性: 修正プログラムが未適用。対策はまだ追加していない
受容基準: 年間予想損失額が300万円を超えたら、対応する
年間予想損失額 = 1回の損失額 × 年間の発生回数

このリスクの評価として、適切なのは？

答えを開く

年間予想損失額は600万円で、受容基準を超えるため、対応する

よくある誤答

  • 10年に1回で低い … 基準は年間予想損失額
  • 年間予想損失額は6000万円 … 6000万は1回の損失額
