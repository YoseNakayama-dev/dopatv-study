#26 ・ 第2章 情報セキュリティにおける脅威

HTTPヘッダインジェクション 改行が区切りになる仕組みと対策

  1. 外部入力をヘッダの値に出力し、含まれる改行を除去・拒否しないと成立する。
  2. 影響はSet-Cookieの追加、レスポンス分割、キャッシュ経由の波及など。実際の影響は実装や中継機器による。
  3. 対策はヘッダ出力のAPI、改行を含む入力の拒否、リダイレクト先の限定。WAFは補助。

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題HTTPヘッダインジェクションで、悪用される文字は？

    1. 改行（CRLF）

    2. SQLインジェクションで問題になる記号

    3. XSSで問題になる記号

    4. ディレクトリトラバーサルの記号

  2. ログイン後の戻り先URLをパラメータで受け、文字列を連結してLocationヘッダを自前で組み立てている。根本に近い改修として最も適切なものはどれか。

    1. HTMLエスケープはブラウザ向けの処理で、ヘッダの区切りである改行の扱いは変わらない。

    2. 正解。言語・フレームワークのAPIを使い、改行を含む入力を拒否する。リダイレクト先の限定も合わせる。

    3. 符号化しても、ヘッダに出力する値に改行が含まれる問題は直らない。

    4. WAFは補助で、ヘッダの出力の不備そのものは直らない。

  3. Set-Cookieを追加される不具合が残るサイトで、ログイン時にセッションIDを再発行する対策を入れた。この対策の評価として最も適切なものはどれか。

    1. 再発行は補助で、脆弱性そのものは直らない。

    2. 改行の拒否は根本に近い対策で、再発行で代えられない。

    3. 正解。ログイン時にIDが変わらないと同じ画面に入られるため再発行は有効だが、補助にとどまる。

    4. 再発行だけでは、偽の本文を返させられるなど他の影響は残る。

  4. ヘッダの出力を、自前の文字列連結からフレームワークのAPIに置き換えた。改行を拒否する実装が多いとされるが、評価として最も適切なものはどれか。

    1. 「必ず」は言い過ぎ。実装により挙動が違うため確認する。

    2. 改行を拒否する実装も多い。置き換えは根本対策になる。

    3. WAFは補助で、API側の挙動の確認の代わりにならない。

    4. 正解。APIの利用は根本対策だが、改行を拒否するかは実装によるため確認する。

  5. Locationヘッダに入力の改行が入り、Set-Cookieが追加される不具合を確認した。影響の見積もりとして最も適切なものはどれか。

    1. 実際の影響は実装や中継機器の挙動による。「必ず」は言い過ぎ。

    2. 正解。実際の影響は実装や中継機器の挙動による。キャッシュを経由すると他の利用者にも及びうる。

    3. キャッシュを経由すれば、他の利用者にも影響が及びうる。

    4. レスポンス分割により、偽の本文を返させられることもある。

  6. リダイレクト先を、サーバ側で許可した範囲の値に限定した。この対策の位置付けとして最も適切なものはどれか。

    1. 「完全に」は言い過ぎ。ヘッダ出力のAPIと改行を含む入力の拒否も組み合わせる。

    2. 検知ではなく、出力する値そのものを限定する対策。

    3. 正解。リダイレクト先を許可した範囲の値だけにする。

    4. ID再発行は固定の悪用を抑える補助で、値の限定とは別の対策。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. ヘッダインジェクションが成立する2つの条件を挙げ、改行がなぜ問題になるのかを頭の中で説明してみよう。

    答えを開く

    ①外部入力をヘッダの値に出力している、②入力に含まれる改行を除去・拒否していない。改行はヘッダの区切りの意味を持つため、入力に含まれると以降が新しいヘッダとして解釈される。

    思い浮かんだ要素にチェック

  2. 戻り先をパラメータで受ける機能でSet-Cookieが追加された。何が起こりうるか、どう直すかを頭の中で説明してみよう。

    答えを開く

    セッションIDを固定され、ログイン時にIDが変わらなければ攻撃者も同じ画面に入れる。実際の影響は実装や中継機器による。ヘッダ出力のAPI、改行を含む入力の拒否、リダイレクト先の限定で直し、ID再発行とWAFは補助にする。

    思い浮かんだ要素にチェック
