#13 ・ 第2章 情報セキュリティにおける脅威

サイバーキルチェーンとATT&CK 攻撃を整理する共通の言葉

  1. キルチェーンは侵入を7段階（偵察から目的の実行）で捉え、防御側の対処を段階に対応づけて考える。
  2. 早い段階で止めるほど有利になりやすいが、断定はできない。拒否の例はパッチ、妨害の例はDEP。
  3. ATT&CKは観測に基づく戦術（なぜ）・技術（どうやって）の知識ベース。優劣でなく見る角度が違う。
用語 10クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題ATT&CKの「戦術」が表すものは？

    1. それは「技術」

    2. 戦術は、なぜ（目的）

    3. 戦術はツール名ではない

    4. 防御製品の一覧ではない

  2. 調査記録に「端末は外向きの通信で外部の制御サーバとつながっており、攻撃者が手動で操作できる状態だった」とある。キルチェーンの段階として最も適切なものはどれか。

    1. 誤り。配送は標的の環境へ届ける段階で、制御サーバとの通信ではない。

    2. 誤り。悪用は相手側でコードを動かす段階。制御サーバとつながるのはその後。

    3. 正解。C2 は、外向きの通信路で制御サーバとつながり、手動操作が可能になる段階。

    4. 誤り。目的の実行は、持ち出しや破壊などを行う段階。通信路の確立とは別。

  3. 未修正の脆弱性を突く悪用に対し、パッチ適用と DEP を比べた。論文の対処の分類の説明として最も適切なものはどれか。

    1. 正解。拒否は行為を成立させない対処（例: パッチ）。妨害は始まった行為を中断させる対処（例: DEP）。

    2. 誤り。パッチも DEP も検知ではない。検知は活動を見つける対処。

    3. 誤り。拒否と妨害が逆になっている。

    4. 誤り。対処は拒否・妨害などに区別され、各段階に対応づけて考える。

  4. 同じ技術でも、攻撃グループごとに実行の細部は異なる。ATT&CK で、その実行の細部を表す項目はどれか。

    1. 誤り。戦術は「なぜ」、つまり目的。

    2. 誤り。技術は「どうやって」を表す。実装の細部までは表さない。

    3. 誤り。サブテクニックは技術をより具体的に分けたもの。実際の実装はプロシージャ。

    4. 正解。プロシージャが、実際の実装を表す。

  5. 既知の攻撃者の手口を再現して、自組織の検知力を確かめる演習を計画している。ATT&CK の使い方として最も適切なものはどれか。

    1. 誤り。載っている技術だけで、手口を網羅できるとは言えない。

    2. 正解。観測に基づく技術を共通の言葉で選んで再現し、検知の有無を整理する。レッドチームや能力評価の用途にあたる。

    3. 誤り。両者は役割が違い、優劣はない。置き換えではなく、見る角度が違う。

    4. 誤り。ルールの本数では能力を測れない。どの技術を検知できるかを対応づけて評価する。

  6. メールの配送段階の対策だけを強化し、悪用以降の検知は行わない方針が示された。キルチェーンの考え方による評価として最も適切なものはどれか。

    1. 正解。早い段階で止めるほど有利になりやすいが、段階ごとに検知・拒否・妨害などを対応づけて考える。

    2. 誤り。「必ず成立しなくなる」と言える根拠はない。手前を抜けた場合に備えて、後段にも対処が要る。

    3. 誤り。偵察を観測しにくいことは、配送の対策が無意味になる理由にならない。

    4. 誤り。論文は、検知のほかに拒否・妨害なども対処として整理している。

頭の中で考える

  1. キルチェーンと ATT&CK の違いと、組み合わせて使う場面を、頭の中で説明してみよう。

    答えを開く

    キルチェーンは侵入の流れを7段階で捉える。ATT&CK は観測に基づく戦術（なぜ）と技術（どうやって）を共通の言葉で整理する知識ベース。どちらが上ではなく見る角度が違う。使い方の一例として、キルチェーンで流れを見て、各段階の手口を ATT&CK の技術に当てはめて整理することが考えられる。

    思い浮かんだ要素にチェック

  2. 防御側の対処を、キルチェーンの段階に対応づけて考える利点と、注意点を頭の中で説明してみよう。

    答えを開く

    段階ごとに効く対処が違うので、検知・拒否・妨害などを各段階に対応づけると、どこに穴があるかを整理できる。早い段階で止めるほど有利になりやすいが、必ず止まるとは言えないので、手前だけに頼らず後段にも検知を置く。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

検知できなかった侵入の調査記録（ダミー）
検知ルールは20本。内容は、既知のマルウェアのハッシュ値の一致のみ
侵入者は、正規の管理ツールを使って社内を移動していた
検知ルールは、一度も反応しなかった
// 調査に必要な期間のログは残っていた

検知の穴を整理するのに適切なのは？

答えを開く

観測された手法ごとに、検知の有無を対応づけて確認する

よくある誤答

  • ハッシュ値のルールを増やす … 正規ツールの利用は、一致しない
  • ログの保存期間を延ばす … 記録は残っていた。穴の整理ではない
