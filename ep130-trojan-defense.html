#30 ・ 第2章 情報セキュリティにおける脅威

トロイの木馬とマルウェア対策 見せかけと多層防御

  1. トロイの木馬は正規を装い、利用者に実行させる。自己増殖はしない。利用者の判断が侵入の入口になる。
  2. 成立には、利用者が信じて実行し、止める仕組みが働かず、実行後の動作が検知されないことが要る。
  3. 対策は入口・端末・影響低減の層で重ねる。パターンマッチングもふるまい検知も限界があり、単独では足りない。
用語 8クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題トロイの木馬の特徴として、適切なのは？

    1. 正規を装い、実行させる

    2. 自己増殖しないのが、特徴

    3. ウイルスの説明

    4. DoS攻撃の説明

  2. 経理端末で、請求書を装ったファイルを利用者が実行したが、アプリケーションの許可リストに無いため起動しなかった。トロイの木馬の成立条件のうち、この対策が崩したものはどれか。

    1. 利用者は実際に実行している。この条件は崩れていない。

    2. 正解。許可リストは実行を止める仕組みの例。これが働くと、条件が成り立たなくなる。

    3. 検知は実行後の話。実行自体が起動しなかった点とは別の条件である。

    4. トロイの木馬は自己増殖しない。そもそも成立条件に含まれない。

  3. パターンマッチング方式の対策ソフトで、既知のトロイの木馬を改変した検体が検出されなかった。評価として最も適切なものはどれか。

    1. 未知や改変された検体に弱いのは方式の性質。運用だけの問題にはできない。

    2. ふるまい検知にも誤検知やすり抜けがありうる。置き換えだけでは足りない。

    3. 正解。パターンマッチングは未知・改変に弱い。どれか1つでは足りないので層で重ねる。

    4. 不審な動きで見つけるのはふるまい検知。パターンマッチングは既知の特徴との照合。

  4. メールフィルタで添付ファイルの大半は止まるが、1通が利用者に届き、実行された。実行後の被害を絞るための対策として最も適切なものはどれか。

    1. 入口の対策は有効だが、すでに実行された後の被害を絞る手段ではない。

    2. 利用者の判断が入口になるのは事実だが、周知だけでは実行後の被害は絞れない。

    3. 未知・改変された検体に弱く、単独では足りない。実行後の被害も絞れない。

    4. 正解。実行されても被害を絞り、すり抜けに備える層になる。

  5. 端末Bで、偽装ファイルの実行によるトロイの木馬が見つかった。同じセグメントの他端末への拡大の有無について、適切な考え方はどれか。

    1. 正解。トロイの木馬自体は自己増殖しない。広がり方は別の仕組み次第なので、その有無を調べる。

    2. トロイの木馬は自己増殖しない。感染済みと決めつける根拠はない。

    3. 広がり方は別の仕組み次第。実行者の人数だけで拡大がないとは言えない。

    4. トロイの木馬は利用者に実行させる点が入口になる。許可リストや導入の許可制など、実行を止める対策も要り、ワーム向けの対策だけでは足りない。

  6. 配布元の不明なフリーソフトを、利用者が各自で導入し、感染が相次いだ。運用上の対策として最も適切なものはどれか。

    1. 対策ソフトは未知・改変に弱い。導入を利用者任せにすると、入口が開いたままになる。

    2. 利用者の判断が入口だからこそ、呼びかけだけに頼らない仕組みが要る。

    3. 正解。導入の許可制と許可リストで、実行を止める仕組みを働かせる。

    4. ふるまい検知にも誤検知やすり抜けがありうる。「ない」とみなすのは言い過ぎ。

頭の中で考える

  1. トロイの木馬が成立する3つの条件と、それぞれを崩す対策を、頭の中で組み立ててみよう。

    答えを開く

    ①利用者が正体を信じて実行するので、入口でメールやWebのフィルタをかけ、導入を許可制にする。②実行を止める仕組みが働かない状態を、許可リストと最小権限で防ぐ。③実行後の動作が検知されない状態を、ふるまい検知やログ監視で減らす。どれも単独では足りない。

    思い浮かんだ要素にチェック

  2. 請求書を装ったファイルを実行した端末が、外部1宛先と一定間隔で通信している。他端末への接続はない。何が起きたかと、被害を絞る備えを説明してみよう。

    答えを開く

    利用者が実行したトロイの木馬が外部と通信していると考えられる。他端末へ広がる動きはなく、ワームではない。最小権限やバックアップ、ネットワーク分離、ログ監視で、すり抜けた場合の影響を絞る。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

経理端末の調査記録（ダミー）
対象: 経理担当の端末（ダミー）。請求書を装ったファイルを、利用者が自分で開いて実行
実行の直後から、外部の宛先への通信が、一定間隔で継続
通信先は、外部の1宛先のみ / 社内の他端末への接続は、なし
少量のデータを、一定間隔で送る継続的な通信（ビーコンのような動き）
// 修正プログラムは適用済み / 端末のサービスは正常に稼働

この端末で起きたこととして、適切なのは？

答えを開く

利用者が実行したトロイの木馬による、外部との通信

よくある誤答

  • ワーム … 通信先は外部1宛先のみで、他端末への接続はない
  • DoS攻撃 … 少量のデータを送る通信で、大量の通信ではない
