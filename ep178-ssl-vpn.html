#78 ・ 第7章 情報セキュリティ対策技術（3）暗号

TLSによるVPN（SSL-VPN） ソフトの要否で選ぶ三つの型

  1. SSL-VPNはTLSで通信を暗号化し、HTTPSと同じ通り道なのでFWを通りやすい。方式はソフトの要否や使える範囲で選ぶ。
  2. 暗号化されても端末の安全は保証されない。弱い認証、感染端末、装置の脆弱性、広すぎる接続先が入口になる。
  3. 対策は多要素認証、接続前の端末確認、修正プログラムの速やかな適用、利用者ごとの接続先の限定。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題SSL-VPNの説明として、適切なのは？

    1. TLSで暗号化し、ブラウザや専用ソフトで接続

    2. 専用の暗号化装置は不要

    3. ESPはIPsecの方式

    4. TLSで通信を暗号化する

  2. 会社支給のPCに専用ソフトを導入できる。利用するアプリを特定せず、社内のLANにつながったように使わせたい。SSL-VPNの方式の特徴として、条件に合うものはどれか。

    1. ソフト不要でブラウザで使えるが、対象はWebが中心。アプリを特定せず使わせる条件には合わない。

    2. 正解。専用ソフトは必要だが、LANにつながったように使え、アプリを選ばない。

    3. 専用ソフトが中継するのは特定のアプリの通信。どのアプリでもという条件には合わない。

    4. SSL-VPNはTLSで通信を暗号化する。暗号化なしの方式ではない。

  3. SSL-VPN装置がインターネットに公開されており、認証はIDとパスワードだけである。評価と対策として、適切なものはどれか。

    1. TLSは通信を暗号化するが、IDとパスワードだけだと乗っ取られやすい。

    2. 認証の強化だけでは、感染した端末、装置の脆弱性、広すぎる接続先といった入口が残る。他の対策も必要。

    3. 正解。IDとパスワードだけだと乗っ取られやすい。多要素認証を使って乗っ取りを防ぐ。

    4. 接続先を絞るのは、つながった後の被害を広げないための対策。乗っ取りそのものを防ぐ対策ではない。

  4. SSL-VPNに多要素認証を導入した。ある社員のPCがマルウェアに感染しているが、正しく認証を通過してVPNに接続した。この状況の説明として、適切なものはどれか。

    1. 暗号化されても端末の安全は保証されない。感染したPCがつながると、社内へ入り込まれる。

    2. 多要素認証は乗っ取りを防ぐ対策で、端末の状態は別に確認する。更新とウイルス対策が済んだ端末だけを接続させる。

    3. 感染したPCから社内へ入り込まれうる。社内の全体に接続できると被害が広がるので、接続先は絞る。

    4. 正解。暗号化されても端末の安全は保証されない。接続前に更新やウイルス対策の状態を確認する。

  5. SSL-VPN装置に修正プログラムが公開された。装置は外から見える場所に置かれている。適用の判断として、適切なものはどれか。

    1. TLSは通信の暗号化。VPN装置の脆弱性を放置すると、突破される。

    2. 正解。VPN装置は外から見える場所に置かれ、脆弱性を放置するとそこから突破される。修正プログラムを速やかに適用する。

    3. 認証の強化と装置の脆弱性への対応は別の対策。脆弱性を放置すると突破される。

    4. 接続先の限定は、つながった後の被害範囲を抑える対策。装置の脆弱性への対応は修正プログラムの適用。

  6. SSL-VPNの設定で、全社員が社内の全体に接続できるようになっていた。一人の利用者のアカウントが乗っ取られた場合の被害を抑える設計として、適切なものはどれか。

    1. 社内の全体に接続できると被害が広がる。通信の暗号化は接続先の範囲とは別の話。

    2. 修正プログラムの適用は装置の突破を防ぐ対策。接続できる範囲は、利用者ごとに絞る対策で限定する。

    3. 正解。社内の全体に接続できると被害が広がるので、利用者ごとに使える先を絞る。

    4. 端末の確認は感染端末からの入り込みを抑える対策。社内の全体に接続できると被害が広がる点は残る。
