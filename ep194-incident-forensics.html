インシデント対応とフォレンジック 証拠保全とログ相関

  1. 初動は被害を抑えつつ証拠を失わない。隔離し、消えやすい揮発性の情報から先に採取する。
  2. ディスクは書込みを防いで複製し、ハッシュ値で照合。解析は複製で行い、原本と受け渡しを記録する。
  3. ログ相関は時刻同期が前提。上書き・消去・保存期間切れでは追えないので、別の場所へ転送して保管する。

クイズ

  1. 動画で出た問題ディスクの証拠保全として、適切なものは？

    1. 原本に接続すると内容が変わりうる

    2. 消すと証拠が失われる

    3. 書込みを防いで複製し、ハッシュ値を記録

    4. 一覧だけでは情報が失われる

  2. 起動中の端末Bに感染の疑いがあり、外部との不審な通信が続いている。上長から「被害が広がる前に電源を抜け」と指示が出たが、原因と侵入経路の調査もこれから必要になる。最初の対応として最も適切なものはどれか。

    1. 正解。隔離で通信による被害拡大を抑えつつ、電源断で失われるメモリ上の情報や通信状態を先に採る。停止はその後の判断になる。

    2. 電源を切るとメモリ上の情報や通信の状態が失われ、原因の調査が難しくなる。ディスクの複製だけでは補えない情報がある。

    3. 通信が続く間は被害が拡大しうる。観察の価値はあっても、隔離せずに続けるのは初動の目的（被害を抑える）に反する。

    4. 削除と再起動で証拠そのものが失われ、メモリ上の情報も消える。正常に見えても侵入経路の手がかりが残らない。

  3. ディスクを書込み防止の状態で複製し、原本と複製のハッシュ値の一致も確認できた。解析担当者から「原本のほうが確実なので、原本を直接調べたい」と要望があった。対応として最も適切なものはどれか。

    1. 原本に接続すると内容が変わるおそれがある。再計算で一致を確認する方法に頼らず、そもそも原本には触れない。

    2. ハッシュ値の一致は複製が同じ内容である確認であって、原本を捨てる根拠にならない。あとで説明が必要になった場合に原本が要る。

    3. 複製の扱いが分散すると、誰がいつ何をしたかの記録が追えなくなる。受け渡しの記録が前提になる。

    4. 正解。解析は複製で行い、原本は保管する。保管者と受け渡しの記録が、改ざんされていないという説明を支える。

  4. プロキシのログとFWのログを時刻順に並べたところ、端末Cが不審サイトへ接続した同じ通信の記録時刻が、2つの機器で約9時間ずれていた。プロキシのログはUTC、FWのログは日本時間で記録されていた。まず行うべきことはどれか。

    1. どちらが正確かの根拠がない。片方を外すと、複数機器をつなげて流れを追うという相関の目的が果たせない。

    2. 正解。相関の前提は時刻同期とタイムゾーンの統一。ずれたまま並べると順序を取り違えるので、まずそろえる。

    3. 書き換えの可能性はあっても、タイムゾーンの違いという説明が先にある。断定せず、前提を確認してから判断する。

    4. 保存期間の延長は大切だが、今回の食い違いの原因（時刻やタイムゾーンのずれ）の確認にならない。

  5. 侵入を受けたWebサーバの調査で、侵入が疑われる時間帯のログが、サーバ内に保存されていたものだけ消えていた。同じ事態に備えた対策として、最も適切なものはどれか。

    1. 正解。侵入者がログを消す場合に備え、別の場所へ転送して保管する。保存期間が短いと、あとで調べるときに追えない。

    2. 閲覧の制限は情報の漏えい対策の面が強い。侵入者に管理権限まで奪われた場合の消去や上書きに備えたことにならない。

    3. 詳しくしても同じ場所に保存していれば、まとめて消されうる。消えたときに別の場所に残る備えが要る。

    4. 保存期間を短くすると、調査に必要な期間のログが残らなくなる。対策としては逆方向になる。

  6. ディスクの複製を取り、原本と複製のハッシュ値が一致した。後日、社内の監査担当から「その複製が改ざんされていないことを説明できるか」と問われた。説明の組み立てとして最も適切なものはどれか。

    1. 一致が確認するのは取得時点での内容の同一性。その後の取り扱いの経緯は、保管者・受け渡しの記録で補う必要がある。

    2. 正解。ハッシュ値の照合で内容の同一性を確認し、証拠管理の連鎖の記録で、改ざんされていないという説明を支える。

    3. ハッシュ値は内容の同一性を確かめる手段で、攻撃者の特定には使えない。目的が違う。

    4. 原本を解析に使うのは避けるべき扱いで、前提が誤っている。解析は複製で行い、原本は保管する。

頭の中で考える

  1. 感染が疑われる起動中の端末について、「すぐ電源を切る」より先に何をするか。理由もあわせて、頭の中で組み立ててみよう。

    答えを開く

    まずネットワークから隔離して被害の拡大を抑える。電源を切るとメモリ上の情報や通信の状態が失われるため、消えやすい（揮発性の）情報から別の媒体へ採取する。操作は誰がいつ行ったかを記録する。そのうえで停止するかどうかを判断する。

    思い浮かんだ要素にチェック

  2. 複数の機器のログを突き合わせて侵入の経緯を追うとき、どんな前提が崩れると追えなくなるか。その備えもあわせて組み立ててみよう。

    答えを開く

    各機器の時刻同期とタイムゾーンの統一が前提で、ずれると出来事の順序を取り違える。ログが上書きや消去をされたり、保存期間が切れたりしても追えない。備えとして、ログを別の場所へ転送して保管し、保存期間を調査に足りる長さにする。

    思い浮かんだ要素にチェック

端末Aに、マルウェア感染の疑いがある。起動中である
端末Aは、外部への不審な通信を、今も続けている

要件: 被害の拡大を止めつつ、証拠を保全したい

この端末への初動として、適切なのは？

答えを開く

電源は切らずに隔離し、揮発性の情報から先に採取する

よくある誤答

  • すぐ電源を切り、ディスクを保全する … 電源を切るとメモリ上の情報が失われ、原因の調査が難しくなる
  • 通信を続けたまま、様子を観察する … 不審な通信が続くと、被害が拡大する
