#16 ・ 第2章 情報セキュリティにおける脅威

パスワードクラックの種類と対策 ソルトとストレッチングの役割

  1. オンラインはログイン画面で試し回数を制限できる。オフラインは漏れたハッシュ値を手元で試すので制限が効かない。
  2. 攻撃は総当たり・辞書・レインボーテーブル。守りはハッシュ保存にソルトとストレッチングを重ねる。
  3. ソルトは1件ずつの辞書や総当たりを防げない。アカウントロックは妨害にも使われるので、多要素認証と併用する。

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ストレッチングの目的は、次のうちどれ？

    1. ハッシュは一方向。復元できない

    2. 攻撃者の1回あたりの試行を遅くする

    3. ソルトの役割

    4. アカウントロックの役割

  2. 認証DBのハッシュ値が漏えいした。現状はソルトなしで、同じパスワードの利用者2人が同じハッシュ値になっている。ユーザーごとのランダムなソルトを加えたとき、抑えられるものはどれか。

    1. 正解。同じパスワードでも値が変わり、事前計算の表が使えなくなる。

    2. ソルトがあっても、1件ずつの辞書や総当たりは防げない。ストレッチングで重くする。

    3. ログイン画面への入力はオンライン攻撃で、ロックなどの制限が担当する。

    4. ハッシュは一方向なので、もともと復号はできない。ソルトの役割ではない。

  3. ログイン画面の失敗回数制限は設定済み。認証DBが漏えいし、ハッシュ値を攻撃者の手元で試される場合に、効果が見込める対策はどれか。

    1. ロックはオンライン向け。手元で試される攻撃には効かない。

    2. 鍵が漏れれば元に戻る。保存の基本はハッシュ。

    3. 正解。ソルトで事前計算を防ぎ、ストレッチングで1回の試行を重くする。

    4. 待ち時間もログイン画面の制限なので、手元の試行には効かない。

  4. パスワードを「英単語に数字を足した16文字」の形にしている利用者が多い。辞書攻撃に対する評価として最も適切なものはどれか。

    1. 「破られることはない」は言い過ぎ。ありふれた語は、長くても弱い。

    2. 変形も候補に入る。記号を1つ混ぜても、人が選びがちな形なら候補になりうる。

    3. 短い文字列は総当たりでも時間の問題になる。強くはならない。

    4. 正解。辞書攻撃は人が選びがちな語やその変形を優先して試す。長さだけでは守れない。

  5. パスワードを可逆な暗号化で保存し、復号用の鍵を同じサーバに置く設計が提案された。評価として最も適切なものはどれか。

    1. 復号できること自体がリスクになる。保存の基本はハッシュ。

    2. 暗号化には鍵が必要で、鍵が漏れれば元に戻る。

    3. 正解。ハッシュは一方向で元に戻せない。暗号化は鍵の漏えいで元に戻る。

    4. 暗号化は鍵の漏えいで破られる。ソルトやストレッチングの役割は別。

  6. 失敗が続いたアカウントを、解除されるまで無期限でロックする設定にした。起こりうる問題として最も適切なものはどれか。

    1. 正解。他人のアカウントを意図的にロックさせる妨害ができる。一時ロックや待ち時間、多要素認証と併用する。

    2. ロックは流出後のオフライン攻撃には効かない。遅くなるのはストレッチングの役割。

    3. ソルトは秘密ではなく、ロックの設定とは関係しない。

    4. ストレッチングは保存方式の話で、ロックの設定では変わらない。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. ハッシュ値が流出した後に効く対策は何か。ロックが効かない理由とあわせて、頭の中で説明してみよう。

    答えを開く

    流出後は攻撃者が手元で試すので、ログイン画面のロックや回数制限は効かない。ソルトで事前計算の表を使えなくし、ストレッチングで1回あたりの試行を重くする。

    思い浮かんだ要素にチェック

  2. ソルトを入れただけでは安心できない理由を、頭の中で説明してみよう。

    答えを開く

    ソルトは事前計算の表や同じ値の一括照合を防ぐが、1件ずつの辞書や総当たりは防げない。そのため、ストレッチングで1回の試行を重くし、利用者側も長くありふれていない文字列にする。

    思い浮かんだ要素にチェック
