#50 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

ファイアウォールの概要と基本的な構成 DMZで被害を止める

  1. FWは境界で、送信元・宛先、ポート、プロトコル等の規則に基づき通信を許可・拒否する。原則は拒否し、必要な通信だけ許可する。
  2. 規則は上から順に評価し、最初に一致したものを適用する製品が多い（製品による）。一致しなければ暗黙の拒否。
  3. DMZを置き、DMZから内部への許可も絞る。許可した通信の中身や内部からの攻撃はFWだけでは防げない。

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ファイアウォールの基本的な考え方として、適切なのは？

    1. 原則拒否で、必要な通信だけ許可

    2. 未知の通信を通してしまう

    3. 乗っ取りが内部に直結する

    4. 被害が内部に広がる

  2. FWの規則表は次のとおり。上から順に評価し、最初に一致した規則を適用する製品とする。1: 外部→DMZ、宛先ポートanyを許可。2: 外部→DMZ、443番以外を拒否。3: 外部→内部を拒否。外部からDMZのWebサーバの22番ポートへ接続要求が来た。結果はどれか。

    1. この前提では、最初に一致した規則が適用される。具体的かどうかで優先順位は決まらない。

    2. 正解。規則1に最初に一致するので許可され、規則2は評価されない。並び順で結果が変わる。

    3. 暗黙の拒否は、どの規則にも一致しなかったときの扱い。規則1に一致している。

    4. この前提では、一致した最初の規則で決まり、最後まで評価しない。

  3. 外側と内側の2台のFWでDMZを挟む構成を採る。2台を異なる種類にする狙いと代償として適切なものはどれか。

    1. 同じ種類だと同じ弱点を共有し、一方で突破された手口がもう一方にも通りうる。異なる種類にする狙いはその回避。

    2. 狙いは種類を変えて弱点を分けること。運用はむしろ増える。

    3. 2台の構成では運用が増える。規則の管理が増えないとは言えない。

    4. 正解。種類を変えると一方の弱点で突破されにくいが、運用は増える。

  4. FWの規則表を見直したところ、終了した過去の案件のために作った例外の許可規則が、利用実績の確認もされないまま残っていた。対応として最も適切なものはどれか。

    1. 上から評価して最初に一致した規則を適用する製品では、下に足した拒否規則は先の許可に負ける。不要な規則は残さない。

    2. 例外の許可規則は許可として働くので、対象の通信は通る。デフォルト拒否は、一致しなかった通信への扱い。

    3. 正解。不要な規則や例外は残さず、定期的に見直す。変更管理とログも整える。

    4. 不要な許可規則が残っていると、その通信が通る余地になる。不要な規則や例外は残さない。

  5. 新しい社内システムの接続試験で通信が通らず、FWのログでは暗黙の拒否に該当していた。対応として最も適切なものはどれか。

    1. 正解。原則拒否のうえで、必要な通信だけを許可するのが基本。

    2. any許可は最小限の許可の方針に反する。しかも一時的なものを残すと、不要な規則・例外を残すことになる。

    3. 原則はすべて拒否し、必要な通信だけ許可する。原則許可への切り替えは方針が逆。

    4. 暗黙の拒否は、どの規則にも一致しなかった通信の扱いで、異常動作ではない。

  6. 443番のみ許可したDMZのWebサーバで、アプリへの不正入力による被害が出た。別の日には社内端末から内部サーバへの不正アクセスも起きた。FWの規則に誤りは無い。評価として適切なものはどれか。

    1. ポートを減らしても、許可した通信の中身は規則で判断できない。内部からの攻撃も同様に防げない。

    2. 正解。許可した通信の中身の攻撃や内部からの攻撃は、FWだけでは防げない。

    3. DMZは被害を内部に広げにくくする設計で、不正入力による被害そのものは防がない。内部からの攻撃にも対応しない。

    4. 規則の見直しは必要だが、中身の攻撃や内部からの攻撃までは防げない。「完全に」は言い過ぎ。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 公開Webサーバが乗っ取られても内部に被害を広げないために、FWの構成と規則をどう設計するか、頭の中で説明してみよう。

    答えを開く

    公開サーバは外部と内部の中間のDMZに置く。外部からDMZへは公開に必要な通信のみ許可し、外部から内部は直接許可しない。DMZから内部への許可も、必要な宛先・通信のみに絞る。

    思い浮かんだ要素にチェック

  2. 規則を上から順に評価する製品で、規則の並びや例外の扱いについて運用上注意すべき点を、頭の中で説明してみよう。

    答えを開く

    最初に一致した規則を適用する製品では、並び順で結果が変わる。広い許可規則を上に置くと、下の拒否が効かない。どれにも一致しなければ暗黙の拒否。不要な規則や例外を残さず、定期的に見直し、変更管理とログを整える。

ネットワーク設定の調査記録（ダミー）
対象: 社内ネットワーク（ダミー）。外部・DMZ・内部の3つに分け、公開Webサーバは、DMZに設置
FWの規則: ①外部→DMZのWebサーバ: 443番ポートのみ許可
②外部→内部: 許可する規則は定めていない　③DMZ→内部: 任意の宛先・任意の通信を許可　④その他: 拒否
ある日、DMZのWebサーバが乗っ取られた
その後、内部のファイルサーバへ、不正な通信が行われ、情報が持ち出された

被害が内部に広がらないようにする対策は？

答えを開く

DMZから内部への許可を、必要な宛先・通信だけに絞る

よくある誤答

  • 外部から内部への許可をなくす … 外部→内部は、許可していない
  • 外部からDMZの許可を絞る … 外部→DMZは、すでに443番のみ
