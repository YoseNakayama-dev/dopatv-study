ポートスキャン 目的・種類・対策

  1. ポートスキャンは各ポートへ要求を送り、返答の違いで開閉やフィルタを判定する。
  2. 攻撃者の偵察にも管理者の棚卸しにも使う。種類は接続・SYN・UDP・変則的な送り方があり、結果は実装で変わる。
  3. 対策は閉じる・絞る・検知。開けたポートは見え、時間をかけた走査は検知を回避しうる。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ポートスキャンの説明として、適切なものは？

    1. 完了させず返答で判定

    2. UDPはICMPの到達不能

    3. 管理者の棚卸しにも使う

    4. 開けたポートは見える

  2. UDPのポート検査で、5001番は何も返らず、5002番はICMPのポート到達不能が返った。結果の読み方として最も適切なものはどれか。

    1. UDPは開いていても返答が少ない。返答がないことだけで閉じていると判断できない。

    2. 正解。閉じていればICMPで到達不能が返ることが多い。開いていても返答が少ないため、返答なしは判別しにくい。

    3. ICMPの到達不能は、閉じているポートに返ることが多い応答で、待ち受けの印ではない。

    4. 閉じたポートにはICMP到達不能が返ることが多いので、開閉を判断する手がかりになる。無関係とは言えない。

  3. IDSは1分間に多数のポートへの接続試行があると警報を出す設定である。ある週、警報は一度も出なかったが、後日、公開サーバへ数日かけて1日に数ポートずつ接続試行した記録が見つかった。評価として最も適切なものはどれか。

    1. 記録が残っているのに、警報がないことだけで走査がなかったとは言えない。しきい値を超えない走査は警報にならない。

    2. FWの許可範囲を絞るのは有効な対策の一つだが、警報が出なかった理由（しきい値を回避する走査）の説明にはならない。IDSの見直しを不要とも言い切れない。

    3. 正解。短時間の多数の接続試行を見つける仕組みは、ゆっくりの走査を見逃しうる。警報がないことは、走査がないことを意味しない。

    4. 間隔が長いほど検知しにくくなる。検知精度が高まるわけではない。

  4. 外部から公開サーバを検査したところ、業務で必要な443番のほかに、過去の検証で使った3つのポートが開いていた。最も根本的な対策はどれか。

    1. 検知は補助の層。開いたままのポートが残る限り、原因は解消しない。

    2. 業務に必要な443番は応答しなければ使えない。開けたポートは見える。すべての応答をやめる設定は現実的ではない。

    3. 検査の頻度を上げても、開いているポート自体は減らない。把握の速さを上げるだけである。

    4. 正解。不要なサービスを止めてポートを閉じ、FWで必要な通信だけを許可する。開けるポートを最小にするのが基本。

  5. セキュリティ担当者が、他部門が管理する社内の公開サーバのポートを棚卸しのために検査しようとしている。検査の前に最初に行うべきことはどれか。

    1. 正解。自組織の公開ポートの棚卸しは、許可を得て行う。対象と範囲もあらかじめ決める。

    2. 自社のサーバでも、検査は許可を得て行う。検知機能を止めて検査することは、許可を得る代わりにならない。

    3. スキャンの種類にかかわらず、許可を得て行う点は変わらない。TCP接続スキャンはむしろ相手のログに残りやすい。

    4. 許可は検査の前に得る。結果が出てからの事後報告では、許可を得て行う手順にならない。

  6. FINなど変則的なフラグを使ったスキャンで、検査対象のすべてのポートが閉じているという結果になった。この結果の扱いとして最も適切なものはどれか。

    1. 変則的な送り方の結果は、実装によって異なる。その結果だけですべて閉じていると結論するのは言い過ぎ。

    2. 正解。FINなどの結果は実装で変わる。SYNスキャンなど他の方法でも確認して判断する。

    3. SYN/ACKはSYNに対する応答で、FINへの返答とは別。FINなどの結果は実装によって異なり、返答なしだけで開いていると読み替えられない。

    4. UDPとTCPは別のプロトコルで、結果が必ず一致するとは言えない。種類ごとに判定の仕方が違う。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. ポートスキャンを防ぐ対策の限界を、頭の中で説明してみよう。それでも対策を行う意味は何か。

    答えを開く

    公開するために開けたポートは、スキャンで見える。時間をかけた走査は検知のしきい値を回避しうる。それでも、不要なポートを閉じ、FWで必要な通信だけを許可すれば、見える範囲を最小にできる。

    思い浮かんだ要素にチェック

  2. ポートスキャン対策で、ファイアウォールとIDSが担う役割の違いを、頭の中で説明してみよう。

    答えを開く

    ファイアウォールは、必要な通信だけを許可し、それ以外は既定で拒否して、見える範囲を絞る。IDSは、短時間の多数の接続試行を見つけて知らせる。前者は絞る役、後者は見張る役で、役割が違う。

午後問題にチャレンジ

外部からのポート検査結果（ダミー）
外部から、自社サーバへSYNを送って検査した
22番: SYN/ACKが返った
23番: RSTが返った
8080番: 何も返らなかった

22番・23番・8080番のうち、待ち受けていると判断できるのは？

答えを開く

22番 … SYN/ACKは、待ち受けている印

よくある誤答

  • 23番 … RSTは、待ち受けるサービスがないことを示す
  • 8080番 … 返答がなければ、待ち受けの有無は判断できない
