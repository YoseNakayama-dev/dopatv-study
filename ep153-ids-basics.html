#53 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

IDSの概要と種類 検知して知らせる見張り番

  1. IDSは通信やホストを監視し、不正の兆候を検知して通知・記録する。通信は止めない（遮断はIPSの役割）。
  2. 監視場所で分けるとネットワーク型とホスト型。暗号化通信は、ネットワーク型は復号しない限り中身が見えない。
  3. 検知方式で分けるとシグネチャ型とアノマリ型。前者は未知に弱く、後者は誤検知が増えやすい。併用も多い。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題IDSの基本的な役割として、適切なのは？

    1. 暗号化の中身は見えない

    2. 未知の攻撃には弱い

    3. 遮断はIPSの役割

    4. 検知して通知・記録する

  2. ネットワーク型IDSを、スイッチのミラーポートに接続して通信の写しを受け取る構成にした。この構成の特徴として適切なものはどれか。

    1. ミラーポートで写しを受け取る構成は、通信の経路に入らない。通信を止めず、障害点にもなりにくい。

    2. ネットワーク型は、暗号化された通信の中身を復号しない限り見えない。写しでも同じ。

    3. 正解。経路に入らないので通信を止めない。IDSの役割は検知・通知・記録で、遮断はIPSの役割。

    4. IDSは通信を止めない。遮断はIPSの役割。

  3. サーバ上のファイルの改ざんと不審なプロセスの起動を検知したい。このサーバとの通信は暗号化されている。適切な選択はどれか。

    1. 正解。ホスト型はサーバ上のログ・ファイル改ざん・プロセスを監視し、暗号化通信も復号後に見える。

    2. ネットワーク型は、暗号化された通信の中身を復号しない限り見えない。監視場所もサーバ上ではない。

    3. 検知方式は検知の仕方の分類で、監視場所とは別の軸。サーバ上のファイル・プロセスを監視するのはホスト型で、方式を変えるだけでは監視場所は変わらない。

    4. 検知方式の強化は、監視場所の違いを埋めない。ファイルやプロセスの監視はホスト型の役割。

  4. アノマリ型の検知を導入したところ、月末の業務で通信量が増えるたびにアラートが出て、調べると正常な通信だった。原因として最も適切なものはどれか。

    1. 既知のパターンと照合するのはシグネチャ型。アノマリ型は通常の状態を基準に外れを検知する。

    2. 正解。アノマリ型は通常の定義が難しく、誤検知が増えやすい。未知も検知しうる反面の弱点。

    3. アノマリ型は未知も検知しうる方式。誤検知の原因は、通常の定義の難しさ。

    4. IDSは通信を遮断しない。アラートは検知・通知の結果である。

  5. IDSが不正な通信のアラートを出していたのに、その通信は遮断されず攻撃が通った。IDSの欠陥だと報告された。評価として適切なものはどれか。

    1. IDSは通信を止めない。遮断はIPSの役割で、基本の役割ではない。

    2. ネットワーク型はミラーポートやTAPで写しを受け取り、経路には入らない。接続は誤りではない。

    3. アラートは出ており、検知と通知はできている。遮断はIDSの役割ではない。

    4. 正解。IDSの主な機能は検知・アラート通知・ログ記録。遮断はIPSの役割。

  6. 多数のサーバにホスト型IDSの導入を検討している。運用上の見込みとして適切なものはどれか。

    1. 1台で多くの端末を監視できるのはネットワーク型。ホスト型はホストごとに導入・管理が要る。

    2. 正解。ホスト型はホストごとに導入・管理が要るので、台数に応じて手間が増える。

    3. ミラーポートで写しを受けるのはネットワーク型の構成。ホスト型はサーバ上で監視する。

    4. 復号しないと見えないのはネットワーク型の課題。ホスト型は暗号化通信も復号後に見える。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. ネットワーク型とホスト型の違いを、監視する対象と暗号化通信の見え方に注目して、頭の中で説明してみよう。

    答えを開く

    ネットワーク型は通信を監視し、1台で多くの端末を見られるが、暗号化された通信の中身は復号しない限り見えない。ホスト型はサーバ上のログ・ファイル改ざん・プロセスを監視し、暗号化通信も復号後に見えるが、ホストごとに導入・管理が要る。

    思い浮かんだ要素にチェック

  2. シグネチャ型とアノマリ型の長所と短所を、頭の中で対比してみよう。併用する理由も添えて。

    答えを開く

    シグネチャ型は既知の攻撃パターンと照合するので、未知には弱い。アノマリ型は通常の状態を基準に外れを検知し、未知も検知しうるが、通常の定義が難しく誤検知が増えやすい。弱点が違うので、両方を組み合わせる製品も多い。

サーバの通信異常の調査記録（ダミー）
IDS: ネットワーク型。サーバ用セグメントの通信を、ミラーポートで受けている
検知: 提供元の最新の攻撃パターンとの照合のみ。パターンは最新を適用済み
ある日から3日間、サーバから外部へ、大量の通信が続いた
通信は暗号化されておらず、ミラーポートで全量を取得できていた
通信は正規のプロトコルの形式で、パターンと一致せず、アラート0件

検知の方式として、追加すべきなのは？

答えを開く

通常の通信量を基準に、外れた通信を検知する方式を併用する
