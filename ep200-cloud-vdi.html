クラウドとVDI クラウドコンピューティングの概要とシンクライアント

  1. クラウドは、自分で用意でき、共用の資源を増減でき、使った量を計測して課金される。
  2. 借りる範囲はIaaS・PaaS・SaaSで違い、利用形態は専用・公開・組み合わせで分ける。
  3. VDIはデータをサーバに集める。停止の集中や転送設定、入口の認証が限界で、撮影は防げない。

  1. 動画で出た問題クラウドとVDIの説明として、適切なものは？

    1. ハイブリッドは複数の形態の組み合わせ

    2. SaaSはOSの管理まで行わない

    3. 処理はサーバ側、画面が端末へ

    4. 資源の共用と使用量の計測

  2. 自社で選んだOSとバージョンの上に自社開発のソフトを載せて運用したい。仮想サーバや保管領域などの基盤は事業者から借りたい。借り方として最も適切なものはどれか。

    1. 正解。基盤を借りて、OSやアプリを利用者が載せる使い方に当たるのがIaaS。

    2. PaaSは開発や実行の土台を借りる形態。基盤の上にOSから自分で載せる使い方に当たるのはIaaS。

    3. SaaSは完成したアプリケーションを利用する形態で、利用者がOSを選んで自社のソフトを載せる使い方ではない。

    4. プライベートは利用形態の分類（誰が専用で使うか）で、借りる範囲を表す提供形態ではない。軸を取り違えている。

  3. VDIを導入し、業務データはサーバ上のみに置く運用にした。外部ネットワークからの接続は、利用者IDとパスワードだけで認証している。端末の紛失は想定済みである。最も優先して見直すべき点はどれか。

    1. データを端末に残さない設計で、紛失への備えは想定済み。端末の暗号化はこの前提では優先度が高い見直しではない。

    2. 正解。接続の認証が破られると業務環境ごと使われる。入口を多要素認証で守るのが、この構成の弱点に対応する。

    3. 台数の増加は性能や可用性の話で、IDとパスワードだけの認証という弱点には対応しない。

    4. 画面の撮影は完全には防げない。のぞき見防止は補助にとどまり、完全になくせるとは言えない。

  4. 全社員がVDIで業務を行う。回線は1本、VDIサーバは1台の構成で、障害のときに全員の業務が止まることを経営層が懸念している。この懸念に直接対応する施策はどれか。

    1. 暗号化は通信内容の保護で、停止への備えではない。

    2. 端末にデータを残さない設計のVDIの利点を損なう。端末への保存は転送設定を絞って避けるものである。

    3. 正解。通信とサーバが止まると全員が使えなくなる。冗長化して、一方が止まっても続けられるようにする。

    4. 多要素認証は認証の入口を守るもので、機器や回線の障害による停止には対応しない。

  5. 事業者が運営する自社専用の環境と、広く一般に提供されているサービスを組み合わせて利用している。利用形態の分類として適切なものはどれか。

    1. プライベートは一組織が専用で使う形態で、運営が自社か事業者かは問わない。運営者で分類を決めるのは誤り。

    2. プライベートクラウドの運営は自社でも事業者でもよい。自社運営が条件という前提が誤り。

    3. 共用と計測はクラウドの特徴で、SaaSの定義ではない。SaaSは提供形態で、利用形態の分類とは軸が違う。

    4. 正解。複数の形態を組み合わせて使う構成がハイブリッド。

  6. 開発部門が、事業者の担当者への依頼なしに管理画面から仮想サーバを追加し、使った量に応じた請求を受けている。この状況に当てはまるクラウドの特徴はどれか。

    1. 使った量に応じた請求という状況と合わない。クラウドは使った量を計測して課金する。

    2. 正解。利用者が自分で必要な資源を用意でき、使った量が計測されて課金される。

    3. 事業者への依頼なしで追加している状況と合わない。クラウドは利用者が自分で用意できる。

    4. クラウドの資源は共用される。共用されないという前提が誤り。

頭の中で考える

  1. VDIを導入すれば業務データは端末に残らず安心だ、と説明されたとする。そのまま受け入れてはいけない点を頭の中で挙げてみよう。

    答えを開く

    データを端末に残さない設計にはできるが、クリップボード・ファイル・ドライブの転送設定次第で端末に残る。画面の撮影は完全には防げない。また、接続の認証が破られると業務環境ごと使われる。

    思い浮かんだ要素にチェック

  2. VDIは管理とデータをサーバに集める。この集約で生じるリスクと対策を、頭の中で2点説明してみよう。

    答えを開く

    通信とサーバが止まると利用者全員が使えなくなるので、冗長化して備える。入口の認証が破られると環境ごと使われるので、多要素認証で守る。転送機能は必要なものだけ許可する。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

VDI導入後の設定記録（ダミー）
業務データの保存先: VDIサーバ上のみ（運用）
接続端末: 私物PC（利用は継続）。VDIの画面で利用
端末ドライブの割当: 有効
要件: 業務データを、私物PCに残さない

このあとの対応として、適切なのは？

答えを開く

VDIから端末のディスクへ、保存できない設定にする

よくある誤答

  • サーバのディスクを暗号化する … 暗号化しても、接続した端末への保存は止まらない
  • 端末のOSを最新にする … 更新しても、端末へ保存できる設定は変わらない
