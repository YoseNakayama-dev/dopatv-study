#122 ・ 第9章 情報セキュリティに関する法制度

サイバーセキュリティ関連の法律 不正アクセス禁止法ほか

  1. 不正アクセス禁止法は、他人の識別符号の無断利用や脆弱性を突く侵入を禁じる。ログインで成立する。
  2. 刑法には、ウイルスの罪や業務妨害、使用詐欺の罪がある。行為ごとに、適用される法律が違う。
  3. 基本法は責務と戦略を定める。対処能力強化法は官民連携と対処。プラットフォーム法は削除と開示の枠組み。

クイズ

  1. 動画で出た問題法律の説明として、適切なものは？

    1. 無断のID利用は不正アクセス

    2. 目的があれば作成や提供も処罰

    3. 責務と戦略を定める法律

    4. 事前の検閲ではない

  2. セキュリティ研究者が、他社のWebサイトの脆弱性を無断で突いて管理画面に入り、閲覧しただけで離脱した。データの持ち出しや改ざんはない。法律上の評価として適切なものはどれか。

    1. 不正アクセス禁止法では、データを盗んだかは問われない。脆弱性を突いたアクセス制御の回避自体が対象になる。

    2. 管理者に防御措置の努力義務があることは、侵入した側の行為が許される理由にならない。

    3. 正解。脆弱性を突いてアクセス制御を回避する侵入は、不正アクセス行為にあたる。

    4. 業務妨害罪は、データの破壊などで業務を妨害する行為が対象。今回は業務の妨害もデータの破壊もない。

  3. 取引先のログインページに似せた偽の画面を公開し、利用者をだましてIDとパスワードの入力を求めた。まだ誰のIDを使ってもログインしていない。この行為の評価として適切なものはどれか。

    1. ログインの有無にかかわらず、フィッシング目的で識別符号の入力を求める行為も禁止されている。

    2. 正解。フィッシング目的で識別符号の入力を求める行為も、不正アクセス禁止法で禁止される。

    3. 不正指令電磁的記録に関する罪は、実行させる目的の不正なプログラムが対象。入力を求める画面の公開とは対象が違う。

    4. 使用詐欺罪は、不正な情報を与えて財産上の利益を得る行為が対象。あわせて問題になりうるとしても、同法の適用を外す理由にはならない。

  4. 基幹インフラ事業者の導入設備の届出やインシデント報告など、官民連携の強化を定めた法律はどれか。

    1. 基本法は基本理念、責務、戦略、推進体制を定める法律。届出や報告の求めは、対処能力強化法の官民連携の内容。

    2. 不正アクセス禁止法は、不正アクセス行為などを禁止する法律。管理者の努力義務はあるが、設備の届出やインシデント報告の枠組みではない。

    3. 情報流通プラットフォーム対処法は、大規模プラットフォーム事業者に削除申出窓口の整備などを求める法律。基幹インフラ事業者の届出とは別。

    4. 正解。サイバー対処能力強化法は、基幹インフラ事業者の導入設備の届出やインシデント報告など、官民連携を強める。

  5. 経理担当の従業員が、自分に与えられたIDと権限を使って経理システムに虚偽の入金データを入力し、自分の口座の残高を不正に増やした。適用が考えられる法律として適切なものはどれか。

    1. 正解。電子計算機使用詐欺罪は、不正な情報を与えて財産上の利益を得る行為が対象。

    2. 不正アクセス禁止法は、他人の識別符号の無断利用や、脆弱性を突く侵入が対象。自分に与えられたIDの利用は、これに当たらない。

    3. 業務妨害罪は、データの破壊などで業務を妨害する行為が対象。今回の目的は、財産上の利益を得ることにある。

    4. この罪の対象は、実行させる目的の不正なプログラム（いわゆるウイルス）。入力した虚偽のデータは、プログラムではない。

  6. 自社を中傷する投稿が、大規模なSNSに残っている。投稿者に責任を問うため、まず投稿者を特定したい。情報流通プラットフォーム対処法の枠組みで使える手段はどれか。

    1. 国が事前に検閲する法律ではない。削除の申出は、事業者が整備する窓口で受け付ける。

    2. 正解。権利を侵害された人は、発信者情報の開示を請求できる枠組みがある。

    3. 基本法は責務と戦略を定める法律で、個人を罰するための法律ではない。

    4. 窓口の整備は削除の申出を受けるためのもの。開示は、請求する枠組みで扱われる。自動的に開示されるわけではない。

頭の中で考える

  1. 不正アクセス禁止法では、データを盗まなくても成立するのはなぜか。頭の中で説明してみよう。

    答えを開く

    この法律は、他人の識別符号の無断利用や、脆弱性を突いたアクセス制御の回避という、アクセスの行為そのものを禁じているため。ログインした時点で成立し、データを盗んだかは問われない。

    思い浮かんだ要素にチェック

  2. サイバーセキュリティ基本法とサイバー対処能力強化法の性格の違いを、頭の中で説明してみよう。

    答えを開く

    基本法は、基本理念、国・自治体・重要インフラ事業者などの責務、戦略、推進体制を定める法律で、個人を罰するものではない。対処能力強化法は、基幹インフラ事業者の届出・報告など官民連携を強め、国が被害防止の措置を取る枠組み。

午後問題にチャレンジ

不正ログインの調査記録（ダミー）
退職者が、元同僚に無断で、そのIDとパスワードを使いログイン
元同僚は知らず、承諾もしていない。閲覧のみで改ざんなし
社内システムは正常に稼働し、業務は止まっていない
ウイルスなどの不正なプログラムは、使われていない
問い: この行為に適用される、主な法律

適用される主な法律は、どれ？

答えを開く

不正アクセス禁止法（他人のIDを使うログインが該当）

よくある誤答

  • 電子計算機損壊等業務妨害罪 … 業務は止まっておらず、データも壊されていない
  • 不正指令電磁的記録に関する罪 … 不正なプログラムは、使われていない
