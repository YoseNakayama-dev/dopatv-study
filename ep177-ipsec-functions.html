#77 ・ 第7章 情報セキュリティ対策技術（3）暗号

IPsecの機能と構成プロトコル 守る役と鍵を配る役

  1. ESPは暗号化と認証、AHは認証のみ。AHは暗号化しないので、盗聴を防ぐならESPを選ぶ。
  2. IKEが相手の認証、鍵の交換、SAの確立を自動で行う。事前共有鍵が弱いとIKEの認証が破られるおそれがある。
  3. 両端のSA設定をそろえ、FWでIKEとESPを許可し、NAT越えも確認する。どれかが欠けると接続できないおそれがある。
用語 9クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題IKEの説明として、適切なのは？

    1. 暗号化を行うのはESP

    2. 認証し、鍵交換とSAの確立を行う

    3. 認証だけを行うのはAH

    4. どちらでも鍵の管理は必要

  2. 拠点間の通信をAHだけで保護するIPsecを導入した。パケットを経路上で観測される状況での評価として、適切なものはどれか。

    1. 正解。AHは認証のみで暗号化はしない。改ざんは検知できるが盗聴は防げないので、盗聴対策にはESPを選ぶ。

    2. 鍵交換とSAの確立を自動で行うのはIKEの働き。AHが行うのは認証（完全性）のみで、暗号化も鍵交換もしない。

    3. 暗号化と認証を行うのはESP。AHは暗号化しないので、盗聴を防ぐ要件には使えない。

    4. AHは認証のみで暗号化はしない。盗聴は防げない。

  3. 拠点間IPsecがつながらない。調べると、両端のSAの設定のうち暗号方式が食い違っていた。対処として適切なものはどれか。

    1. AHでもESPでも、両端でSAの設定が合わないとつながらない。

    2. 鍵の長さと、両端のSAの設定の一致は別の話。SAの設定が合わないとつながらない。

    3. 正解。両端でSAの設定が合わないとつながらない。方式も鍵の長さも同じにする。

    4. FWでIKEを許可するのは通り道の対策。SAの設定が合わない問題は、設定をそろえて解消する。

  4. 拠点のFWで、ESPの通信は許可しているが、IKEの通信は止めている。このとき起こることとして、適切なものはどれか。

    1. 鍵の交換とSAの確立を行うのはIKE。FWがIKEを止めると、SAを確立できない。

    2. IKEは暗号化を行わないが、鍵の交換とSAの確立を担う。FWが止めるとSAを確立できない。

    3. FWがIKEを止めてもSAを確立できず、ESPを止めても通信が通らない。どちらを止めても問題になる。

    4. 正解。FWがIKEを止めるとSAを確立できない。FWでIKEとESPの両方を許可する。

  5. ESPで暗号化したIPsecで、IKEの認証に推測されやすい短い事前共有鍵を使っている。評価と対策として適切なものはどれか。

    1. 正解。事前共有鍵が弱いとIKEの認証が破られるおそれがあり、認証の強さが全体の強さを左右する。長い鍵か証明書を使う。

    2. ESPで暗号化しても、IKEの認証が破られるおそれは残る。認証の強さが全体の強さを左右する。

    3. AHに替えても、相手の認証や鍵の交換、SAの確立を担うIKEは必要。事前共有鍵が弱いと認証が破られるおそれは残る。

    4. SAの設定の一致は、つながるための条件。事前共有鍵が弱いと破られるおそれは別に残る。

  6. IPsecのSAの説明として、適切なものはどれか。

    1. 暗号化を行うのはESP。SAは暗号方式や鍵などの取り決めのことで、鍵も含む。

    2. 認証のみで暗号化しないのはAH。SAは取り決めのことで、プロトコル名ではない。

    3. 正解。SAは暗号方式や鍵などの取り決めで、一方向ごとに確立される。

    4. SAの確立はIKEが自動で行う。IKEのおかげで鍵を自動で作り、更新できる。

頭の中で考える

  1. 盗聴も改ざんも防ぎたいとき、ESPとAHのどちらを選ぶか。理由を頭の中で説明してみよう。

    答えを開く

    ESPを選ぶ。ESPは暗号化と認証を行うので盗聴も改ざんも防げる。AHは認証のみで暗号化しないため、改ざんは検知できても盗聴は防げない。

    思い浮かんだ要素にチェック

  2. IPsecがつながらない原因として確認すべき点を、IKE・SA・FWの観点で頭の中で挙げてみよう。

    答えを開く

    両端のSA設定（暗号方式・鍵長）が一致しているか。FWでIKEとESPが許可されているか（IKEを止めるとSAを確立できず、ESPを止めると通信が通らない）。NATがある場合はNAT越えが可能かも確認する。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

IPsec拠点間通信の構成に関する調査記録（ダミー）
現状: 拠点間の通信に、IPsecのトンネルを使う
通信内容の盗聴と、データの改ざんを、防ぎたい
通信相手が正規であることも、確認したい
要件: 鍵は手作業でなく自動で交換し、定期的に更新したい

要件を満たす構成として、適切なのは？

答えを開く

ESPで暗号化と認証を行い、IKEで鍵を自動で交換する

よくある誤答

  • AHを使い、鍵はIKEで自動交換する … AHは暗号化しないので、盗聴を防げない
  • ESPを使い、鍵は管理者が手作業で設定する … 鍵を自動で交換する要件に反する
