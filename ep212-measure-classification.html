#112 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

情報セキュリティ対策の分類 機能と実施方法の二つの軸

  1. 機能は抑止・予防・検知・回復、実施方法は組織的・人的・物理的・技術的。二つの軸を組み合わせて抜けを点検する。
  2. 予防だけに偏ると、起きたとき気付けず戻せない。検知は気付くだけで被害を止めないので、対応につなげる。
  3. 一つの対策が複数の機能を持つことがある。分類は整理の道具で十分さは示さないので、リスクに応じて組み合わせる。

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題対策の分類の説明として、適切なものは？

    1. 元に戻すのは回復

    2. 気付いて対応につなげる

    3. 他の面の対策も組み合わせる

    4. 抑止にもなる

  2. ある事業者の対策は、アクセス制御の設定、パッチ適用、サーバ室の入室制限の三つだけである。機能と実施方法の二つの軸で点検したときの指摘として、最も適切なものはどれか。

    1. 分類は整理の道具で、対策が十分かどうかは示さない。予防が複数あっても、機能の面では抜けが残る。

    2. 教育は人的対策で、実施方法の軸の補強になる。機能の軸の抜け（検知と回復）は、別に点検して補う必要がある。

    3. 正解。三つとも起こさせないための予防で、機能の軸では偏っている。検知（ログの監視など）と回復（バックアップなど）を足す。

    4. 予防は破られることがある。破られたときに気付き、戻すために検知と回復が要る。予防の強化だけでは代わりにならない。

  3. 不正持出しを防ぐため、「持出しは監視している」と全従業員に周知し、各部屋に掲示した。この対策の機能と効果についての評価として、最も適切なものはどれか。

    1. 正解。周知は心理に働きかける抑止で、実行そのものは止めない。起こさせない予防や、気付く検知と組み合わせる。

    2. 抑止は実行そのものを止めない。ためらわせるだけで、起こさせない予防と同等とは言えず、ほかの対策も要る。

    3. 周知はためらわせるもので、起きたことに気付くものではない。気付くには、ログの監視などの検知の対策が別に要る。

    4. 抑止も機能による分類の一つで、警告の表示や監視の周知が例。機能の軸と実施方法の軸の両方で整理する。

  4. ログ監視の仕組みから不正なログイン試行の通知が毎日届いているが、確認する担当者が決まっておらず、誰も対応していない。この状況への判断として最も適切なものはどれか。

    1. 検知は気付くだけで、被害は止まらない。通知を確認して対応につなげて初めて、被害を抑えられる。

    2. 通知が多いことを理由に監視をやめると、起きたことに気付けなくなる。予防だけに偏ると、気付けず戻せない。

    3. バックアップは元に戻す回復の対策で、起きたことに気付く検知の代わりにはならない。

    4. 正解。検知は気付くだけで被害を止めない。確認と対応の体制は組織的対策で、決めておくことで対応につながる。

  5. 情報セキュリティ規程は整備済みだが、従業員は内容をよく知らず、禁止された私物USBメモリの持込みが続いている。規程の見直し案が出る一方、現場からは「内容が伝わっていない」との声がある。最も適切な対応はどれか。

    1. 正解。規程があっても、守る人の理解がなければ働かない。教育や訓練で理解させつつ、規程は組織的対策の土台として維持する。

    2. 規程があっても、守る人の理解がなければ働かない。内容を厳しくするだけでは、伝わっていない問題が残る。

    3. 技術的対策は有効だが、技術だけで守りきれるわけではない。規程や教育など、ほかの面と組み合わせる。

    4. 入退室管理は物理的対策で、人の出入りに関するもの。規程を理解して守る人を育てる人的対策の代わりにはならない。

  6. サーバの障害で業務データが破損した。バックアップは毎日取得しているが、復旧の手順書は無く、担当者の記憶に頼っている。機能の軸で見たとき、最も適切な見直しはどれか。

    1. 回復の例はバックアップと復旧の手順。バックアップだけでは元に戻す備えとして足りず、手順も整える。

    2. 予防は破られることがある。その備えが回復なので、予防の強化は復旧の手順の代わりにならない。

    3. 正解。回復はバックアップや復旧の手順で、元に戻す機能。予防が破られたときの備えとして、手順も定めておく。

    4. 検知は起きたことに気付く機能で、元に戻す手順は回復に当たる。早く気付いても、戻す手順の代わりにはならない。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 予防の対策だけに偏った構成が問題になる理由と、補うべき対策を頭の中で説明してみよう。

    答えを開く

    予防は破られることがある。予防だけでは、起きたときに気付けず、戻せない。そこで、起きたことに気付く検知（ログの監視など）と、元に戻す回復（バックアップや復旧の手順など）を足す。検知は気付くだけで被害を止めないので、対応につなげる。

  2. 監視カメラを例に、一つの対策が複数の機能を持つ場合と、分類という方法の限界を頭の中で説明してみよう。

    答えを開く

    監視カメラは、映っていることがためらわせる抑止と、起きたことに気付く検知を兼ねる。分類は整理の道具で、対策が十分かどうかは示さない。リスクに応じて、二つの軸を組み合わせて対策を選ぶ。

動画の午後問題です。ログを読んで、答えを頭の中で決めてから開いてください。

サーバ室の管理記録（ダミー）
先月、サーバ室から、機器が無断で持ち出された
入口は扉だけで、誰でも出入りできる状態
出入りの記録は、取っていない
要件: 無断の持出しを、未然に防ぎたい

適切な対策は、どれ？

答えを開く

入室できる人を限定し、入口を施錠する

よくある誤答

  • 出入りの記録を取り、毎月確認する … 記録を取っても、誰でも入れる状態は変わらず、持出しは止められない
  • 機器の再調達の予算を確保する … 持ち出された後の備えで、未然には防げない
