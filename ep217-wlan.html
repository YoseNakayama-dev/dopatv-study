#117 ・ 第7章 情報セキュリティ対策技術（3）暗号

無線LANのセキュリティ 脅威・暗号化方式・強化策

  1. 無線LANは電波が届けば建物の外からも傍受されうる。電波は囲えないので暗号化と認証が要る。
  2. WEPは使わない。主流はAES（CCMP）のWPA2、WPA3はSAEでパスワード推測への耐性を高めた。
  3. SSID非表示とMAC制限は補助にとどまる。共有鍵は退職時に変更し、電波調査で不正APを検知する。

  1. 動画で出た問題無線LANの説明として、適切なものは？

    1. WEPは使うべきでない

    2. SSIDを隠しても暗号化されない

    3. MACアドレスは偽装できる

    4. PSKは全員共通の鍵

  2. 全社員が同じPSKを使うWPA2-Personalで運用している。先月退職者が出たが、PSKは変更していない。最も適切な対応はどれか。

    1. SSIDの非表示は名前を隠すだけで、接続時の通信にSSIDは含まれる。鍵を知る退職者への対策にならない。

    2. 正解。PSKは全員共通なので、退職時などに変更が要る。利用者ごとに個別に認証したいなら802.1Xがある。

    3. MACアドレスは偽装できる。制限は補助にとどまり、鍵の変更の代わりにならない。

    4. 電波は建物の外にも届き、囲えない。建物に入れなくても傍受や接続を試みられるため、変更は要る。

  3. 社内の無線LANは802.1Xで保護している。ある日、会議室付近で社内と同じSSIDを名乗る未知のAPの電波が観測された。最も適切な対応はどれか。

    1. SSIDの非表示は隠すだけの補助策で、不正APの設置そのものを防げない。

    2. 正解。正規を装うAPや無断設置のAPには、電波を定期的に調べて検知する対策がある。

    3. 認証を行っていても、正規を装うAPや無断設置のAPへの注意は別に必要である。

    4. 社内APの暗号化を強くしても、他の場所に置かれたAPを使えなくするものではない。

  4. WPA2のPSKに、短く推測しやすい語を使っている。通信を記録した第三者が、後からパスワード候補を試して鍵を割り出す恐れがある。対策として最も適切なものはどれか。

    1. SSIDの名前はパスワードの推測とは別の話。名前を変えても推測しやすい語は強くならない。

    2. TKIPはWEPの後継としての暫定対応で、主流はAESを使うWPA2。古い方式に戻しても推測への耐性は得られない。

    3. 正解。WPA3のSAEは、パスワード推測（オフライン辞書攻撃）への耐性を高めた。共有鍵自体も長く推測されにくくする。

    4. MACアドレスの制限は端末を絞る補助策で、記録した通信からのパスワード推測を防ぐものではない。

  5. 倉庫の古いハンディ端末が、WEPにしか対応していない。他の機器はWPA2で運用している。対応として最も適切なものはどれか。

    1. SSIDの非表示とMACの制限は補助にとどまり、暗号化の代わりにならない。WEPの弱さは補えない。

    2. WEPは脆弱性が知られており、使ってはならない。鍵を工夫しても同等とは言えない。

    3. WPAはTKIPによる暫定的な対応で、主流はAESを使うWPA2。同じ強度とは言えない。

    4. 正解。WEPは使ってはならない。暗号化はWPA3か、AESを使うWPA2にして、機器の更新も進める。

  6. 新設した拠点のAPは、暗号化はWPA3、共有鍵は長い文字列にしてある。一方、SSIDと管理画面のパスワードは出荷時のままだった。点検での指摘として最も適切なものはどれか。

    1. 正解。初期設定のSSIDや管理者パスワードは変更する。機器の更新と管理画面の保護も、強化策に含まれる。

    2. 通信の暗号化と、管理画面の守りは別。管理者パスワードが初期設定のままでは、管理画面の保護が欠ける。

    3. SSIDの非表示は名前を隠すだけの補助策で、管理者パスワードの代わりにならない。

    4. MACアドレスの制限は補助策で、偽装もできる。管理画面を守る代わりにはならない。

頭の中で考える

  1. 無線LANが有線と違い、暗号化と認証の両方を必要とする理由を頭の中で説明してみよう。

    答えを開く

    電波は物理的に囲えず、届けば建物の外からも傍受されうる。暗号化がなければ内容を読み取られ、認証が弱ければ第三者に接続される。だから暗号化と認証で守る。

    思い浮かんだ要素にチェック

  2. 全員共通のPSK運用の弱点と、802.1Xで個別に認証する利点を頭の中で説明してみよう。

    答えを開く

    PSKは全員共通なので、退職時などに変更が要り、鍵が漏れたら全員分を入れ替える必要がある。802.1Xは利用者ごとに認証するので、個別に扱える。EAPで認証しRADIUSが判定する。

午後問題にチャレンジ

社内無線LANの診断記録（ダミー）
社内無線LAN: SSIDは非表示、端末はMACアドレスで制限
暗号化: 設定していない（オープンな状態）
診断: 接続せずに、電波を受信しただけで傍受を試した
結果: 通信の内容を、平文で取得できた
要件: 無線区間で傍受されても、内容を読まれないこと

適切な対策は、どれ？

答えを開く

WPA2（AES）以降の方式で、無線区間を暗号化する

よくある誤答

  • SSIDを隠す … すでに非表示だが、通信内容は平文で取得できた
  • MACアドレスの制限を厳しくする … 傍受は接続せずに行われており、影響しない
