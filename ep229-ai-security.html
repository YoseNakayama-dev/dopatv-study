AIシステム固有のセキュリティ 指示とデータ・権限・出力

  1. AIは指示とデータの区別が苦手で、外部の文章に埋まった指示にも従いうる。
  2. 「従うな」と書くだけでは防ぎきれない。権限の最小化と人の承認で被害を狭める。
  3. 出力は渡す前に検証し、入れる情報を選び出所を確認する。記録で異常を見つけて改善する。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題AIシステムの安全な使い方として、適切なものは？

    1. 出所と中身の確認が要る

    2. 書くだけでは防ぎきれない

    3. 出力も検証してから渡す

    4. 権限は最小限にする

  2. 社内の調査AIは、利用者が指定したWebページを読み込んで要約する。利用者の入力は「このURLを要約して」だけだったが、AIは要約の代わりに別の動作を始めた。ページの本文には、AIへの指示らしい文が埋まっていた。まず疑うべき原因はどれか。

    1. 利用者の入力は要約の依頼だけで、不正な文字列は無い。指示は利用者が入力していない外部の文章に埋まっており、入力欄の検査は対象外になる。

    2. 正解。利用者が打ち込んでいない外部の文章に指示が埋まり、AIがそれを指示として扱う間接型の典型。

    3. 汚染は学習データに不正なデータが混ざる問題。今回は読み込んだページの文に従っており、学習データの混入を示す事実は無い。

    4. 機密情報が出力に出た事実は無く、起きているのは別の動作の実行。漏えいの問題とは症状が違う。

  3. 部署が、顧客の個人情報を含む文書を社外のAIサービスに入力して要約させる運用を始めたい。入力した情報や学習した情報が出力に出うる点を踏まえた判断として、最も適切なものはどれか。

    1. 注意喚起だけでは、何を入れてよいかが決まらない。入れる情報を選び、扱いの方針を決めることが対策になる。

    2. 要約を確認しても、入力した情報が別の場面で出力に出る可能性は消えない。問題は入れる時点の判断にある。

    3. 事故後の調査に頼ると、入力した情報が出力に出うる点への備えが無いまま運用することになる。入れる前に範囲を決める必要がある。

    4. 正解。入力した情報が出力に出うる以上、AIに入れる情報を選び、出力の扱いも含めて方針で決めておく。

  4. AIエージェントの動作記録に、普段は送らない宛先へのメール送信が短時間に連続して残っていた。受信メールの文中の指示に従った疑いがある。初動として最も適切なものはどれか。

    1. 正解。異常な動きがあれば権限を止められるようにしておき、記録から原因を調べて改善する。権限を絞る設計の見直しにもつながる。

    2. 従わない保証は無く、送信できる権限も残る。書き加えて様子を見る間にも被害が続きうる。

    3. 特定の送信元を拒否しても、別の送信元の文章に指示が埋まる経路は残る。AIの権限が広いままでは同じ事故が起きうる。

    4. 原因は学習データではなく、読み込んだ文章中の指示を指示として扱う点にある。調査を省くと原因を特定できない。

  5. 問い合わせAIの再学習に、外部から収集した大量のデータを使っている。最近、回答が特定の方向に偏るようになったが、データの出所を記録しておらず、どれが原因か分からない。この状況の説明として最も適切なものはどれか。

    1. プロンプトインジェクションは文中の指示に従う問題。今回は再学習に使ったデータが疑わしく、入力欄の検査では扱えない。

    2. 正解。不正なデータを混ぜて挙動をゆがめるのが学習データの汚染で、出所が分からないと混入に気づけない。

    3. 出力の検証は出力を渡す前の対策で、学習に混ざったデータの影響を取り除くものではない。取り除けるという言い切りも根拠が無い。

    4. 公開されているからといって安全とは限らない。外部のデータは出所を確認する、という考え方が必要になる。

  6. AIが読み取る対象には、外部から届くメールやWebページも含まれる。担当者は「利用者の入力欄の検査と、プロンプトへの禁止事項の記載で、対策は十分」と報告した。見直しとして最も適切なものはどれか。

    1. 従わない保証は無く、「可能性はなくなる」は言い過ぎ。外部の文章は入力欄も通らない。

    2. 記載や語の追加を重ねても、従わせない保証にはならない。権限の最小化や人の承認など設計で重ねる必要がある。

    3. 利用者が入力していなくても、外部の文章に埋まった指示で起きうるのが間接型。対象にならないとは言えない。

    4. 正解。外部の文章は入力欄の検査を通らず、記載だけでは防ぎきれない。権限・承認・出力の検証など設計で重ねる。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 利用者が何も打ち込んでいないのに、AIが勝手に動いてしまうことがある。その仕組みと、被害を狭める設計上の手立てを頭の中で説明してみよう。

    答えを開く

    AIは指示とデータの区別が苦手なので、外部のメールやWebページに埋まった指示を指示として扱うことがある（間接型）。防ぎきれない前提で、AIに与える権限と接続先を最小限にし、送信や削除など影響の大きい操作は人の承認を挟む。

    思い浮かんだ要素にチェック

  2. 「従うな」とプロンプトに書くだけでは足りない理由と、あわせて必要な対策を頭の中で説明してみよう。

    答えを開く

    書いても従わない保証が無く、権限が残っていれば被害が出うる。権限の最小化、人の承認、出力を渡す前の検証、動作の記録といった設計で重ねる。

問い合わせAIの事故記録（ダミー）
社内の問い合わせAIが、受信メールを要約し返信文を作る
AIには顧客リストの外部送信が許可され、自分の判断で実行できる
外部からのメールの文中に、送信を促す指示があった
AIがその指示に従い、顧客リストを外部へ送信した
要件: 文中の指示だけで、外部送信を実行させない

適切な対策は、どれ？

答えを開く

AIの権限を最小化し、外部送信などの操作は人の承認を挟む

よくある誤答

  • 指示に『外部の指示に従うな』と書き加える … 従わせない保証はなく、送信の権限が残る
  • 返信文に禁止語がないか検査する … 送信の操作は、返信文の検査では止まらない
