#110 ・ 第4章 情報セキュリティマネジメントの実践

BCPとBCM 事業継続の計画と回し続ける運用

  1. BCPは事業全体で重要業務を続け戻す計画。策定前にBIAで影響を調べ、業務ごとにRTOとRPOを決める。
  2. 戦略（代替拠点・複製）と、発動基準・連絡網・役割分担を文書にする。経営層が方針と資源を決め、委託先も対象に含める。
  3. 計画は想定の範囲で、作っただけでは動かない。BCMで訓練と見直しを続ける。システムが戻っても業務手順が要る。
用語 9クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題BCPとBCMの説明として、適切なものは？

    1. BCMは訓練と見直しも続ける

    2. BCPは事業全体の継続を扱う

    3. BIAは影響を調べて重要業務を決める分析

    4. 時間の目標はRTO

  2. 受注業務の目標は「障害が起きても直前1時間分までの入力を復元でき、障害から3時間以内に再開する」である。現行運用は、データのバックアップを1日1回の夜間に取得し、復旧作業は4時間かかる見込みである。評価として最も適切なものはどれか。

    1. RPOも未達。1日1回の取得では、戻るのは最大で約1日前の時点で、直前1時間分という目標を満たさない。

    2. 正解。RPOは戻すデータの時点、RTOはいつまでに復旧するかの目標。取得が1日1回では直前1時間に届かず、4時間の復旧は3時間の目標を超える。

    3. RTOも未達。目標の3時間に対して、復旧作業が4時間かかる。

    4. RPOは、どの時点のデータまで戻すかの目標。バックアップがあっても、取得が1日1回なら直前1時間分までは戻らない。

  3. 情報システム部が単独でBCPを作成した。内容はサーバの復旧手順と代替サイトの確保で、営業や製造の業務手順、委託先の外部サービスは記載がなく、経営層には完成後に報告しただけである。評価として最も適切なものはどれか。

    1. ITの復旧は重要だが、BCPはIT部門に限らず事業全体が対象。システムが戻っても業務手順が戻らなければ事業は再開しない。

    2. 経営層は方針と資源を決め、発動の判断に責任を持つ。IT部門だけの計画にしない。

    3. 正解。BCPは事業全体の計画で、経営層が方針と資源を決める。重要業務を支える委託先や外部サービスも対象に含める。

    4. 重要業務を支える委託先や外部サービスも、BCPの対象に含める。契約があっても、業務が止まる影響は自社に及ぶ。

  4. BCPの机上演習で、連絡網の担当者が異動済みで連絡がつかず、代替拠点の利用手順にも古い設備名が残っていた。組織変更や委託先の変更後、計画の文書は更新していなかった。演習結果の扱いとして最も適切なものはどれか。

    1. 計画は想定の範囲で作るので、演習で手順を実際に動かして不備を見つけ、計画に戻す。反映しないと古い前提のまま残る。

    2. 連絡網だけでなく、組織・設備・委託先の変化も見直しの対象。まとめて先送りすると、古い前提が残る。

    3. 記録だけでは計画は変わらない。見直さない計画は古い前提のまま残り、被災時に動けない。

    4. 正解。訓練の結果と、組織や設備、委託先の変化を反映して見直す。BCMはこれを回し続ける活動。

  5. 復旧訓練で、障害を起こしたシステムは目標時間内に復旧した。しかし業務側は、受付の手順や連絡の役割が決まっておらず、システムの復旧後も業務を再開できなかった。評価として最も適切なものはどれか。

    1. RTOはいつまでに復旧するかの目標で、システムはすでに目標内に戻っている。業務の手順が戻らない点は、目標を短くしても解決しない。

    2. 正解。システムが戻っても、業務の手順が戻らなければ事業は再開しない。業務手順もBCPで定め、訓練で動かして確かめる。

    3. ITの復旧計画はBCPの一部を支えるもの。BCPと切り離さず、見直しの対象に含める。

    4. 業務を再開できなかった以上、計画が機能したとは言えない。計画は想定の範囲で作るため、訓練の結果を計画に反映する。

  6. 経営層が「全業務をRTO1時間、RPOほぼゼロで」と要求した。BIAでは、業務ごとに停止の影響の大きさと許容できる停止の長さに差があった。代替拠点とデータの複製を全業務に用意するには大きな費用がかかる。BCP担当者の対応として最も適切なものはどれか。

    1. 目標が短いほど備えの費用がかかる。費用の判断を後回しにすると、経営層が決める資源との関係が抜けたまま計画が進む。

    2. RTOとRPOは業務ごとに異なる。BIAで影響の大きい業務を見極め、業務ごとに決める。

    3. 正解。BIAで重要業務と優先順位を決め、目標を業務ごとに定める。目標が短いほど費用がかかるので、経営層が方針と資源を決められるよう説明する。

    4. 経営層が方針と資源を決める。IT部門だけの計画にせず、目標と資源の関係を経営層とあわせて決める。

頭の中で考える

  1. RTOとRPOの違いを、障害が起きた場面を想定して頭の中で説明してみよう。

    答えを開く

    RTOは、いつまでに復旧するかという時間の目標。RPOは、どの時点のデータまで戻すかという目標。どちらもBIAの結果をもとに業務ごとに決め、目標が短いほど代替拠点や複製などの備えに費用がかかる。

    思い浮かんだ要素にチェック

  2. BCPを作っただけでは事業継続につながらない理由と、BCMで何を回すのかを頭の中で説明してみよう。

    答えを開く

    計画は想定の範囲で作るため、作っただけでは動かない。手順が人の頭の中だけにあると被災時に動けず、組織や設備、委託先が変われば計画も古くなる。BCMは、策定・訓練・見直しを回し続け、訓練で見つけた不備や変化を計画に反映する。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

復旧計画の検討記録（ダミー）
受注システム: 停止が4時間を超えると、納期遅延が確定
経理システム: 3日止まっても、決算に影響しない
復旧の要員は少なく、同時に着手できるのは1システム
要件: 事業への影響が大きい業務から、順に復旧したい

復旧計画の方針として、適切なのは？

答えを開く

受注システムを、4時間以内の目標で最優先にする

よくある誤答

  • 全システムを、同じ目標時間にそろえる … 4時間にそろえても着手できるのは1システム。経理に割くと受注が間に合わない
  • 経理システムを、最優先で復旧する … 経理は3日待てる。先に限度が来るのは、4時間の受注
