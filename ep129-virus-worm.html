#29 ・ 第2章 情報セキュリティにおける脅威

ウイルスとワーム 宿主の有無と広がり方の違い

  1. ウイルスは他のファイルに寄生して増え、宿主ファイルが実行されて動く。実行されなければ広がらない。
  2. ワームは宿主を持たず単独で増える。広がるには到達できる経路と、未修正の脆弱性などが要る。
  3. 対策は修正プログラム適用・不要サービス停止・ネットワーク分離。検知ソフトだけでは未知の検体を取りこぼしうる。
用語 8クイズ 6考える 2午後本

用語カード

クイズ

  1. 動画で出た問題ウイルスとワームの違いとして、適切なのは？

    1. 逆。ウイルスは宿主に寄生する

    2. それは、ランサムウェアの挙動

    3. 宿主ファイルの実行が、きっかけになる

    4. ワームは宿主を持たない

  2. 社内でワームが同一セグメントの端末に広がった。再発と拡大を抑える対策として最も適切なものはどれか。

    1. 検知ソフトだけでは未知の検体を取りこぼしうる。「確実に防げる」は言い過ぎ。

    2. 正解。ワームの足がかりである未修正の脆弱性と不要なサービスを減らし、分離で拡大を抑える。

    3. ウイルス向けの対策。脆弱性を突くワームは、利用者の操作なしで広がりうる。

    4. ワームは宿主を持たない。宿主ファイルを探す対処は、ウイルスの説明に当たる。

  3. ある端末のファイルがウイルスに寄生されているが、そのファイルは一度も実行されていない。（狭義の定義で）ウイルスの性質から言える評価として最も適切なものはどれか。

    1. 宿主を持たずに広がるのはワーム。ウイルスは他のファイルに寄生する。

    2. 3機能はウイルスの説明の枠組み。動き出すきっかけは宿主ファイルの実行である。

    3. 正解。宿主ファイルが動かなければ広がらない。なお広義の定義では、寄生を問わない場合がある。

    4. 動き出すには宿主ファイルの実行が要る。「必ず」と言い切れる根拠はない。

  4. 端末Aがワームに感染したが、ネットワークを分けた別セグメントの端末は感染しなかった。この結果の解釈として最も適切なものはどれか。

    1. 正解。経路が閉じていれば、ワームは広がりにくい。ただし実際の挙動は検体ごとに異なる。

    2. 実際の挙動は検体ごとに異なる。一度の結果から「確実に届かない」とは言えない。

    3. ワームは宿主を持たない。感染しなかった理由は経路の有無で説明する。

    4. 分離は拡大を抑える対策の1つ。足がかりとなる脆弱性を減らす対策とは役割が違い、重ねて使う。

  5. ワームへの対策として、修正プログラムの適用の効果が大きいとされる理由はどれか。

    1. 宿主ファイルに寄生して増えるのはウイルス。ワームは宿主を持たない。

    2. 修正プログラムは脆弱性を直すもの。検体の検出や駆除は役割が違う。

    3. 利用者の行動を変えるものではない。脆弱性を突くワームは、操作なしでも広がりうる。

    4. 正解。脆弱性を突くタイプの足がかりは、ネットワーク上の未修正の脆弱性である。

  6. 暗号資産の採掘に端末を悪用するマルウェアが見つかった。ウイルスかワームかを判断する軸として最も適切なものはどれか。

    1. 目的と増え方は別の軸。目的だけでワームと決まるわけではない。

    2. 採掘は「何をするか」の軸の例で、増え方の軸ではない。

    3. 正解。軸①は増え方、軸②は目的。ウイルスとワームは軸①で分ける。

    4. 採掘をするものも、増え方（宿主の有無）で分類できる。軸が別なだけである。

頭の中で考える

  1. ウイルスとワームの違いを、宿主の有無と「広がる条件」の観点で、頭の中で説明してみよう。

    答えを開く

    ウイルスは他のファイルに寄生して増え、宿主ファイルが実行されて動き出すので、実行されなければ広がらない。ワームは宿主を持たず単独で増え、到達できる経路と未修正の脆弱性などがあればネットワーク経由で広がる。

    思い浮かんだ要素にチェック

  2. 修正プログラム未適用の端末だけが次々に感染し、利用者のファイル実行の記録は無い。種類の判断と、拡大を抑える対策を頭の中で説明してみよう。

    答えを開く

    宿主がなく、実行操作なしで脆弱性を介して広がっているので、ワームと判断する。修正プログラムの適用と不要なサービスの停止で足がかりを減らし、ネットワーク分離で拡大を抑える。ただし挙動は検体ごとに異なる。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

社内端末の感染調査記録（ダミー）
対象: 社内の端末群（ダミー）。端末Aの感染のあと、同一セグメントの端末が次々に感染
感染した端末は、すべて修正プログラム未適用 / 適用済みの端末は感染なし
感染端末から、他端末の共有サービス用ポートへの接続が、連続して発生
最初の実行は、OSの共有サービスのプロセスから / 既存の実行ファイルに変更なし
感染時刻は、利用者のログオンの有無と無関係 / 利用者が実行したファイルの記録なし

この感染の種類として、適切なのは？

答えを開く

ワーム（単独で自己増殖し、脆弱性を介して広がる）

よくある誤答

  • ウイルス … 既存の実行ファイルに変更がなく、宿主がない
  • トロイの木馬 … 感染は、利用者のログオンと無関係で、実行したファイルもない
