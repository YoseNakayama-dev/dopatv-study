IP-VPN・L2TP・S/MIME・PGP 閉域網とメール保護の整理

  1. IP-VPNは経路を分離する閉域網で、暗号化は含まれないのが一般的。事業者の運用を信頼する前提がある。
  2. L2TP自体に暗号化と認証の機能はない。IPsecと組み合わせて補う。
  3. S/MIMEとPGPは暗号化と署名が目的。違いは鍵の持ち主の保証で、認証局か利用者同士の署名か。

クイズ

  1. 動画で出た問題通信とメールの保護の説明として、適切なものは？

    1. IP-VPN自体は暗号化を保証しない

    2. L2TPに暗号化の機能はない

    3. 署名は本文を隠さない

    4. 利用者同士の署名で信頼を築く

  2. A社の担当がB社の担当へ、S/MIMEで機密メールを送る。内容を第三者に読まれないようにし、かつ送信者が本人だと確認できるようにしたい。鍵の使い方として最も適切なものはどれか。

    1. 正解。暗号化は受信者の公開鍵で行い、受信者の秘密鍵で復号する。署名は送信者の秘密鍵で付け、公開鍵で検証する。

    2. 鍵の役割が逆になっている。暗号化は受信者の公開鍵、署名は送信者の秘密鍵を使う。

    3. 受信者の公開鍵は誰でも使えるので、暗号化しても送信者の確認にならない。送信者の確認と改ざんの検知には署名が要る。

    4. 受信者の秘密鍵は受信者だけが持つ鍵で、送信者は使えない。署名も送信者の公開鍵ではなく秘密鍵で付ける。

  3. 初めて取引する相手から、PGPの公開鍵が添付されたメールが届いた。その鍵が本人のものかを確かめる方法として最も適切なものはどれか。

    1. PGPは認証局に頼らない。鍵の持ち主の確認は利用者自身が行う。

    2. 正解。PGPでは鍵の持ち主の確認を利用者自身が行い、鍵の指紋を別の経路で確かめる。

    3. 鍵と指紋が同じメールで届いたのでは、同じ経路を通っただけで、別の経路での確認にならない。

    4. 送信元アドレスが一致しても、鍵の持ち主の確認にはならない。指紋を別の経路で確かめる必要がある。

  4. 在宅勤務者が本社へL2TPだけでリモートアクセスしている。セキュリティ診断で、通信が暗号化されていないと指摘された。改善策として最も適切なものはどれか。

    1. IP-VPNは経路を分けるサービスで、暗号化は含まれないのが一般的。乗り換えても暗号化されるとは限らない。

    2. トンネルを増やしても、暗号化や認証の機能がL2TPに加わるわけではない。

    3. 正解。L2TP自体に暗号化・認証の機能はないので、IPsecと組み合わせて補う。

    4. S/MIMEはメールの暗号化と署名の仕組みで、リモートアクセスの通信全体を保護するものではない。

  5. 本社と支店を事業者のIP-VPNでつなぎ、事業者網内で経路が利用者ごとに分離されている。この構成のリスク評価として最も適切なものはどれか。

    1. インターネットを経由しないことと、暗号化されていることは別。暗号化は含まれないのが一般的である。

    2. IP-VPNは事業者の運用を信頼することが前提になる。評価から外すことはできない。

    3. IP-VPNは閉域網のサービスで、インターネットVPN（IPsec VPN・SSL-VPN）とは別物。IPsecは必須ではなく、事業者網内の漏えいが心配なときに併用する。

    4. 正解。経路は分離されても暗号化は一般に含まれず、事業者の運用を信頼する前提がある。心配ならIPsecなどを併用する。

  6. 取引先からS/MIMEの署名付きメールが届いた。署名の検証には取引先の公開鍵を使う。その鍵が本当に取引先のものだと判断する根拠として最も適切なものはどれか。

    1. 正解。S/MIMEでは、公開鍵の持ち主を認証局が発行した証明書（X.509）で保証する。

    2. これはPGPの信頼の築き方。S/MIMEは認証局の証明書で鍵の持ち主を保証する。

    3. 署名の検証は、その公開鍵で署名が合うかを確かめるだけである。鍵の持ち主の保証は証明書が担う。

    4. 送信元アドレスは鍵の持ち主の保証にならない。証明書で確認する。

頭の中で考える

  1. S/MIMEの暗号化と署名で、使う鍵と守れることの違いを頭の中で説明してみよう。

    答えを開く

    暗号化は受信者の公開鍵で行い、受信者の秘密鍵で復号して本文を隠す。署名は送信者の秘密鍵で付け、公開鍵で検証して送信者の確認と改ざんの検知をする。署名は本文を隠さない。

    思い浮かんだ要素にチェック

  2. S/MIMEとPGPで、公開鍵の持ち主を信頼する仕組みがどう違うか。PGPの注意点も頭の中で説明してみよう。

    答えを開く

    S/MIMEは認証局が発行した証明書で持ち主を保証する。PGPは認証局に頼らず、利用者同士が互いの鍵に署名し合う。PGPでは鍵の持ち主の確認を利用者自身が行い、指紋を別の経路で確かめる。

適切な対策は、どれ？

答えを開く

よくある誤答

  • 帯域の大きい回線に変更する … 帯域は十分で、暗号化にも関係しない
  • 別の事業者のIP-VPNに乗り換える … 検討中のどの事業者も、暗号化は含まない
