#123 ・ 第9章 情報セキュリティに関する法制度

電子署名法 本人だけが行える署名と認証業務

  1. 電子署名は本人性と非改ざん性を確認する。本人だけが行える署名があれば、真正に成立したと推定される。
  2. 推定は反証があれば覆る。署名を行う符号や物件を適正に管理し、本人だけが使えることが前提になる。
  3. 認証業務の認定は任意。立会人型は事業者が利用者の指示で署名する方式。検証と保存はPKIとタイムスタンプで支える。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題電子署名法の説明として、適切なものは？

    1. 推定は反証で覆る

    2. 本人だけが行える署名で推定

    3. 認定は任意

    4. 画像は本人だけが行えない

  2. 社長のICカードと暗証番号を、秘書が預かって日常的に代行署名していた。契約相手は「電子署名があるので社長の署名として成立したと推定される」と主張し、社長は自分の意思ではないと争っている。評価として適切なものはどれか。

    1. 正解。推定は、本人だけが行える署名であることが前提。符号や物件を適正に管理していなければ、推定が成り立たない、または反証で覆る恐れがある。

    2. 推定の前提は、符号や物件を適正に管理し、本人だけが行えること。事業者の認定は任意の制度で、その管理を代わりに満たすものではない。

    3. 暗証番号の共有や貸し借りは、本人だけが行える状態を損なう。カードの所有者であっても、推定の前提は満たされない。

    4. 管理の方法は、本人だけが行える署名かどうかを左右する。電子データであっても、管理は推定の前提に関わる。

  3. 電子証明書の発行元を選ぶ。事業者Xは国の認定を受けており、事業者Yは未認定である。選定の考え方として適切なものはどれか。

    1. 認定は任意で、認定がなくても認証業務は行える。未認定だから、すべて無効になるわけではない。

    2. 証明書を発行する側の認定と、署名鍵・暗証番号を本人だけが使えるよう管理することは別。利用者側の管理は引き続き必要。

    3. 認定は任意でも、基準は本人確認の方法・設備・運営などを見るためのもの。認定の有無だけでなく、基準の内容も比べる価値がある。

    4. 正解。認定は一定の基準を満たす事業者を国が認める任意の制度。未認定でも業務は行えるので、基準の中身も見て選ぶ。

  4. 取引先が「この契約書には電子署名が付いているので、真正に成立したことは確定しており、争う余地はない」と主張している。見解として適切なものはどれか。

    1. 電子署名があっても、成立が確定するわけではない。推定であり、反証があれば覆る。

    2. 推定である以上、反証があれば覆る。認定は任意の制度で、反証を不可能にするものではない。

    3. 正解。本人だけが行える電子署名があると、真正に成立したと推定される。推定なので反証があれば覆る。

    4. 符号や物件の適正な管理は、本人だけが行える署名であることの前提。推定と無関係とは言えない。

  5. 電子署名付きの契約書を、長期間保存する。署名の検証と長期保存の設計として、適切なものはどれか。

    1. 署名の検証と長期保存は、PKIとタイムスタンプで支える。ファイルを保存するだけでは、検証の仕組みを用意したことにならない。

    2. 正解。署名の検証と長期保存は、PKIとタイムスタンプで支える。

    3. 押印し直しても、電子署名の効力が引き継がれるわけではない。電子署名の本人性と非改ざん性は、その署名自体で確認する。

    4. 暗証番号は署名を行うときの本人の管理に関わるもの。長期の検証を保つ手段にはならない。

  6. 取引先から届いた電子署名付きの文書を検証したところ、署名者は取引先の担当者本人と確認できたが、署名後に文書の一部が変更されていた。判断として適切なものはどれか。

    1. 電子署名は本人性だけでなく、改変がないことも確認できる。署名後に変更された部分まで、本人の作成とは扱えない。

    2. 電子署名が確認するのは、本人性と、改変がないことの二つ。改変があれば、目的の一方が満たされない。

    3. 改変の有無を確認できることは、電子署名の要素の一つ。別の手段に任せる前提ではない。

    4. 正解。電子署名は、本人が作成したことと、改変がないことを確認するもの。変更があるなら、その文書は信頼できない。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 電子署名があっても、文書が真正に成立したと推定されない場合を、頭の中で説明してみよう。

    答えを開く

    推定は、本人だけが行える署名であることが前提で、反証があれば覆る。鍵や暗証番号を共有・貸し借りして本人だけが使える状態でなければ、推定は成り立たない、または覆る恐れがある。

  2. 認証業務の認定が「任意」とは、どういうことか。事業者を選ぶ立場で、頭の中で説明してみよう。

    答えを開く

    国が一定の基準（本人確認の方法・設備・運営など）を満たす事業者を認定する制度だが、認定は任意で、認定がなくても認証業務は行える。認定の有無だけでなく、基準の中身も見て選ぶ。

電子契約の確認記録（ダミー）
契約書のPDFを、電子メールで取引先へ送る
社内のPCに、社長の署名画像があり、担当者も使える
社長のICカードに、署名鍵が入っている
要件: 契約書が、社長本人の署名で成立したと推定される

適切な対策は、どれ？

答えを開く

社長の署名鍵で電子署名を付与し、鍵は社長だけが使えるよう管理する

よくある誤答

  • 署名画像をPDFに貼り付ける … 担当者も使え、改変の有無も確認できず、電子署名ではない
  • PDFにパスワードを設定する … 開く人を限るだけで、誰が署名したかを示さない
