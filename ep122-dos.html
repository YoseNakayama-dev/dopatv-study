#22 ・ 第2章 情報セキュリティにおける脅威

DoS攻撃の種類 狙う資源で4つに分ける

  1. DoSは可用性への攻撃で、DDoSは多数の機器から分散して行う。狙う資源で帯域・接続・アプリ・脆弱性に分けて考える。
  2. 接続型（SYNフラッド）は、未完了の接続が溜まって新規接続を受けられない。回線に余裕があっても応答しなくなる。
  3. 正規と同形式で送信元が分散・偽装されるため防ぎにくい。回線・接続・アプリの状況から資源を切り分ける。

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題DoS攻撃で、直接損なわれるセキュリティ特性は？

    1. 情報が漏れないこと

    2. 改ざんされないこと

    3. 可用性

    4. 本物であると確認できること

  2. Webサービスに接続できなくなった。監視では、回線使用率が上限に張り付いており、正規の通信も入れない状態だった。DoSの型として最も適切なものはどれか。

    1. 正解。回線使用率の極端な上昇は帯域型の特徴。

    2. 接続型は回線に余裕があっても応答しなくなる型。使用率が上限というこの状況とは合わない。

    3. アプリ型は通信量が多くない。回線使用率が上限に張り付く状況とは合わない。

    4. 脆弱性型は想定外の入力で停止する型で、回線使用率の上昇は特徴ではない。

  3. 特定の送信元IPアドレスを遮断して対処したが、攻撃元が多数で次々と変わり、止まらなかった。DDoSが防ぎにくい理由として最も適切なものはどれか。

    1. この状況の理由は暗号化ではない。送信元が分散・偽装され、正規と同じ形式であることが、送信元単位の遮断を難しくしている。

    2. 正解。正規と同じ形式で、送信元が分散・偽装されるため、送信元単位では切り分けにくい。

    3. 脆弱性型は一つの型にすぎず、DDoS全般の防ぎにくさの理由ではない。

    4. 帯域型が使い切るのは回線容量。CPUを使い切るのは別の型の特徴である。

  4. 検索ページへのアクセスだけが増え、サービスが遅くなった。回線使用率は平常で、通信量も多くない。回線を増強する案が出た。この判断の評価として最も適切なものはどれか。

    1. 回線使用率は平常で、帯域は枯渇していない。増強しても原因は変わらない。

    2. 接続が溜まっているという根拠がない。検索ページへのアクセスだけが増え、回線使用率も平常という症状は、接続型とは合わない。

    3. 想定外の入力による停止という根拠がない。症状は正規に見える要求の増加である。

    4. 正解。通信量が多くなく処理が重くなる場合はアプリ型が疑われ、帯域の増強では解消しにくい。

  5. 通信量は少ないのに、細工された入力を1件受けただけでサービスが停止した。型として最も適切なものはどれか。

    1. 正解。想定外の入力でプログラムを停止させる型で、脆弱性が前提になる。

    2. 帯域型は大量の通信が必要。通信量が少ないこの状況とは合わない。

    3. 接続型は未完了の接続が溜まって起きる。1件の入力で停止する状況とは合わない。

    4. アプリ型は重い要求を繰り返す必要がある。1件で停止する点と合わない。

  6. サービスが応答しなくなった。DoSの型を切り分けるための確認として最も適切なものはどれか。

    1. 回線使用率が低くても、接続型やアプリ型では応答しなくなる。攻撃でないとは言えない。

    2. 正解。回線・接続・アプリのどの資源が尽きているかを見て、型を切り分ける。

    3. DDoSかどうかが分かっても、尽きた資源が分からなければ対処を選べない。

    4. アプリ型は通信量が多くなくても成立する。通信量が少ないことだけで、帯域・接続・アプリ型の可能性を否定できるとは言えない。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. サービスが応答しないのに回線の使用率は平常だった。どの型を疑い、何を確認するかを、頭の中で説明してみよう。

    答えを開く

    帯域型ではなく、接続型（SYNフラッドなど）やアプリ型を疑う。未完了の接続の数が上限に達していないか、アプリのCPU・メモリや要求の内容に偏りがないかを確認し、尽きた資源を切り分ける。

    思い浮かんだ要素にチェック

  2. DDoSが、単純な送信元の遮断では防ぎにくい理由を、頭の中で説明してみよう。

    答えを開く

    攻撃の通信が正規と同じ形式で、見分けにくい。送信元も多数の機器に分散し、偽装されることもある。そのため送信元や内容だけでは正規の通信と切り分けにくい。
