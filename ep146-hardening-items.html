#46 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

要塞化の主な実施項目 アカウント・サービス・更新・ログ

  1. アカウントとサービスは不要なものを減らす。初期パスワードは変え、共有アカウントは避ける。
  2. 修正プログラムは検証して適用し記録。ファイル権限は必要最小限。ログは別の場所に保管し時刻を合わせる。
  3. チェックリストと構成基準で漏れを減らし、定期点検でずれを見つける。限界は未知の脆弱性と運用の誤り。

クイズ

  1. 動画で出た問題要塞化の実施項目として、適切なのは？

    1. 不要なサービスの停止と通信の絞り込み

    2. ログがないと、事故を調査できない

    3. 共有だと、誰の操作か追えない

    4. 脆弱性が残る。検証して適用する

  2. 侵害されたサーバで、同じサーバ内に保存していたログが消されており、調査できなかった。再発防止として最も適切なものはどれか。

    1. 保存期間や容量を増やしても、同じサーバ内では消去や改ざんに備えられない。

    2. ログがないと、事故のあとに調査できない。

    3. 正解。ログは別の場所に保管し、時刻も合わせる。改ざんや消去に備えるため。

    4. 閲覧を絞っても保存先が同じなら、消去や改ざんへの備えにならない。

  3. 運用担当が、リモート管理でサーバに接続する運用を設計している。設計として最も適切なものはどれか。

    1. リモート管理では、暗号化した経路・接続元の制限・多要素認証を挙げる。パスワードの変更だけでは足りない。

    2. 正解。リモート管理は暗号化した経路で行い、接続元も制限する。可能なら多要素認証も使う。

    3. 接続元の制限と、経路の暗号化は別々に必要。片方だけでは足りない。

    4. 共有アカウントは、誰の操作か追えなくなるため避ける。

  4. サーバに適用する修正プログラムが公開された。運用方針として最も適切なものはどれか。

    1. 検証せずに一斉に適用すると、業務への影響を確かめられない。記録も適用のたびに残す。

    2. 適用しないと脆弱性が残る。影響を恐れて適用しないのは言い過ぎ。

    3. 修正プログラムは検証してから適用し、記録を残す。記録を障害時だけにするのは足りない。

    4. 正解。修正プログラムは、検証してから適用し、記録を残す。

  5. 共有フォルダの重要ファイルに、閲覧だけで足りる利用者にも書き込み権限が付いていた。見直しとして最も適切なものはどれか。

    1. 正解。重要なファイルは必要な利用者だけが読める設定にし、読むだけで足りる人に書き込みの権限は与えない。

    2. 通知しても書き込み権限は残る。権限を必要な範囲に絞る対策にならない。

    3. 権限の設定を変えていないので、読むだけで足りる人に書き込み権限が残る。

    4. マルウェア対策は別の項目で、権限の見直しの代わりにならない。

  6. 要塞化のチェックリストの全項目を実施し終えた。担当者は「これで完了。以後の点検は不要」と報告した。評価として最も適切なものはどれか。

    1. 実施しても、未知の脆弱性や運用の誤りは残る。

    2. 正解。実施しても未知の脆弱性や運用の誤りは残る。定期的な点検で基準からのずれを見つける。

    3. 基準もチェックリストも、システムの変化に合わせて更新する。

    4. 優先順位は公開サーバや重要な資産から順に進める。後回しにするのは逆。

頭の中で考える

  1. 削除の操作ログに共有の管理者アカウントしか残らない場合に、誰の操作か特定できない理由と、パスワードを強くしても解決しない理由を、頭の中で説明してみよう。

    答えを開く

    共有アカウントでは、複数人が同じアカウントで操作するため、ログに残るのはアカウントまでで、人の区別がつかない。パスワードを強くしても共有している限り区別できない。共有をやめて個人のアカウントで行う。

    思い浮かんだ要素にチェック

  2. ログを別の場所に保管し、時刻を合わせる理由を、頭の中で説明してみよう。

    答えを開く

    改ざんや消去に備えるため。ログがないと事故のあとに調査できない。

午後問題にチャレンジ

ファイルサーバの調査記録（ダミー）
対象: 社内ファイルサーバB（ダミー）。重要フォルダが削除された
誰が削除したかは、特定できていない
操作ログ: 削除の操作を記録。実行アカウントは admin-shared
admin-shared は、運用担当5人が共同で使う管理者アカウント
パスワードは強度基準を満たす / 5人は個人のアカウントも持つ

特定できない原因への対策として、適切なのは？

答えを開く

共有アカウントを廃止し、管理作業も個人のアカウントで行う

よくある誤答

  • ログの取得を始める … 削除の記録は、すでにある（アカウントまで）
  • パスワードを強くする … 強度は基準を満たす。5人の区別はつかない
