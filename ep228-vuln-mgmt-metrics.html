脆弱性管理 CVE・CVSS・KEV・EPSS 何を測る指標か

  1. CVEは識別番号、CVSSは技術的な深刻度、KEVは悪用が確認された事実、EPSSは今後30日の悪用の予測。
  2. CVSSの基本値は自社の危険度そのものではない。KEVに無いことは安全の証明にならず、EPSSは予測にすぎない。
  3. 悪用の状況・資産の公開有無と重要度・CVSSを組み合わせて決め、修正が困難なら緩和策、後で再確認する。

  1. 動画で出た問題脆弱性管理の指標の説明として、適切なものは？

    1. CVEは識別番号

    2. KEVは確認された悪用の一覧

    3. EPSSは確率の予測

    4. 資産の状況で優先度は変わる

  2. 公開中の顧客向けサーバにある脆弱性が、KEVに載っていない。担当者は「載っていないので悪用されていない」と報告し、後回しを提案した。この判断の評価として最も適切なものはどれか。

    1. KEVに載るのは、悪用が確認されたものの一部。載っていなくても、悪用されていないとは言えない。

    2. 正解。載っていないことは安全の証明にならない。EPSSの値や、資産の公開有無・重要度もあわせて判断する。

    3. 米国視点の一覧という限界はあるが、現実の攻撃に使われた事実を示す点は、自社の判断材料になる。

    4. EPSSは予測にすぎず、確定ではない。資産の公開有無や重要度は、EPSSが低くても確認する。

  3. ある脆弱性のEPSSの値が0.02と報告された。この値の読み方として最も適切なものはどれか。

    1. 正解。EPSSは今後30日以内に悪用される確率を統計で予測した値。予測であり確定ではないので、他の材料とあわせて判断する。

    2. 技術的な深刻度を示すのはCVSS。EPSSは深刻度ではなく悪用される確率の予測。

    3. 確認された悪用の一覧はKEV。EPSSは事実の集計ではなく、将来の悪用の予測。

    4. EPSSは自社の資産への影響の割合を表すものではない。脆弱性ごとの悪用の確率の予測。

  4. 公開中の顧客向けサーバの脆弱性がKEVに掲載された。修正の適用は業務の都合で今月は難しい。最も適切な対応はどれか。

    1. 悪用が確認されたものは急ぐ。CVSSの基本値だけで先送りを決めない。

    2. 修正が困難な間も、対応を止めない。修正が難しければ緩和策を取る。

    3. 正解。修正が困難なら緩和策を取る。対応したあとは、効果を再確認する。

    4. KEVは米国視点の一覧という限界はあるが、現実の攻撃に使われた事実を示す。公開サーバなら急ぐ材料になる。

  5. 公開サーバの脆弱性に、ベンダーの修正がまだ無い。アクセス元を制限する緩和策を適用し、修正は未適用のままチケットを完了にした。この扱いの評価として最も適切なものはどれか。

    1. 正解。緩和策は修正の代わりに取る対応。対応したあとは効果を再確認し、修正が残っていることも管理に残す。

    2. 緩和策は被害を抑えるもので、脆弱性そのものが直るわけではない。効果は再確認する。

    3. 修正が困難なら、緩和策を取る。修正を待つ間に何もしないのは、公開サーバでは危険。

    4. CVSSの基本値は脆弱性そのものの特性から決まる。緩和策を取っても基本値は変わらない。

  6. 自社の規程案に「KEVに載った脆弱性は、KEVの対応期限までに必ず修正する」とあった。この規程案の評価として最も適切なものはどれか。

    1. KEVの対応期限は、連邦政府機関向けに定められたもの。民間の組織にそのまま適用されるわけではない。

    2. 正解。期限は連邦政府機関向け。掲載は悪用が確認された事実なので、自社の資産の状況を踏まえて対応期限を定める材料にする。

    3. 確率の予測はEPSS。KEVは悪用が確認された事実の一覧であり、優先順位の材料として使える。

    4. CVSSの基本値は単独では優先順位を決めない。悪用の事実を示すKEVは、基本値とは別の判断材料。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. KEVとEPSSの違いを「事実」「予測」の言葉を使って説明し、それぞれの限界も頭の中で述べてみよう。

    答えを開く

    KEVは悪用が確認された事実の一覧（CISA）で、載っていないことは悪用されていない証明にならず、米国視点の一覧でもある。EPSSは今後30日以内に悪用される確率の統計的な予測（FIRST）で、確定ではない。

    思い浮かんだ要素にチェック

  2. CVSSの高い順に直す運用が不十分な理由と、組み合わせるべき材料を頭の中で説明してみよう。

    答えを開く

    CVSSの基本値は技術的な深刻度で、自社での危険度そのものではない。悪用の状況（KEV・EPSS）、資産の公開有無と業務上の重要度、悪用に必要な条件などを組み合わせて優先順位を決める。修正が困難なら緩和策を取り、対応後に再確認する。
