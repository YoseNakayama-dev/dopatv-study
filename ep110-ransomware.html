#10 ・ 第2章 情報セキュリティにおける脅威

ランサムウェア 被害の大きさは備えで決まる

  1. ファイル暗号化型は、感染した端末がアクセスできる範囲に及ぶ。入口はメール添付や改ざんサイトの閲覧。
  2. 復号は困難とされるため、戻す備えが要る。バックアップは取得時だけ接続し、複数媒体に取り、復元を確認する。
  3. 更新やセキュリティソフトは入口を減らす対策で、戻す備えとは別。IPA資料は2017年のもの。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ランサムウェアの被害を低減する備えとして適切なのは？

    1. 同時に暗号化されうる

    2. 切り離し、戻せるか確認する

    3. 感染の入り口になりうる

    4. 更新し続けるのが基本

  2. バックアップ運用の見直し案が4つ出た。ランサムウェアの被害を低減する観点で、最も適切なものはどれか。

    1. 誤り。接続したままだと、バックアップも同時に暗号化されうる。

    2. 誤り。クラウドと同期するフォルダは、感染端末の変更の影響を受けうる。

    3. 誤り。リストア確認は定期的に行う。故障時だけでは、戻せない事態に気づけない。

    4. 正解。書き換え不可の光学メディアは接続したままでも可。複数の媒体に取っておく。

  3. ファイル暗号化型ランサムウェアに感染した端末Aは、ファイルサーバの共有フォルダ、クラウドと同期するフォルダ、接続中の外付けHDDを利用できる。暗号化の影響範囲として最も適切なものはどれか。

    1. 正解。暗号化型は、感染端末がアクセスできる範囲に影響しうる。

    2. 誤り。影響はローカルディスクに限られない。

    3. 誤り。端末からアクセスできるサーバ上のデータは、対象になりうる。

    4. 誤り。クラウドと同期するフォルダも、対象になりうる。

  4. 社員が通常の業務で閲覧した改ざんサイトの広告から、OSとブラウザの更新を長く止めていた端末が感染した。メールの添付は開いていない。入口対策として最も適切なものはどれか。

    1. 誤り。今回の入口はメールの添付ではない。入口に合った対策が要る。

    2. 誤り。定義ファイルの更新は入口を減らす対策で、戻す備えとは別。バックアップは要る。

    3. 正解。改ざんサイトや広告の閲覧では、脆弱な端末が入口になる。OSとソフトを最新にする。

    4. 誤り。外付けHDDは影響範囲の話で、閲覧による感染の入口とは別。

  5. 更新が多い営業部門のファイルサーバと、ほとんど更新されない保管用のファイルサーバがある。バックアップの方式と頻度の決め方として最も適切なものはどれか。

    1. 誤り。一律に最安・月次では影響の大きさに合わない。定義ファイルの更新は入口を減らす対策で、戻す備えの代わりにならない。

    2. 正解。影響範囲のリスク分析をして、バックアップの方式と頻度を決める。

    3. 誤り。保管用のサーバも暗号化の対象になりうる。影響を分析せずに外してはいけない。

    4. 誤り。影響を分析せずに現状維持とするのは、リスク分析に基づく判断ではない。

  6. バックアップ装置は取得時だけ接続する運用で、毎日「取得成功」の通知が届く。ただし、一度も復元を試したことがない。この運用の評価として最も適切なものはどれか。

    1. 誤り。取得の成功は、戻せることの保証にならない。

    2. 誤り。取得時だけの接続は有効だが、戻せるかの確認は別に必要。

    3. 正解。バックアップは取っただけでは足りない。定期的に復元（リストア）して確認する。

    4. 誤り。必要になってから初めて確認すると、戻せないことに手遅れで気づく。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. ランサムウェア対策で、「入口を減らす対策」と「戻す備え」を分けて考える理由を、頭の中で説明してみよう。

    答えを開く

    OS・ソフトの更新、定義ファイルの更新、添付ファイルに注意することは入口を減らす対策で、感染した後の復旧を保証しない。復号は困難とされるので、バックアップを切り離し、複数の媒体に取り、戻せるか確認する備えが別に要る。

    思い浮かんだ要素にチェック

  2. バックアップの方式と頻度を決めるために、何を分析するか。頭の中で説明してみよう。

    答えを開く

    暗号化された場合の影響範囲を分析する。感染した端末がアクセスできるファイルサーバ、接続中の外付けHDD、クラウドと同期するフォルダ、共有フォルダが、どこまで使えなくなるかを見積もり、それに合わせて方式と頻度を決める。

暗号化被害の調査記録（ダミー）
ファイルサーバの文書が暗号化され、身代金を要求された
バックアップ用NASは、ファイルサーバと同じネットワークにあった
NAS内のバックアップも暗号化され、復旧に使えるデータが残らなかった
// バックアップは1台のNASのみ。リストア確認は実施済み
// OSとソフト、定義ファイルは最新だった

復旧できなかった根本原因は？

答えを開く

バックアップが切り離されておらず、暗号化の対象になった

よくある誤答

  • リストア確認をしていなかった … 記録では実施済み
  • OSが古かった … 記録では最新。感染の入口の話で、復旧の可否とは別
