#55 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

IPSの概要と主な機能 経路の中で検知して止める

  1. IPSは通信の経路に置き（インライン）、通る通信を検査して、不正なものを自動で遮断する。
  2. IDSは経路の外で通知のみ。IPSは誤検知なら正常な通信も止めるので、まず検知のみで運用して調整する。
  3. 脆弱性を狙う通信の遮断は修正までの被害軽減で、修正の代わりではない。暗号化通信は復号が要る。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題IPSの説明として、適切なのは？

    1. 経路に置き、自動で遮断

    2. それは、IDSの説明

    3. 復号しないと、中身は見えない

    4. 誤検知なら、正常な通信も止まる

  2. 「既知の脆弱性を狙う通信をIPSで遮断できているので、Webアプリの修正は後回しにしてよい」という判断があった。評価として最も適切なものはどれか。

    1. 遮断しても脆弱性そのものは残る。解消されたことにはならない。

    2. 正解。脆弱性を狙う通信の遮断は修正までの被害軽減で、修正の代わりではない。

    3. IPSは検知に加えて遮断を行う。通知のみなのはIDS。

    4. IPSは経路の中に置く（インライン）もの。配置を変えても修正の代わりにはならない。

  3. IPSを導入初日から遮断を有効にしたところ、業務の正常な通信が止まった。導入の進め方として本来望ましいものはどれか。

    1. 検知の方法を限るだけでは、誤検知を調整したことにならない。調整の手順を踏むことが要る。

    2. 遮断できることがIPSの役割で、IDSへの置き換えは目的に合わない。調整してから遮断を有効にする。

    3. 正解。導入時は検知のみで運用し、調整してから遮断を有効にする。

    4. 検知のみのままでは、IPSの遮断の役割を使わない。調整してから有効にするのが筋。

  4. 経路には機器を置かず、サーバ1台の上で不正な挙動を阻止する構成にした。この種類の名称として適切なものはどれか。

    1. ネットワーク型は経路上で検査する種類。今回は経路に機器を置いていない。

    2. IDSは通知のみで、阻止はしない。今回は阻止する構成。

    3. 経路の中に置いて検査し止めるのはIPS。IDSは経路の外で通知のみ。

    4. 正解。ホスト型はホスト上で不正な挙動を阻止する種類。

  5. 同じ誤検知が、経路の外に置いたIDSと、インラインに置いたIPSの両方で起きた。両者の影響の違いとして最も適切なものはどれか。

    1. IPSは自動で遮断できるので、通知のみではない。

    2. 正解。IDSは経路の外にあり誤検知でも通信は止まらない。IPSは誤検知なら正常な通信も止める。

    3. 役割が逆。止めるのはIPSで、IDSは基本的に通知のみ。

    4. 誤検知なら正常な通信も止めて業務に影響する。調整は導入時に人が行うもの。

  6. 「HTTPSなどの暗号化通信は、IPSが何もせずに中身まで検査できる」という説明があった。この説明への指摘として最も適切なものはどれか。

    1. 経路上にあっても、復号しないと暗号化通信の中身は見えない。

    2. 検査できるかは復号の有無で決まる。ネットワーク型でも復号すれば検査できるので、ホスト上でなければ検査できないとは言えない。

    3. 正解。暗号化通信は復号しないと中身を検査できない。

    4. 復号すれば中身が見えるので、シグネチャ照合も行える。暗号化通信が照合の対象外になるわけではなく、復号しないと中身が見えないのが要点。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. IDSでは「確認を待つ間も通信が到達し続ける」状況だった。IPSが解決する点と、IPSで新たに生じる注意点を頭の中で説明してみよう。

    答えを開く

    IPSは通信の経路の中に置かれ、不正な通信を自動で遮断するので、人の確認を待たずに止められる。一方、誤検知なら正常な通信も止めて業務に影響するため、検知のみで運用して調整してから遮断を有効にする。

    思い浮かんだ要素にチェック

  2. IPSで脆弱性を狙う通信を遮断している。それでも修正が必要な理由を頭の中で説明してみよう。

    答えを開く

    遮断は修正までの間の被害を減らす時間稼ぎで、脆弱性そのものは残る。修正の代わりにはならないので、修正は別に行う。
