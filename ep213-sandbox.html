#113 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

サンドボックス 隔離して動かして見る仕組みと限界

  1. 隔離環境でファイルを実行し、振る舞いで危険かを判定する。特徴が未登録の未知のマルウェアにも対応しうる。
  2. メールやWebの入口と連携し、検査中は配送を保留する。クラウド型はファイルを外部へ送るので、機密の扱いを確認する。
  3. 見抜く検体・待つ検体・パスワード付き圧縮は苦手で、通過は安全の証明ではない。端末側の対策と監視を重ねる。

用語カード

クイズ

  1. 動画で出た問題サンドボックスの説明として、適切なものは？

    1. 隔離した環境で実行する

    2. 未知にも対応しうる

    3. 見抜かれると動作しない

    4. 配送が遅れうる

  2. メールの入口にサンドボックスを導入した。検査中は添付付きのメールの配送が保留される。営業部から「重要な見積メールが届くのが遅い」と苦情が出た。運用上の対応として最も適切なものはどれか。

    1. サンドボックスは、既知を照合する方式を補う関係にある。遅延があっても、未知のマルウェアへの対応という役割をやめる理由にはならない。

    2. 検査中に配送を保留し、結果で配送か隔離かを決めるのが基本の流れ。結果を待たずに配送すると、検査が間に合わず利用者が開くおそれがある。

    3. 検査環境のOSやソフトは、実際の利用環境に合わせて用意する。環境を簡素にすると、利用環境と異なる動作になりうる。

    4. 正解。検査の遅延や誤検知には備えが要る。サンドボックスで判定できない場合もあるため、端末側の対策や監視を重ねる。

  3. 法務部は、機密の契約書案を含むファイルを頻繁にメールでやり取りする。メールの入口にサンドボックスを導入する際、クラウドで検査する型を選ぶ案が出た。判断として最も適切なものはどれか。

    1. 環境の破棄は、検査後に初期状態へ戻す話で、外部へ送るかどうかとは別。クラウド型は外部へ送るので、機密の扱いを確認する。

    2. 正解。クラウド型は検査のためにファイルを外部へ送る。機密を含む場合の扱いを、事前に確認して型を選ぶ。

    3. 社内に置く型は社内で検査する。外部へ送るのはクラウド型で、機密の扱いを比べる意味がある。

    4. 利用者の端末で開くと、端末が感染しうる。隔離した環境で動かすという目的に反する。

  4. メールの入口のサンドボックスを通過した添付ファイルを利用者が開き、数時間後に端末の感染が発覚した。調査では、そのファイルは一定時間が経つまで動作しない作りだったと判明した。判断として最も適切なものはどれか。

    1. 正解。一定時間や操作を待つ検体は、観察中に動かないことがある。動かなければ危険と判定できないので、端末側の対策や監視を重ねる。

    2. 振る舞いで判定するのは、観察中に動いたときだけ。動かない検体は判定できないので、通過したから危険でないとは断定できない。

    3. 既知を照合する方式は、特徴が未登録の新種を検出できない。サンドボックスはそれを補う関係で、置き換えれば解決するわけではない。

    4. 環境を利用環境に合わせるのは運用上必要だが、時間を待つ検体の問題は残る。完全に判定できるとは言えない。

  5. メールの添付は、パスワード付きの圧縮ファイルだった。入口のサンドボックスは異常を検出せず、そのまま配送した。この結果の解釈として最も適切なものはどれか。

    1. パスワード付きの圧縮は、中身を実行できない。通過しても、中身が観察済みとは限らず、安全と断定できない。

    2. 正解。パスワード付き圧縮などは中身を実行できず、検査の対象外になりうる。通過を安全の証明とせず、端末側の対策や監視で補う。

    3. 中身を実行できないことは、危険がないことを意味しない。中身が観察できていない点が、検査の限界として残る。

    4. サンドボックスは、特徴の照合ではなく、実行して振る舞いを見る方式。中身を実行できない圧縮は、観察できない場合がある。

  6. 新種と疑われる添付ファイルを調べた。検査環境のOSやソフトは利用者の端末と構成が異なっており、サンドボックス上では不審な通信が観察されなかったが、実際の利用者の端末では不審な通信が確認された。この差の説明として最も適切なものはどれか。

    1. 正解。検査環境と気付くと動作しない検体がある。検査環境のOSやソフトは、実際の利用環境に合わせて用意することが運用上の課題になる。

    2. 隔離は、実行しても本番へ影響を出さないための仕組み。環境を利用環境に合わせることと両立できるので、簡素にするのが望ましいとは言えない。

    3. 観察中に動かなかったことは、危険でない証明にならない。端末で実際に通信が確認された以上、誤検知と決めつけず、対応する。

    4. サンドボックスは特徴の照合ではなく、振る舞いで判断する。特徴の照合は、既知を照合する方式の説明である。

頭の中で考える

  1. サンドボックスが未知のマルウェアにも対応しうる理由と、既知を照合する方式との関係を頭の中で説明してみよう。

    答えを開く

    隔離した環境でファイルを実行して動作を観察し、特徴の照合ではなく振る舞いで危険かを判断する。そのため特徴が未登録の未知のマルウェアにも対応しうる。既知を照合する方式を補う関係であり、置き換えるものではない。

    思い浮かんだ要素にチェック

  2. サンドボックスを通過したファイルを安全と言い切れない理由を、限界の例を挙げて頭の中で説明し、どう備えるかも述べてみよう。

    答えを開く

    検査環境と気付くと動作しない検体、一定時間や操作を待って観察中に動かない検体、パスワード付き圧縮のように中身を実行できないものがあり、判定できないことがある。そのため通過を安全の証明とせず、端末側の対策や監視を重ねる。

よくある誤答

  • 定義ファイルの更新を、頻繁にする … すでに最新で、特徴の登録がない新種は検出できない
  • 利用者の端末で開き、動作を確認する … 開く前に判定する要件に反し、取引先を名乗る文書で端末が感染しうる
