#82 ・ 第7章 情報セキュリティ対策技術（3）暗号

電子文書の長期保存 時刻の証拠を付け直す

  1. 時間がたつと、証明書の期限切れ・失効情報の取得不可・暗号方式の危殆化で、署名の有効性を示しにくくなる。
  2. タイムスタンプは、TSAが発行する「ある時刻にデータが存在し、以降変更がない」証拠。それ自体にも有効期間がある。
  3. 長期署名は、署名にタイムスタンプと検証用の証明書・失効情報を加えて保存し、期限前に付け直す。方式の移行も要る。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題タイムスタンプの説明として、適切なのは？

    1. 暗号化の仕組みではない

    2. 作成者の確認ではなく、時刻と存在の証明

    3. 失効した証明書の一覧はCRL

    4. ある時刻に存在し、以降の変更がない

  2. 署名だけを付けて保存した電子文書がある。数年後、署名用の証明書の有効期間が切れた。この保存方法で困ることはどれか。

    1. 正解。証明書が期限切れになると、署名時点の有効性を後から示しにくい。

    2. 古い失効情報は公開が終わることもあり、保存しないと後で取得できないことがある。

    3. 期限が切れると、署名時点で証明書が有効だったことを後から示しにくく、改ざんの有無も変わらず示せるとはいえない。署名した時刻はタイムスタンプで示す。

    4. 暗号の方式は年月がたつと安全でなくなる。古い方式のままでは証拠の価値が下がる。

  3. 署名時にタイムスタンプを付けて保存している。そのタイムスタンプの有効期間の終わりが近づいてきた。適切な対応はどれか。

    1. タイムスタンプ自体にも有効期間がある。付け直さないと、保存の途中で切れる。

    2. 期限が切れた後では、元のタイムスタンプの有効性が途切れる。付け直しは期限が切れる前に、元の証拠と検証用の情報も含めて行う。

    3. 正解。期限の前に、元の証拠と検証用の情報も含めて付け直し、有効性を延長する。

    4. 署名用証明書とタイムスタンプは別の証拠で、それぞれ有効期間を持つ。タイムスタンプの期限は、期限前の付け直しで延長する。

  4. 保存開始から年月がたち、使っている暗号方式が安全でなくなる懸念が出てきた。適切な対応はどれか。

    1. 暗号方式は年月がたつと安全でなくなる。有効期間内でも、古い方式のままでは証拠の価値が下がる。

    2. 正解。方式が安全でなくなる前に、強い方式へ移行する。

    3. 対策は、方式が安全でなくなる前に強い方式へ移行すること。古い方式のままでは証拠の価値が下がる。

    4. 失効情報の保存は、検証に必要な情報を残す対策。古い方式のままでは証拠の価値が下がる点は変わらない。

  5. 契約書にタイムスタンプを付けた後、内容が1文字だけ書き換えられた疑いが出た。タイムスタンプの検証で分かることとして適切なものはどれか。

    1. データが一文字でも変わると、タイムスタンプの検証は失敗する。

    2. タイムスタンプは作成者の確認ではなく、ある時刻にデータが存在したことの証明。

    3. 正解。タイムスタンプは、ある時刻に存在し以降変更がないことを示す。変更があれば検証に失敗する。

    4. データが一文字でも変わると検証に失敗する。証明書の期限切れに限られない。

  6. 署名した契約書へのタイムスタンプ付与を、月末にまとめて行う運用になっている。見直し案として適切なものはどれか。

    1. 正解。タイムスタンプが示すのは、付与した時刻にデータが存在し以降変更がないこと。署名から間があくと、その間の状態を示せないので、署名の直後に付ける。

    2. ファイル名の日付は誰でも書き換えられ、第三者に示せる証拠にならない。時刻の証拠はTSAが発行するタイムスタンプで示す。

    3. 証明書が期限切れになると、署名時点の有効性を後から示しにくい。期限切れの後に付けても避けられない。

    4. 長期署名は、検証に必要な証明書・失効情報も一緒に保存する。失効情報は、保存しないと後で取得できないことがある。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 署名付きの契約書を長期間保存する。署名だけでなく何を足し、いつ何をすべきか頭の中で説明してみよう。

    答えを開く

    署名の直後にタイムスタンプを付け、検証に必要な証明書と失効情報を署名と一緒に保存する。タイムスタンプの期限が切れる前に付け直し、暗号方式が安全でなくなる前に強い方式へ移行する。

契約書の長期保存に関する調査記録（ダミー）
現状: 契約書の電子ファイルに署名を付けて、10年間保存する
署名用の証明書の有効期間は3年、タイムスタンプは5年である
署名時点の証明書と失効情報は、署名と一緒に保存できる
要件: 10年後も、署名時点から改ざんがないことを確認したい

要件を満たす方法として、適切なのは？

答えを開く

署名時にタイムスタンプを付けて情報も保存し、期限前に繰り返し付け直す

よくある誤答

  • 署名だけを付け、時刻の証明はせずに保存する … 署名した時刻を証明できず、証明書が切れた後は署名時点の有効性を示せない
  • 署名時にタイムスタンプを付け、そのまま10年保存する … 有効期間は5年で、10年保存なら期限前の付け直しが必要

本で読む

  • 7.7.5 電子文書の長期保存のための技術

署名だけでは長期に有効性を示せない理由（証明書の期限・失効情報・暗号方式）と、タイムスタンプの付け直しでの延長を確かめる。
