#101 ・ 第2章 情報セキュリティにおける脅威

脅威の分類 災害・障害・人の脅威と備え

  1. 脅威は災害・障害・人（偶発的と意図的）で整理でき、原因に合う備えを選ぶ。
  2. 災害と障害は主に可用性に影響し、人の脅威は機密性・完全性・可用性のすべてに関わりうる。
  3. UPSは短時間用、バックアップは復元用。分類は整理の道具で、事象は重なりうる。
用語カード 9クイズ 6考える 2午後問題本で読む

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題脅威の説明として、適切なものは？

    1. 誤操作は偶発的な脅威

    2. 地震や火災は災害に分類

    3. 故障は可用性を損なう

    4. 内部不正は意図的な脅威

  2. UPSを導入済みの事業所で、落雷による停電が数時間続き、サーバが停止した。評価として最も適切なものはどれか。

    1. 正解。UPSは停電を短時間しのぐための装置。長時間の停電には、拠点分散・遠隔地バックアップ・事業継続計画などで備える。

    2. 停電は災害に分類される。UPSの役割は短時間のしのぎで、数時間の停電で止まったことを機器の故障と決めつける根拠はない。

    3. 停電は外部の電力が止まることで、災害に分類される。人の行為が原因ではないので、教育中心の備えは原因に合わない。

    4. UPSは停電への備えで、機器内の部品の故障は防げない。容量を増やしても、その点は変わらない。

  3. 退職予定の担当者が、自分の権限で顧客データを大量に複製して持ち出した形跡がある。意図的な人の脅威への備えとして最も適切なものはどれか。

    1. 教育と確認手順は偶発的な脅威への備え。故意の持ち出しは、手順を知っていても行われうる。

    2. 正解。意図的な脅威には、最小権限・職務分離・ログで備える。

    3. バックアップは復元用で、複製を持ち出す行為（機密性の侵害）を防がない。

    4. 冗長化は機器の障害への備えで、権限を持つ人の持ち出しとは原因が違う。

  4. 共有フォルダのファイルを誤って削除する事故が月に数回起きている。原因は故意ではなく操作の誤りである。効果が見込める備えとして最も適切なものはどれか。

    1. 拠点分散は災害への備え。原因が操作の誤りの場合、拠点を分けても誤操作は防げない。

    2. 冗長化は機器の障害への備え。原因が故障ではなく操作なので、原因に合わない。

    3. ログによる抑止は意図的な脅威への備え。今回は故意ではない誤操作で、原因に合わない。

    4. 正解。偶発的な人の脅威には、教育と確認の手順で備える。

  5. 落雷による停電をきっかけに、ストレージ機器の不具合が生じて、一部のデータにアクセスできなくなった。この事象の扱いとして最も適切なものはどれか。

    1. UPSは停電を短時間しのぐ備えで、機器の不具合には効かない。重なった事象の片方だけを見ている。

    2. 冗長化は障害への備えだが、きっかけの停電には拠点分散や事業継続計画などの備えも要る。障害側だけでは足りない。

    3. 正解。分類は整理の道具で、事象は重なりうる。重なったときは両方に対する備えを組み合わせる。

    4. 重なる事象を一つに決められないからと、後から出た障害を切り捨てると、障害への備えが抜ける。

  6. 地震や水害を想定した遠隔地バックアップと拠点分散を整備した組織が、内部不正による情報の持ち出しと記録の書換えへの備えを問われた。評価として最も適切なものはどれか。

    1. 正解。災害と障害は主に可用性に影響する。人の脅威は機密性・完全性・可用性のすべてに関わりうるので、原因に合う別の備えが要る。

    2. バックアップは復元用で、書換えの復元に役立つ場合はあっても、持ち出し（機密性の侵害）は防げない。十分とは言えない。

    3. 拠点分散は災害への備え。権限を持つ人が持ち出す場合、拠点を分けても持ち出しは防げない。

    4. 人の脅威は機密性・完全性・可用性のすべてに関わりうる。可用性にだけ影響するという前提が誤り。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 人の脅威を「偶発的」と「意図的」に分けると、備えがどう変わるか。頭の中で説明してみよう。

    答えを開く

    偶発的（誤操作・紛失）は悪意がないので、教育と確認の手順で起きにくくする。意図的（内部不正）は故意に行われるので、最小権限・職務分離・ログで備える。原因が違えば備えも違う。

    思い浮かんだ要素にチェック

  2. 災害への備えとして、拠点の分散、遠隔地バックアップ、事業継続計画は、それぞれ何を担うか。頭の中で説明してみよう。

    答えを開く

    拠点の分散は、一つの拠点が被災しても他の拠点で続けられるようにする。遠隔地バックアップは、被災したときにデータを戻せるようにする。事業継続計画は、復旧の手順をまとめておく。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

動画の午後問題です。ログを読んで、答えを頭の中で決めてから開いてください。

業務停止の調査記録（ダミー）
サーバの電源部品が故障し、業務が止まった
サーバは1台のみで運用している
データは、毎日バックアップを取っていた
要件: 機器が1台故障しても、業務を止めたくない

このあとの対応として、適切なのは？

答えを開く

サーバを冗長化し、故障時に別の機器へ切り替える

よくある誤答

  • バックアップの頻度を上げる … バックアップはデータを戻すもので、故障中の業務は続けられない
  • 利用者への教育を強化する … 停止の原因は部品の故障で、利用者の操作ではない
