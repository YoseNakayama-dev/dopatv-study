#17 ・ 第2章 情報セキュリティにおける脅威

リバースブルートフォースとパスワードリスト攻撃 ロックで止まらない理由

  1. リバースブルートフォースは、パスワードを固定してIDを変えて試す。1アカウントの失敗が少なく、ロックに届かない。
  2. パスワードリスト攻撃は、別サービスで漏れた組の流用。前提は使い回しで、組が合えば1回で成功し、正規の入力に見える。
  3. 対策は多要素認証、使い回しの禁止、サイト全体の監視。どれも完全ではなく、層で守る。

用語カード

クイズ

  1. 動画で出た問題パスワードリスト攻撃への対策として、最も有効なのは？

    1. 1アカウントの失敗が少なく、届かない

    2. 使い回しをやめ、多要素認証を併用

    3. 短くすると、むしろ弱くなる

    4. 詳しい理由の表示は、攻撃者にも有利

  2. ログを調べたところ、IDが1つだけで、短時間に約3000種類の異なるパスワードが試され、ロックされていた。この試行の型として最も適切なものはどれか。

    1. それはリバースブルートフォース。ここではIDが固定されている。

    2. パスワードリスト攻撃は、IDとパスワードの組が1つずつ違う。1回の試行で成功しうる。

    3. 正解。IDを固定してパスワードを変える通常の型。同一アカウントの失敗が積み重なるので、ロックで止めやすい。

    4. ログイン試行のログが残っているので、当てはまらない。

  3. サイト側が、リバースブルートフォースを検知しやすくするための見方として、最も適切なものはどれか。

    1. 正解。見る単位をアカウントだけにせず、サイト全体や送信元でも見る。分散されると効きにくい点は残る。

    2. 1アカウントの失敗が1回程度なので、しきい値を少し下げても届かない。

    3. 永久ロックは正規の利用者を締め出す恐れがあり、検知の改善にもならない。

    4. 文言を分けると、IDの存在を攻撃者に教えてしまう。検知の改善にもならない。

  4. 利用者Aは、このサイト専用のパスワードを使っていて、他のサービスでは使い回していない。他のサービスから漏れた組を試す攻撃の評価として最も適切なものはどれか。

    1. 組が合わなければ成功しない。IDが一致するだけでは成功しない。

    2. 成立の前提は使い回し。多要素認証の有無だけで決まらない。

    3. この攻撃は組を1回ずつ試すので、失敗は積み重なりにくい。「必ず」も言い過ぎ。

    4. 正解。パスワードリスト攻撃が成り立つ前提は、使い回し。

  5. 送信元ごとの試行回数制限を導入した。攻撃が多数の送信元に分散して行われた場合の評価として最も適切なものはどれか。

    1. 正解。送信元の制限は、分散されると効きにくい。多要素認証や監視と重ねる。

    2. 「完全に防げる」は言い過ぎ。分散されると1送信元あたりの回数が少なくなる。

    3. 分散されると、1つの送信元あたりの失敗は減るので、検知しにくくなる。

    4. 使い回しをやめるのは利用者側の対策。送信元の制限とは別。

  6. パスワードリスト攻撃への対策として多要素認証を導入する。評価として最も適切なものはどれか。

    1. 導入と運用が要る。「一切ない」は言い過ぎ。

    2. 2要素目があれば、パスワードが一致しても、それだけでは成功しない。

    3. 正解。強い対策だが、コストがかかる。使い回しの禁止や監視と重ねる。

    4. どの対策も完全ではない。層で守る。

頭の中で考える

  1. 約3000のIDに各1回失敗し、試された文字列は全IDで同じだった。ロックが動かなかった理由を、頭の中で説明してみよう。

    答えを開く

    パスワードを固定してIDを変えるリバースブルートフォースが疑われる。ロックは同じアカウントの連続失敗を数えるが、1アカウントの失敗は1回程度でしきい値に届かない。送信元やサイト全体の失敗数も見る必要がある。

    思い浮かんだ要素にチェック

  2. パスワードリスト攻撃が成り立つ条件と、利用者側・サイト側の対策を、頭の中で説明してみよう。

    答えを開く

    別サービスから漏れたIDとパスワードの組を流用するので、利用者が使い回していることが前提。利用者は使い回しをやめ、サイトは多要素認証や漏えい済みパスワードの使用禁止、試行の監視や通知で守る。どれも完全ではない。

    思い浮かんだ要素にチェック
