#31 ・ 第2章 情報セキュリティにおける脅威

悪意あるモバイルコードとスパイウェア 閲覧だけで動く仕組みと対策

  1. モバイルコードはページ等とともに届き、端末で実行される。閲覧だけで動くことがあり、携帯端末とは無関係。
  2. 成立には、届き、実行環境が許し、その権限で動くことが要る。動いた権限が被害の上限になる。
  3. スパイウェアは気づかれずに情報を送る。更新・最小権限・通信の監視を重ねる。多要素認証にも限界がある。
用語カード 8クイズ 6考える 2午後問題本で読む

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題悪意あるモバイルコードへの対策として、適切なのは？

    1. 偽装を見抜きにくくなる

    2. 被害の上限が広がる

    3. 更新と、不要な機能の無効化

    4. 実行されるコードは止まらない

  2. 取引先の正規サイトだからと、Webフィルタの対象から外して運用している。この判断の評価として最も適切なものはどれか。

    1. 正解。正規サイトの改ざんでも届く。信頼だけを根拠にフィルタを外すのは危うい。

    2. 正規サイトでも、改ざんされればモバイルコードが届く。

    3. 最小権限は被害の上限を絞るもので、なくすものではない。「まったくなくなる」は言い過ぎ。

    4. モバイルコードは閲覧しただけで動くことがあり、ファイルの実行は必須ではない。

  3. スパイウェアが入力内容を暗号化した通信で外部に送っている。監視の考え方として最も適切なものはどれか。

    1. 暗号化されると、通信の中身を見て判断しにくい。内容の監視だけに頼れない。

    2. 暗号化されていることは正規である根拠にならない。外す理由がない。

    3. 暗号化されると中身で判断しにくいという前提を読み落としている。

    4. 正解。外部通信の監視に加え、送信先の制限を併用する。

  4. 入力内容が盗まれる場合に備え、多要素認証を導入する。評価として最も適切なものはどれか。

    1. 中継型の攻撃には効かない場合がある。「すべて防げる」は言い過ぎ。

    2. 正解。入力内容だけでは使えなくする効果があるが、限界もある。

    3. 感染を防ぐ対策ではなく、盗まれた入力内容を使えなくする対策である。

    4. 1つで防げないので、重ねて使う。更新・最小権限・通信の監視なども併用する。

  5. 「モバイルコード」という用語の説明として、最も適切なものはどれか。

    1. 正解。ページやメールとともに届き、端末（実行環境）で実行される。携帯端末とは無関係。

    2. 携帯端末とは無関係。名前から連想して取り違えやすい。

    3. ページ・メールとともに届くプログラムを指す。持ち運んだファイルの話ではない。

    4. 自分で移動して増えるのはワームの説明で、モバイルコードの定義ではない。

  6. 閲覧用端末を管理者権限で常用している。モバイルコードが実行された場合の評価として最も適切なものはどれか。

    1. 実行を許すかは、脆弱性や設定で決まる。管理者権限だからといって許さなくなる根拠はない。

    2. 動いた権限が被害の上限になる。権限は被害の大きさに関わる。

    3. 権限が広いほど上限が広がる。検出されやすくなるという根拠はない。

    4. 正解。だから最小権限で閲覧して、上限を絞る。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. モバイルコードが「閲覧しただけで」被害に至る成立条件を、順に頭の中で説明してみよう。

    答えを開く

    ①コードがページなどとともに実行環境に届く。②実行環境が脆弱性や設定のために実行を許す。③その権限で動く。動いた権限が被害の上限になる。正規サイトが改ざんされても届く。

    思い浮かんだ要素にチェック

  2. スパイウェアによる情報の流出に備える対策を、予防と検知の観点で挙げ、限界も説明してみよう。

    答えを開く

    予防は、ブラウザやプラグインの更新、不要な実行機能の無効化、不審なソフトを入れないこと。検知は、対策ソフトと外部通信の監視・送信先の制限。通信が暗号化されると中身で判断しにくく、多要素認証も中継型には効かない場合があるので、重ねて使う。

午後問題にチャレンジ

動画の午後問題です。ログを読んで、答えを頭の中で決めてから開いてください。

営業端末の調査記録（ダミー）
対象: 営業担当の端末（ダミー）。取引先の情報サイト（正規）を閲覧しただけ
閲覧したページに、悪意あるスクリプトが含まれていた（利用者が実行したファイルはなし）
閲覧時、ブラウザのプラグインは修正プログラム未適用の旧版で動作 / 既知の脆弱性を突かれた
その後、常駐プロセスが生成され、入力内容が外部の宛先へ定期送信
// 常駐プロセスの動作は、入力内容の収集と送信のみ / 利用者のファイルは変更されず、要求の表示もなし

この事象の原因として、適切なのは？

答えを開く

閲覧で実行された悪意あるモバイルコードが、旧版プラグインの脆弱性を突き、スパイウェアを動かした

よくある誤答

  • トロイの木馬 … 動いたのはページ内のスクリプトで、利用者が実行したファイルはない
  • ランサムウェア … 動作は入力内容の送信のみで、ファイルは変更されていない

本で読む

  • 2.9.5 悪意あるモバイルコード
  • 2.9.6 スパイウェア

モバイルコードが動く条件（届く・許される・権限）と、スパイウェアの収集・送信を、各対策の限界とあわせて読む。
