#69 ・ 第6章 情報セキュリティ対策技術（2）アクセス制御と認証

ディレクトリサービスとEAP 名簿と入口を整える

  1. ディレクトリは利用者・機器の情報を一元管理しLDAPで参照する。通信は暗号化し、匿名の参照は制限する。
  2. EAPは認証方式を差し替える枠組みで802.1Xで使う。EAP-TLSは証明書の配布が要り、PEAPはパスワード認証を続ける。
  3. PEAPは端末がサーバ証明書を検証しないと偽の親機に渡しうる。管理者権限は奪われると影響が全体に及ぶ。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ディレクトリサービスの説明として、適切なのは？

    1. 一元管理し、LDAPなどで問い合わせ

    2. 端末ごとでなく、一元管理する

    3. 利用者の情報を管理する

    4. 属性やグループも扱える

  2. PEAPで無線LAN認証を行っているが、端末側でサーバ証明書の検証が無効になっている。このときの問題として最も適切なものはどれか。

    1. PEAPなどでは端末にサーバ証明書を検証させる必要があり、検証しないと偽の親機に資格情報を渡しうる。

    2. 正解。端末がサーバ証明書を検証しないと、偽の親機に資格情報を渡しうる。

    3. PEAPはサーバ証明書で保護した中でパスワード認証を行い、端末側の準備が軽い。端末への証明書の配布が要るのはEAP-TLSである。

    4. 802.1Xの認証装置は、認証の結果が出るまで通信を通さない。

  3. 802.1XとEAPで無線LANを構成する。認証結果が出るまで端末の通信を通さない機器と、認証サーバについての説明の組合せとして適切なものはどれか。

    1. サプリカントは認証を受ける側の端末で、通信を通さない役割は認証装置が担う。

    2. 通信を通さない役割は認証装置で、認証サーバではない。RADIUSは認証サーバとしてよく使われる。

    3. LDAPはディレクトリを参照するプロトコルで、802.1Xの認証サーバにはRADIUSがよく使われる。

    4. 正解。認証装置は結果が出るまで通信を通さず、認証サーバにはRADIUSがよく使われる。

  4. EAP-TLSで無線LANに接続している。従業員が証明書を導入した端末を紛失した。対応として最も適切なものはどれか。

    1. パスワードを使わないEAP-TLSでも、紛失した端末の証明書は失効させる必要がある。

    2. パスワードを変えても、証明書で認証するEAP-TLSでは証明書自体は無効にならない。証明書が有効なままだと、紛失した端末から接続されるおそれが残るため、証明書を失効させる。

    3. 正解。紛失した端末の証明書は失効させる。

    4. 管理者を絞って操作を記録するのは管理者権限への対策で、紛失した端末の証明書の扱いとは別である。

  5. 社内アプリがLDAPでディレクトリに問い合わせている。通信は暗号化されておらず、認証なしの匿名参照も許可されている。見直し方針として最も適切なものはどれか。

    1. 暗号化されていないLDAPの通信は途中で内容を読まれうる。匿名参照を許すと、認証なしでディレクトリの情報を引き出される。通信は暗号化し、匿名の参照は制限する。

    2. 正解。LDAPの通信は暗号化し、匿名の参照は制限する。

    3. 管理者を絞って操作を記録するのは管理者権限への対策で、LDAPの暗号化や匿名参照の制限の代わりにはならない。

    4. EAP-TLSは認証方式を差し替える枠組みEAPの一方式で、ディレクトリを参照するLDAPの通信保護とは別の話である。

  6. ディレクトリサービスで利用者・機器の情報を一元管理している。管理者権限の扱いとして適切なものはどれか。

    1. 管理者権限は、奪われると影響が全体に及ぶ。

    2. 情報は階層的に整理されているが、管理者権限が奪われると影響は全体に及ぶ。

    3. 管理者は絞り、操作を記録する。

    4. 正解。管理者を絞って操作を記録する。管理者権限は奪われると影響が全体に及ぶ。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. PEAPの無線LANで、端末にサーバ証明書の検証をさせないとどうなるか、どう防ぐかを頭の中で説明してみよう。

    答えを開く

    端末が偽の親機を正規のものと区別できず、パスワードなどの資格情報を渡してしまうおそれがある。PEAPなどでは端末にサーバ証明書を検証させる。

    思い浮かんだ要素にチェック

  2. ディレクトリサービスで利用者情報を一元管理する利点と、運用上の注意を、頭の中で説明してみよう。

    答えを開く

    認証や認可の判断に同じ情報を使い回せ、異動や退職の反映も一か所で済む。注意として、LDAPの通信は暗号化して匿名の参照は制限し、管理者権限は奪われると影響が全体に及ぶので、管理者を絞って操作を記録する。

無線LAN認証の見直しに関する調査記録（ダミー）
現状: 無線LANは、全員共通の事前共有鍵で接続している
退職者も鍵を知っており、鍵の変更は全端末の再設定が要る
全端末は管理下で証明書を導入でき、親機は802.1Xに対応する
要件: 利用者ごとに認証し、パスワード入力は求めない

要件を満たす方式として、適切なのは？

答えを開く

802.1XとEAP-TLSを使い、証明書で端末とサーバが互いに確認する

よくある誤答

  • 共通の事前共有鍵を、毎月変更する … 共通のままで、利用者ごとの認証にならない
  • PEAPで、利用者のパスワードを送って認証する … パスワードの入力を求めない要件を満たさない
