#115 ・ 第6章 情報セキュリティ対策技術（2）アクセス制御と認証

バイオメトリック認証 仕組み・誤り・方式の特徴

  1. 生体認証は読み取りが毎回一致しないため、類似度がしきい値以上かで判定する。
  2. しきい値を厳しくすると他人受入率は下がり本人拒否率は上がる。両方を同時にゼロにはできない。
  3. 特徴は変えられないので保管を厳重に。写真や模型には生体検知、拒否には代替手段で備える。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題生体認証の説明として、適切なものは？

    1. それは他人受入率

    2. 厳しくすると他人受入率は下がる

    3. 容易に変更できない

    4. 静脈は体内の血管

  2. 社内の入退室で、他人が誤って受け入れられる事例が複数起きた。生体認証システムの運用担当として、まず検討する対応として最も適切なものはどれか。

    1. しきい値を緩めると他人受入率は上がる。誤受入れを抑えたいなら逆向きの調整になる。

    2. 正解。厳しくすると他人受入率は下がるが、本人拒否率は上がる。用途に応じて調整し、拒否に備えて代替手段を用意する。

    3. 厳しくすると本人拒否率は上がる。二つの誤りはトレードオフなので、副作用を考えないのは誤り。

    4. 登録をやり直しても、両方を同時にゼロにはできない。しきい値の調整で釣り合いを取る。

  3. 認証サーバの保守担当が、登録済みの指紋の特徴情報を、平文のままバックアップ媒体に保存していた。この点への指摘として最も適切なものはどれか。

    1. 生体の特徴は変えられない。漏えいすると取り返しがつかないので、影響は小さくない。

    2. 特徴情報は漏えいすると取り返しがつかない。画像そのものでないことは、保管を緩めてよい理由にならず、厳重な保管が要る。

    3. 正解。特徴は変更できず、漏えいの影響が大きい。登録した特徴情報は、暗号化するなどして厳重に保管する。

    4. 生体検知は写真や模型の提示に備える機能で、保存した情報の漏えいを防ぐものではない。

  4. 冬に指が乾燥して、指紋認証の勤怠端末で本人が何度も拒否される苦情が増えた。他人の不正打刻は今のところ見られない。対応として最も適切なものはどれか。

    1. 正解。指紋は乾燥・汚れ・傷で不安定になる。拒否に備えて代替手段を用意し、他人受入率とのバランスを見てしきい値を調整する。

    2. 最も緩くすると本人拒否は減るが、他人受入率が大きく上がる。不正打刻が今ないことは、緩めてよい理由にならない。

    3. 顔は照明や経年変化に弱いという別の弱点がある。方式を変えても誤りがなくなるわけではない。

    4. 方式を変えても、二つの誤りのトレードオフは残る。調整なしに両方を同時に下げられるとは言えない。

  5. ゲートAは社員証でIDを示してから顔を、そのIDの登録情報1件とだけ照合する。ゲートBはIDを示さず、顔を全登録者の情報と照合する。説明として最も適切なものはどれか。

    1. 正解。IDを示して1件と照合するのが1対1、全件から探すのが1対N。読み取りは毎回一致しないので、どちらも類似度で判定する。

    2. 1対1と1対Nが逆になっている。IDを示すのは1対1で、全件から探すのは1対N。

    3. 読み取りは毎回まったく同じにはならないので、完全一致を条件にはできない。類似度としきい値で判定する。

    4. 照合の方法そのものが違う。IDを示すと1件との照合になり、示さなければ全件から探すことになる。

  6. 導入候補の顔認証製品の資料に「他人受入率0%」とあった。導入担当が次に確認すべきこととして最も適切なものはどれか。

    1. 他人受入率は他人が誤って通る割合。写真などの提示は別の問題で、生体検知で備える。数値が良くても確認は要る。

    2. 二つの誤りはトレードオフで、片方が極端に低いなら、しきい値が厳しく本人拒否率が高い可能性がある。

    3. しきい値を厳しくして他人受入率を下げたなら、本人拒否は起きやすくなる。拒否に備えた代替手段は、むしろ必要になる。

    4. 正解。他人受入率が低いのは、しきい値を厳しくした結果かもしれない。そのときの本人拒否率とあわせて評価する。

顔認証の入室管理の記録（ダミー）
入室管理: 顔のみで判定し、特徴量が一致すれば許可
先週、他人が登録者の顔写真を示し、入室できた
示された写真の顔は、登録者の顔と一致していた
しきい値は適切で、本人拒否はほとんどない
要件: 利用者の操作を増やさず、写真で入れなくする

適切な対策は、どれ？

答えを開く

生体検知で、実物の顔かを判定する

よくある誤答
