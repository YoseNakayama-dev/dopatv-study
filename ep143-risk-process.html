#43 ・ 第4章 情報セキュリティマネジメントの実践

リスクマネジメントのプロセスとリスク対応 残留リスクを管理する

  1. プロセスは、組織の状況の確定→リスクアセスメント→リスク対応。監視・レビューと協議は全体を通す。
  2. 対応の目的は、リスクを受容できる水準にすること。費用と効果を比べて選び、ゼロにはならない。
  3. 対応後に残留リスクが残る。再評価し、計画と受容はリスク所有者が承認し、繰り返し見直す。

  1. 動画で出た問題「残留リスク」の説明として、適切なのは？

    1. それは対応前のリスク

    2. リスクはゼロにならない

    3. 対応後も残るリスク

    4. 見積もりの有無とは別の話

  2. 新たにリスクマネジメントを始める組織で、リスクの受容基準を決める作業が必要になった。プロセスのどの段階で行うのが適切か。

    1. 正解。目的・範囲・基準（受容基準など）は、最初の組織の状況の確定で決める。

    2. リスク評価は、算定した大きさを基準と比べる段階。基準は先に決めておく。

    3. 対応は、評価の結果に基づいて選ぶ段階。基準はその前に決める。

    4. 監視・レビューは対策の効果と残留リスクの変化を確かめる段階で、基準を初めて決める場ではない。

  3. リスク対応案が2つある。案Aは費用が年100万円で、損失が年400万円減る。案Bは費用が年600万円で、損失が年80万円減る。選び方として適切なのはどれか。

    1. 目的はゼロにすることではなく、受容できる水準にすること。費用と効果を比べて選ぶ。

    2. どんな対策をしてもリスクはゼロにならない。対応後は残留リスクを再評価する。

    3. 対応後に残留リスクが残るのは避けられない。再評価して受容できるかを確かめる。

    4. 正解。対応は費用と効果を比べて選び、効果を上回る費用がかかる対策は選ばない。

  4. リスク対応計画（何を・誰が・いつまでに行うか）を作成した。顧客DBのリスク所有者は情報システム部長で、運用は担当者が行う。計画の承認と残留リスクの受容について、適切なのはどれか。

    1. 受容を決めるのはリスク所有者。担当者の判断で済ませない。

    2. 正解。リスクの責任と権限をもつリスク所有者が、計画を承認し、受容を決める。

    3. リスク対応計画は、リスク所有者の承認を得る。

    4. 承認するのはリスク所有者。評価結果の確認では代わりにならない。

  5. 対応計画の承認から半年後、環境が変わり新しい脅威が報告された。適切な対応はどれか。

    1. 正解。環境や脅威は変わるので、プロセスは繰り返して見直す。監視・レビューで残留リスクの変化を確かめる。

    2. 環境や脅威は変わるので、承認済みでも残留リスクの変化を確かめ続ける。

    3. 監視・レビューは対策の効果と残留リスクの変化を確かめるもので、全体を通して行う。

    4. 環境や脅威が変わるため、プロセスは繰り返して見直す。前の結果をそのまま使い続けない。

  6. 経営層から「対策を実施すればリスクはゼロにできるはずだ」という意見が出た。説明として適切なのはどれか。

    1. 費用をかけても、リスクはゼロにできない。受容基準は必要。

    2. 対応後に残るのは残留リスクで、避けられない。誤りの証拠ではなく、再評価して受容できるか確かめる。

    3. 目的は受容できる水準にすること。手法は低減だけではない。

    4. 正解。どんな対策でもリスクは残る。受容できる水準にし、残留リスクを再評価して管理する。

頭の中で考える

  1. リスクマネジメントのプロセスを、順序と「全体を通して行うもの」に分けて、頭の中で説明してみよう。

    答えを開く

    組織の状況の確定（目的・範囲・基準）→リスクアセスメント（特定・分析・評価）→リスク対応の順。監視・レビューと、関係者とのコミュニケーション・協議は、全体を通して行う。環境や脅威は変わるので反復して見直す。

    思い浮かんだ要素にチェック

  2. 対応後の再評価で基準以内に収まった。このあとやるべきことを、頭の中で説明してみよう。

    答えを開く

    対応後に残る残留リスクとして、受容できるかを確かめ、リスク所有者の承認を得る。計画は何を・誰が・いつまでにを明確にする。そのうえで監視・レビューを続け、環境や脅威の変化に合わせて見直す。

午後問題にチャレンジ

顧客DBのリスク対応記録（ダミー）
対象: 顧客DBのリスクX（ダミー）。年間予想損失額は600万円
受容基準は300万円。アクセス制御の強化後、再評価で100万円
追加の対策案: 費用は年500万円。損失の減少は年50万円
役割: 顧客DBのリスク所有者は、情報システム部長。運用は担当者が行う
来期に、クラウドへの移行を予定している

対応を実施したあとの手順として、適切なのは？

答えを開く

残留リスクの受容についてリスク所有者の承認を得て、監視・レビューを続ける

よくある誤答

  • 追加の対策でゼロ … 年500万円の費用に対し減少は50万円
  • 担当者が受容を決める … 役割: リスク所有者は部長。運用は担当者

本で読む

  • 4.2.1 リスクマネジメントのプロセス
  • 4.2.2 リスク対応の概要

プロセスの順序と全体を通す活動を整理し、対応の目的（ゼロではなく受容できる水準）、残留リスク、リスク所有者の役割を確かめながら読む。
