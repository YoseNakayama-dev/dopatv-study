#106 ・ 第3章 情報セキュリティにおける脆弱性

ネットワーク構成の脆弱性 区画・公開・経路・障害

  1. ネットワーク構成には、区画の分割なし・不要な公開・平文の通信・単一障害点という弱点が潜む。
  2. 構成図と実態のずれ、境界を通らない経路、管理通信の共用、期限なく残る許可は見えにくい弱点になる。
  3. 区画を分け、区画間は必要な通信だけ許可する。許可した通信は通るので、構成図の維持と見直しが要る。

用語カード

クイズ

  1. 動画で出た問題弱点と対策の組合せとして、適切なものは？

    1. 区画を分け、必要な通信だけ許可

    2. 単一障害点は冗長化で対処

    3. 平文は暗号化で対処

    4. 不要なポートは閉じる

  2. 保守用の遠隔監視機器が、基幹サーバと同じネットワークにある。機器が侵入された場合に、基幹サーバへ広げにくくする見直しとして最も適切なものはどれか。

    1. 暗号化は盗聴や改ざんへの対策。機器が侵入された後の広がりを抑える対策ではない。

    2. VLANで分けただけでは通信は絞れない。区画間で許可する通信を、規則で決める必要がある。

    3. 正解。区画を分け、区画間は必要な通信だけ許可することで、侵入後の広がりを抑える。

    4. 冗長化は単一障害点をなくす対策で、侵入後の広がりは抑えられない。

  3. 現地調査で、構成図に載っていない無線のアクセスポイントが社内LANにつながっていた。境界のファイアウォールの規則は厳格に設定済みである。この状況の評価として最も適切なものはどれか。

    1. 正解。無許可の無線や保守回線は境界を通らない経路になり、境界のファイアウォールはその通信を見ていない。

    2. その通信は境界のファイアウォールを通らないので、規則の厳しさとは関係なく制御の対象にならない。

    3. 把握していない機器は守れない。暗号化があっても、境界を通らない経路という弱点は残る。

    4. 構成図の更新は把握に必要だが、更新しただけでは境界を通らない経路は残る。把握したうえで対処が要る。

  4. 運用管理の画面が、業務用ネットワークと同じ経路上にあり、全端末から接続できる。管理者は日常的にこの画面を使う。見直しとして最も適切なものはどれか。

    1. 人数を増やしても、業務側が侵害されると管理側に届きやすいという状況は変わらない。

    2. 暗号化は盗聴や改ざんへの対策。経路と接続元がそのままでは、業務側の侵害が管理側に届きやすい弱点が残る。

    3. 業務用を暗号化しても、管理用の経路は共用のまま。接続元も絞れていない。

    4. 正解。管理は専用の経路に限り、管理を行える接続元も絞る。管理用の通信は権限が強いので暗号化もする。

  5. 3年前の移行作業のために開けた、特定の外部アドレスからの接続を許可する規則が残っている。移行は完了しているが、担当者が異動し、規則を残した理由が分からない。対応として最も適切なものはどれか。

    1. 一時的な許可が期限なく残ると、そのまま弱点になる。理由が不明なまま残すのは弱点を放置することになる。

    2. 正解。目的を終えた一時的な許可は、変更管理と定期的な見直しの対象。不要なら削除する。

    3. 記録を取るだけでは、期限なく残る許可という弱点そのものは残る。

    4. 確認は見直しの一部だが、移行が完了して目的がなくなった許可を残す理由にはならない。

  6. 経理サーバを別の区画に置き、区画間は経理システムの通信だけを許可した。その後、営業部の端末が感染し、許可した通信を経由して経理サーバに影響が及んだ。この事象の説明として最も適切なものはどれか。

    1. 分割は、必要な通信だけ許可して広がりを抑える対策。許可した通信は通るという限界はあるが、効果がないとは言えない。

    2. 問題になっているのは区画間で許可した通信。境界の規則を強化しても、許可した通信は通る。

    3. 正解。許可した通信は通るのが限界。許可の範囲を絞り、構成図の維持と見直しを続ける。

    4. 同一ネットワークに戻すと、一台の侵入が内部へ広がりやすい弱点が戻ってしまう。

頭の中で考える

  1. 区画を分けただけでは安心できない理由を、頭の中で説明してみよう。

    答えを開く

    分けただけでは通信は絞れないので、区画間は必要な通信だけ許可する規則が要る。さらに許可した通信は通るので、感染した端末がその通信を使う可能性は残る。許可範囲を絞り、構成図の維持と定期的な見直しを続ける。

    思い浮かんだ要素にチェック

  2. 無許可の無線や保守回線が弱点になる理由と、構成図の維持が必要な理由を、頭の中で説明してみよう。

    答えを開く

    境界を通らない経路になり、境界のファイアウォールはその通信を見ていない。構成図や機器の一覧が実態と違うと、存在を知らない機器は守れない。構成図の維持、変更管理、定期的な見直しで把握し続ける。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

社内ネットワークの構成記録（ダミー）
営業部の端末1台が感染。社内は全機器が同一ネットワーク
経理サーバも同じ。全端末から直接通信できる
境界のFWは設定済み。バックアップは毎日取得済み
要件: 経理サーバへ、感染を広げにくくしたい

構成の見直しとして、適切なのは？

答えを開く

経理サーバを別のセグメントに置き、必要な通信だけ許可する

よくある誤答

  • 境界のFWの規則を厳しくする … 感染は社内で広がり、その通信は境界のFWを通らない
  • バックアップの頻度を上げる … 復旧の手段で、感染の広がりは抑えられない

本で読む

  • 3.2.1 ネットワーク構成における脆弱性
  • 3.2.2 ネットワーク構成における脆弱性への対策

構成そのものの弱点と見えにくい弱点を整理し、区画分割の限界（許可した通信は通る）まで確かめながら読む。
