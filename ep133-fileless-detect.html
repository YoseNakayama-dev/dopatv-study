#33 ・ 第2章 情報セキュリティにおける脅威

ファイルレス攻撃とマルウェアの検出手法 ファイルがなくても見つける

  1. ファイルレス攻撃は、ディスクに実行ファイルを置かず、メモリ上やOS標準のツールで動く。完全にファイルなしとは限らない。
  2. ファイルを照合する検査には対象が見当たらない。検出手法はそれぞれ得意な範囲が違い、単独では足りない。
  3. 見る対象をファイルからプロセスの動作と通信へ変え、手法を組み合わせる。誤検知と見逃しは残る。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ファイルレス攻撃の検出に、有効なのは？

    1. 更新を増やしても、照合するファイルがない

    2. ファイルが置かれないので、変化もない

    3. 標準ツールは、実行ファイルを増やさない

    4. 動作と通信を見る

  2. 経理部の端末で、定期スキャンは検出なしだったが、OS標準のスクリプト実行機能が外部と通信していた。ディスク上に新しい実行ファイルはない。次の調査の観点として最も適切なものはどれか。

    1. 正解。見る対象を、ファイルからプロセスの動作と通信に変える。

    2. 更新を増やしても、照合するファイルが見当たらない。

    3. OS標準の正規ツールが悪用されることがある。正規のツールだから通信も正規、とは言えない。

    4. 初期侵入にファイルが使われる例がある。「断定」は言い過ぎ。

  3. 未知の添付ファイルをサンドボックスで実行したが、不審な挙動は観察されなかった。評価として最も適切なものはどれか。

    1. 環境を見抜かれると回避される。無観察を安全の証拠にはできない。

    2. 正解。サンドボックスは隔離環境で実行して観察する仕組みで、見抜かれると回避される。

    3. 隔離して観察しても、環境を見抜かれると回避される。「可能性はない」は言い過ぎ。

    4. 変更検知はハッシュ値を基準と比べる手法で、実行して観察するサンドボックスとは別の仕組み。

  4. OS標準ツールの悪用が疑われる端末で、変更検知を行ったところ、既存ファイルのハッシュ値は基準と一致していた。評価として最も適切なものはどれか。

    1. ファイルが置かれなければ変化も生じない。一致は侵害がない証拠にならない。

    2. 端末の動作を記録するのはEDR。変更検知はハッシュ値を基準と比べる手法である。

    3. 正解。ファイルが置かれない攻撃では、比べる変化が生じない。

    4. 手法は単独では完全ではなく、得意な範囲が違う。組み合わせて使う。

  5. 標準ツールがいつ、どのような使われ方をしたかを、端末上の動作の記録からさかのぼって調べたい。使う仕組みとして最も適切なものはどれか。

    1. 正解。EDRは端末上の動作を記録し、検知と調査に使う。

    2. ファイルとの照合方式で、動作の記録は残らない。

    3. 隔離環境で実行して観察する仕組みで、実際の端末での動作の記録ではない。

    4. ファイルのハッシュ値の変化を見る手法で、動作の記録ではない。

  6. 標準ツールの不審な使われ方を見る振る舞い検知を導入したところ、管理者の正規作業でも警報が多数出た。対応として最も適切なものはどれか。

    1. ファイルが見当たらない場合、パターンマッチングは見つけにくい。止めると見る範囲が狭まる。

    2. 正解。正規の使い方に似ていると誤検知と見逃しが残る。手法を組み合わせ、疑わしい動作は隔離と調査の流れで扱う。

    3. 正規の使い方に似ていると見逃しも残る。警報の内容だけでは見逃しの有無は判断できない。

    4. 正規の使い方に似ていると、誤検知も見逃しも残る。「なくなる」は言い過ぎ。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. ファイルレス攻撃がパターンマッチングで見つかりにくい理由と、代わりに見る対象を、頭の中で説明してみよう。

    答えを開く

    パターンマッチングは既知の特徴とファイルを照合する方式で、ディスクに実行ファイルを置かないファイルレス攻撃には、照合する対象が見当たらない。そこで、見る対象をファイルからプロセスの動作と通信に変え、標準ツールの使われ方を確かめる。

  2. ファイルレス攻撃への備えで、検出手法を組み合わせる理由と、組み合わせても残る限界、疑わしい動作が出たときの流れを説明してみよう。

    答えを開く

    手法ごとに得意な範囲が違い、単独では完全ではないため、パターンマッチング・振る舞い検知・EDRなどを組み合わせる。正規の使い方に似ていると誤検知と見逃しが残る。疑わしい動作が出たら、端末を隔離して調べる流れを用意する。

経理部端末の調査記録（ダミー）
対象: 経理部の端末（ダミー）。定期スキャンは、検出なし
同時刻、OS標準のスクリプト実行機能が起動し、外部へ通信
ディスク上に新しい実行ファイルは作られていない（監査ログ）
定期スキャンは、ディスク上のファイルを、パターンファイルと照合
パターンファイルは最新で、スキャンの除外設定はなし

定期スキャンで検出できなかった理由として、適切なのは？

答えを開く

新しい実行ファイルがなく、ファイルを照合する方式では、見つけられなかった

よくある誤答

  • パターンファイルが古かった … 最新だった
  • 除外設定に入っていた … 除外設定はなし
