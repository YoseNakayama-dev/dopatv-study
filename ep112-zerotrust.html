#12 ・ 第1章 情報セキュリティ及びITの基礎

ゼロトラスト 場所を信頼しない考え方

  1. ゼロトラストは、ネットワークの位置や機器の所有だけでは暗黙の信頼を与えず、リソースの保護に重点を置く考え方。
  2. アクセスはセッション単位で最小権限を与え、ID・資産状態・振る舞い・環境の動的ポリシーで判断する。
  3. 製品を入れただけでは完成しない。収集した情報は改善に使う。実現方式は別の回で扱う。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ゼロトラストの考え方として適切なのは？

    1. 位置による暗黙の信頼は与えない

    2. 位置だけでは信頼せず、リソースごとに許可

    3. リソースごと・セッションごとに許可

    4. 導入しただけでは完成しない

  2. 社内LANに接続した会社支給のPCは、追加の確認なしに、複数の業務システムを利用できる設計になっている。ゼロトラストの観点の評価として最も適切なものはどれか。

    1. 誤り。位置と機器の所有だけでは、暗黙の信頼を与えない。内側の機器も同じ要件で評価する。

    2. 誤り。利用者の確認だけでは足りない。機器の状態も踏まえて、リソースごとに許可を判断する。

    3. 誤り。社内か社外かによらず、すべての要求を同じ要件で評価する。

    4. 正解。ネットワークの位置や機器の所有だけでは、暗黙の信頼を与えない。

  3. 判定ログに次の順で記録されていた。(1) ある利用者の要求の許可を取り消す判断、(2) 該当セッションの経路を遮断する指示、(3) 接続の終了。(1) の判断を行ったコンポーネントはどれか。

    1. 正解。PEが、許可・拒否・取り消しの最終判断を行う。

    2. 誤り。PAはPEの判断に従い、経路の確立・遮断を指示する。(2) に当たる。

    3. 誤り。PEPは接続の有効化・監視・終了を行う。(3) に当たる。

    4. 誤り。NISTの文書が示す3つの役割に含まれない。

  4. 夜間に普段と異なる環境から、OSの更新が止まった端末で重要システムへの接続要求があった。ゼロトラストの考え方に沿った対応として最も適切なものはどれか。

    1. 誤り。IDとパスワードだけでなく、端末の状態や環境も判断材料にする。

    2. 誤り。社内からの接続でも、位置だけで信頼しない。

    3. 正解。動的ポリシーで、ID・資産状態・振る舞い・環境属性を踏まえて判断する。

    4. 誤り。一律拒否の静的なルールではなく、状況に応じて動的に判断する。

  5. データの多くが社外のクラウドにあり、社員は在宅で働き、私物の端末も使う。社内ネットワークの境界を固める投資だけで守る方針の評価として最も適切なものはどれか。

    1. 誤り。境界だけでは、社外のクラウドや私物端末の通信を社内と同じ強さで守れない。

    2. 正解。リモートワーク、BYOD、社外のクラウドで境目があいまいになった。リソースの保護に重点を置く。

    3. 誤り。禁止しても、境界の外にある資産やクラウドは残る。考え方が不要になるわけではない。

    4. 誤り。ネットワークの位置によらず通信を保護し、アクセスごとに評価する。暗号化だけでは足りない。

  6. ある組織は、資産の状態やネットワーク、通信の情報を集めて保管しているが、ポリシーの見直しにはまったく使っていない。NIST SP 800-207 の考え方に沿った評価として最も適切なものはどれか。

    1. 正解。資産・ネットワーク・通信の情報は、集めて態勢の改善に使う。

    2. 誤り。集めるだけでは足りず、改善に使うことが前提になっている。

    3. 誤り。判断は動的ポリシーで行う。固定して反映させない運用は考え方に合わない。

    4. 誤り。IDだけでなく、資産の状態や通信の情報も収集して改善に使う。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 「社内ネットワークの中なら安全」とみなす設計の問題点と、ゼロトラストでの考え方の違いを、頭の中で説明してみよう。

    答えを開く

    境界防御は中を信頼するので、一度中に入られると中では広く動かれうる。ゼロトラストは位置や機器の所有だけでは暗黙の信頼を与えず、リソースごと・セッションごとに、最小権限と動的ポリシーで許可を判断する。

    思い浮かんだ要素にチェック

  2. 利用者の要求が来てから接続が成立するまでを、PE・PA・PEP の役割で、頭の中で説明してみよう。

    答えを開く

    PEが許可・拒否・取り消しを最終判断する。PAがPEの判断に従い、経路の確立・遮断を指示してセッショントークンを生成する。PEPが接続を有効化し、監視し、終了する。判断と実施の役割が分かれている。

情報漏えいの調査記録（ダミー）
利用者は、多要素認証でVPNに接続した（正規の利用者）
接続後、利用者の端末から、複数の社内システムにアクセスがあった
端末はマルウェアに感染しており、人事システムのデータが持ち出された
// VPNの通信は暗号化されていた
// 各システムの設定は、VPN接続元アドレスからの通信を許可するのみ

ゼロトラストの観点で、設計上の問題点は？

答えを開く

接続元の位置だけで許可し、リソースごと・端末の状態を踏まえた認可をしていなかった

よくある誤答

  • VPNの暗号が弱かった … 記録では暗号化されていた
  • 認証が弱かった … 認証は通っている。問題は認証の後の認可
