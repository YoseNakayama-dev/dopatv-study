#59 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

ログ分析の概要 突き合わせて初めて見える不正の足取り

  1. ログ分析の目的は、不正の検知・インシデントの調査・証跡の確保。残すログを前提として決めておく。
  2. 複数機器のログを突き合わせる相関分析は、機器の時刻が同期していることが前提になる。
  3. 保管は目的に応じた期間で改ざんされにくく。基準を決めてアラート化しても、最終判断は人が行う。

用語カード

クイズ

  1. 動画で出た問題ログ分析の「相関分析」の説明として、適切なのは？

    1. それは、ログの整理と保管

    2. それは、マスキングなどの加工

    3. それは、ログの廃棄

    4. 複数のログを突き合わせる

  2. ログ収集基盤を導入し、アラートを自動化することにした。運用方針として適切なものはどれか。

    1. 正解。何を異常とみなすか基準を決めてアラートに使い、自動化しても最終的な判断と対応は人が行う。

    2. アラートは決めた基準に基づく通知で、誤検知や見落としがありうる。自動化しても最終的な判断と対応は人が行う。

    3. 製品の既定の基準では、自組織で何を異常とみなすかが定まらない。基準は自組織で決めてアラートに使う。

    4. SIEMは集約・相関分析・アラートを自動化するが、機器ごとに形式が違うログを突き合わせるには、収集と分析の間で形式をそろえる作業が別に要る。

  3. 認証サーバのログで、ログイン失敗の連続が見つかった。侵入の有無と範囲を調べる次の一手として適切なものはどれか。

    1. ひとつのログから見つけられるのは、異常な値や回数。一連の動きは複数の機器のログを突き合わせてたどる。

    2. 正解。相関分析で複数機器のログを突き合わせ、侵入から持ち出しまでの一連の動きをたどる。

    3. 回数の異常は個別の確認で分かるが、一連の動きをたどるには複数の機器のログの突き合わせが要る。

    4. 機器ごとに形式が違うため、そろえる作業が要る。流れは、収集、形式をそろえる、分析、対応の順。

  4. インシデント調査と証跡の確保のため、ログの保管を設計する。考え方として適切なものはどれか。

    1. 期間は目的に応じて決める。保管場所も、改ざんされにくい場所に残すことが大切とされている。

    2. 個人情報を理由に取得から外すと、調査や証跡に必要な記録が残らない。個人情報への配慮は、含まれる場合の取り扱いの話。

    3. 正解。目的に応じた期間で保管し、改ざんされにくい場所に残す。

    4. 目的ごとに必要な保管期間は異なる。一律にすると、調査に必要な期間が足りなくなることがある。

  5. 不審な操作の調査で、誰が何をして成功したのかが記録から分からなかった。見直しとして適切なものはどれか。

    1. 保管期間は目的に応じて決めるもの。取得していない項目は、期間を延ばしても記録に増えない。

    2. 正解。時刻・送信元・宛先・結果・利用者などを含め、いつ誰がどこから何をして結果はどうかが分かる項目を取得する。

    3. 時刻と送信元だけでは、誰が何をして結果がどうだったかが分からない。

    4. 利用者を取得しないと、誰の操作かを追えなくなる。個人情報への配慮は、含まれる場合の取り扱いの話で、取得をやめる理由ではない。

  6. FW・プロキシ・認証のログを一か所に集めたが、形式が違い、検索も突き合わせもできない。流れの中で不足している作業はどれか。

    1. 正解。流れは収集、形式をそろえる、分析、対応。機器ごとに形式が違うため、そろえる作業が要る。

    2. 異常の基準とアラートは分析に使う仕組みで、形式が違う状態を解消するものではない。

    3. 保管期間や改ざんされにくい保管はログ管理の要点で、形式をそろえる作業とは別。

    4. 最終的な判断と対応は人が行うが、形式がそろっていないと突き合わせ自体ができない。

頭の中で考える

  1. ログ分析を始める前に、あらかじめ決めておくべきことは何か。なぜそれが要るのかも含めて、頭の中で説明してみよう。

    答えを開く

    どのログを、いつまで、どこに残すかを決めておく。残していないログは見られないため。期間は目的に応じて決め、改ざんされにくい場所に残し、いつ・誰が・どこから・何をして・結果はどうかが分かる項目を取得する。

  2. SIEMでアラートが出るようになった。それでも担当者が関わり続ける必要がある点を、頭の中で説明してみよう。

    答えを開く

    SIEMは集約・相関分析・アラートの自動化を行う。何を異常とみなすかの基準は決めておく必要があり、自動化しても最終的な判断と対応は人が行う。

午後問題にチャレンジ

不正アクセスの経路調査の記録（ダミー）
FWとWebサーバのログは、ログ用サーバに集約済み
保管期間は1年。調査対象の日のログは、すべて残っている
同じ通信が、FWログでは10:02、Webサーバでは10:05の記録
各機器は、それぞれの内蔵時計で、時刻を記録している
要件: 手作業の補正なしで、2つのログを時系列に突き合わせたい

ログの突き合わせのために、必要な対策は？

答えを開く

全機器の時刻を、基準となる時刻源に同期させ続ける

よくある誤答

  • ログの保管期間をさらに延ばして、長期間残すようにする … 保管は1年で、調査日のログは残っている
  • ログ用サーバへの集約を進めて、一か所にまとめる … すでに集約済みで、記録の時刻は変わらない
