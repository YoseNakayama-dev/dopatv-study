#88 ・ 第9章 情報セキュリティに関する法制度

Pマークとは何か JIS Q 15001とGDPRの違い

  1. JIS Q 15001はPMSの要求事項。Pマークは、それに基づく体制を付与機関が審査して認定する任意の制度。
  2. GDPRはEUの法規制。EU域内に拠点がなくても、域内の個人に商品やサービスを提供する場合などは適用されうる。
  3. Pマークは漏えいの保証でもGDPR適合でもない。侵害でリスクがある場合は、72時間以内に監督機関へ通知する。

  1. 動画で出た問題プライバシーマーク制度の説明として、適切なものは？

    1. 取得は法律上の義務ではない

    2. JIS Q 15001に基づく体制の認定

    3. 漏えいがないことを保証するものではない

    4. GDPRへの適合を認める制度ではない

  2. Pマークを取得した事業者が、取得時の体制を更新まで見直さない方針にしている。この方針への評価として適切なのはどれか。

    1. 正解。JIS Q 15001は、方針・計画・実施・点検・見直しで継続的に改善する。

    2. PMSは計画、実施、点検、見直しで継続的に回す。審査のときだけの取組みではない。

    3. Pマークは漏えいがないことの保証ではなく、体制の評価。

    4. Pマークは法律上の義務ではなく、任意の制度。

  3. 全世界年間売上高が10億ユーロの事業者が、GDPRの制裁金の対象となる重大な違反をした。制裁金の上限として適切なのはどれか。

    1. 上限は2000万ユーロと売上高の4%のいずれか高い方。定額だけを適用するわけではない。

    2. 正解。10億ユーロの4%は4000万ユーロで、2000万ユーロより高いので、4000万ユーロが上限になる。

    3. いずれか高い方が上限で、低い方ではない。また10億ユーロの4%は400万ユーロではなく4000万ユーロ。

    4. 二つを加算するのではなく、いずれか高い方が上限になる。

  4. EU域内の個人の個人データが漏えいしたことを、事業者が認識した。個人の権利へのリスクがある。対応として適切なのはどれか。

    1. 通知は、認識から72時間以内に行う。時期を問わずに通知するのではない。

    2. 通知が必要になるのは、個人の権利へのリスクがある場合。

    3. 個人データの侵害は、監督機関へ通知する。

    4. 正解。リスクがある場合、侵害の認識から72時間以内に監督機関へ通知する。

  5. EU域内の子会社が収集した顧客の個人データを、日本の本社へ移転する。GDPR上の対応として適切なのはどれか。

    1. 正解。EU域外への移転は、十分性認定や標準契約条項（SCC）などを根拠にして行う。

    2. Pマークは、GDPRへの適合を示すものではない。移転の根拠にもならない。

    3. 日本は補完的ルールを条件に十分性認定を受けている。条件なく移転できるわけではない。

    4. 域外への移転は、十分性認定や標準契約条項などを根拠に行える。

  6. 営業資料にPマークの取得を記載する。記載として適切なのはどれか。

    1. Pマークは、GDPRへの適合を示すものではない。

    2. Pマークは、漏えいがないことの保証ではなく、体制の評価。

    3. 正解。Pマークは、JIS Q 15001に基づく体制を付与機関が審査して認定する制度。

    4. Pマークの取得は法律上の義務ではなく、任意の制度。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 「Pマークがあれば、EUの規則も大丈夫」と言えない理由を、頭の中で説明してみよう。

    答えを開く

    Pマークは、JIS Q 15001に基づく体制を認定する任意の制度。GDPRはEUの法規制で、別のもの。Pマークを取得してもGDPRに適合したことにはならない。EU域内に拠点がなくても、域内の個人に商品やサービスを提供すればGDPRは適用されうる。

  2. 拠点のない日本の事業者がEU域内の個人へ販売を始める。GDPRの面で確認する点を、頭の中で説明してみよう。

    答えを開く

    まず、域内の個人に商品やサービスを提供するかでGDPRの適用範囲を確認する。侵害があり個人の権利へのリスクがある場合は、認識から72時間以内に監督機関へ通知する。域外へ移すときは、十分性認定や標準契約条項などの根拠を用意する。
