#86 ・ 第9章 情報セキュリティに関する法制度

NISTサイバーセキュリティフレームワーク 機能とプロファイルで見る

  1. CSFは組織が自主的に使う枠組みで、法的義務ではない。コア・ティア・プロファイルから成る。
  2. コアは機能で対策を整理し、2.0ではガバナンスが加わり六機能になる。ティアは取組みの度合いを四段階で示す。
  3. プロファイルで現状と目標を比べ、不足と優先順位を決める。作るだけでは進まず、実行と見直しが要る。

用語カード

用語を見て意味を言えるか試し、タップで裏返します。「覚えた」を続けるほど定着度が上がり、「まだ」で最初に戻ります。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題ティアの説明として、適切なのは？

    1. それはコアの説明

    2. それはプロファイルの説明

    3. CSFは自主的に使う枠組み

    4. 取組みの度合いを四段階で示す

  2. 取締役会が「全社のティアを最高にすることを目標とする」と指示した。ティアの目標設定として適切なのはどれか。

    1. 正解。ティアはリスク管理の取組みの度合いで、高いほど良いとは限らない。リスクに合った度合いを組織が選ぶ。

    2. 高いほど良いとは限らない。目標は組織がリスクに合わせて決める。

    3. CSFは組織が自主的に使う枠組みで、法的義務ではない。

    4. CSFは個々の対策の細かい手順を定めない。ティアは取組みの度合いを四段階で示すもの。

  3. 現状と目標のプロファイルを作成し、差が一覧になった。しかし半年たっても対策が進んでいない。対応として適切なのはどれか。

    1. プロファイルは作るだけでは改善が進まない。差を埋める計画を実行して見直す。

    2. コアの機能は組織のリスクに合わせて扱い、すべてを同じ水準で行う必要はない。

    3. 正解。差から優先順位を決めて計画に落とし込み、実行して定期的に見直す。

    4. 他社の目標は、当社の現状やリスクと合わず、当社の不足を示さない。

  4. CSFを導入するチームが「CSFを読めば、個々の対策の細かい設定手順が分かる」と説明した。評価として適切なのはどれか。

    1. CSFは個々の対策の細かい手順を定めない。参照規格を示す。

    2. 正解。CSFは個々の対策の細かい手順を定めず、参照規格を示す。手順は参照規格などで確認する。

    3. ティアはリスク管理の取組みの度合いを示すもので、手順を決めるものではない。

    4. CSFは組織が自主的に使う枠組みで、法的義務ではない。

  5. CSF 1.1 を使ってきた組織が 2.0 に更新する。変わる点として適切なのはどれか。

    1. ティアはリスク管理の取組みの度合いを示す四段階で、機能の数とは別のもの。

    2. CSFは組織が自主的に使う枠組みで、法的義務ではない。

    3. 復旧は五機能の一つ。2.0ではこの五機能にガバナンスが加わる。

    4. 正解。1.1の五機能（特定・防御・検知・対応・復旧）に、2.0でガバナンスが加わり六機能になる。

  6. 自社でCSFを使い始める。最初の整理として適切なのはどれか。

    1. 正解。資産とリスクの把握から始め、コアの機能で今の対策を整理する。その後に現状と目標のプロファイルを作る。

    2. 他社の目標は、自社の現状やリスクと合わず、自社の不足を示さない。

    3. ティアは高いほど良いとは限らず、目標は組織が決める。最高を先に決める必要はない。

    4. コアの機能は組織のリスクに合わせて扱う。すべてを同じ水準で行う必要はない。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 不足している対策を洗い出して優先順位を決めるために、CSFをどう使うか、頭の中で説明してみよう。

    答えを開く

    コアの機能で今の対策を整理し、現状と目標のプロファイルを作る。二つを比べて不足を洗い出し、差から優先順位を決めて計画に落とし込む。作るだけでは改善は進まないので、実行して定期的に見直す。

    思い浮かんだ要素にチェック

  2. 「CSFを導入すれば、法律で求められる対策が決まる」という説明を修正してみよう。

    答えを開く

    CSFは組織が自主的に使う枠組みで、法的義務ではない。個々の対策の細かい手順も定めておらず、参照規格を示す。組織がリスクに合わせて目標を決め、現状との差を見て対策を選ぶ。

午後問題にチャレンジ

動画の午後問題です。ログを読んで、答えを頭の中で決めてから開いてください。

セキュリティ対策の整理に関する記録（ダミー）
現状: 当社は、対策をコアの機能ごとに、整理済みだが、不足は分からない
今の状況と、将来の姿は、それぞれ文書化できる
経営層は、不足する対策を、根拠付きで知りたがっている
要件: 不足する対策を明確にし、優先順位を決めたい

要件を満たす方法として、適切なのは？

答えを開く

現状と目標のプロファイルを比べ、不足と優先順位を決める

よくある誤答

  • ティアを上げることだけを、目標にする … ティアは取組みの度合いを示すもので、不足する個別の対策は分からない
  • 他社のプロファイルを、そのまま採用する … 他社の目標は、当社の現状やリスクと合わず、当社の不足を示さない

  • 9.1.7 NISTサイバーセキュリティフレームワーク

コア・ティア・プロファイルの役割を区別し、ティアの誤解と、プロファイルを作るだけで終わらせない点を確かめながら読む。
