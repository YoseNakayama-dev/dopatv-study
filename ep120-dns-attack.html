#20 ・ 第2章 情報セキュリティにおける脅威

DNSサーバへの攻撃 4種類を狙いで整理する

  1. DNS攻撃は狙いで整理する。答えの正しさはポイズニング、可用性は増幅とランダムサブドメイン。
  2. ポイズニングは、照合を通る偽の応答が正規より先に届くと成立し、照合要素が予測しやすいほど成立しやすい。
  3. 増幅はUDPの送信元偽装と誰にでも答えるサーバが条件。ゾーン転送の無制限許可は構成情報が漏れる。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題DNS増幅攻撃が成立する条件として、適切なのは？

    1. 送信元の偽装＋誰にでも答えるサーバ

    2. DNSSECは応答の正当性の検証

    3. ゾーン転送の制限は別の攻撃への備え

    4. 保持が長いほど、問い合わせは減る

  2. 社外向けDNSサーバの送信トラフィックが急増した。宛先の大半は自社が通信した覚えのない単一のIPアドレスで、このサーバは外部の誰からの再帰問い合わせにも応答する設定だった。疑われるものはどれか。

    1. ポイズニングは偽の答えを覚えさせる攻撃で、単一の宛先への大量の応答は説明できない。

    2. ランダムサブドメイン攻撃は存在しない名前の問い合わせが急増する攻撃。送信トラフィックの宛先が単一である点と合わない。

    3. 正解。誰にでも応答する設定のサーバが、送信元を偽装された問い合わせに応じ、大きな応答を被害者へ送っている。

    4. ゾーン転送の悪用は情報収集が目的で、大量の応答が単一の宛先へ送られる状況とは合わない。

  3. キャッシュポイズニングが成立しやすい状況として最も適切なものはどれか。

    1. 再帰の扱いは主に増幅攻撃の踏み台に関わる。ポイズニングの成立条件ではない。

    2. ゾーン転送の制限はゾーン転送の悪用への備えで、ポイズニングとは別の話。

    3. 照合を厳密にするほど、偽応答は受理されにくくなる。成立しにくい状況である。

    4. 正解。照合を通る偽応答が正規の応答より先に届くと成立し、照合要素が予測しやすいほど成立しやすい。

  4. 手前にキャッシュサーバがあるのに、ランダムサブドメイン攻撃で権威サーバに負荷がかかる。その理由として最も適切なものはどれか。

    1. 偽の答えを覚えさせるのはポイズニング。この攻撃の仕組みではない。

    2. 正解。存在しないランダムな名前はキャッシュに答えがなく、問い合わせが権威サーバまで届く。

    3. 応答の集中は増幅攻撃の仕組み。ランダムサブドメイン攻撃では被害者の偽装は必要条件ではない。

    4. ゾーン転送は複製の仕組みで、この攻撃とは関係しない。

  5. 外部から、副サーバ以外の相手にもゾーン転送に応じていたため、内部ホスト名の一覧が取得された。この攻撃が狙った特性として最も適切なものはどれか。

    1. 答えの正しさを狙うのはポイズニング。ここでは応答は書き換えられていない。

    2. 可用性を狙うのは増幅攻撃やランダムサブドメイン攻撃。サービス停止は起きていない。

    3. 正解。ゾーン内の登録情報が漏れ、攻撃の前段の情報収集に使われる。

    4. 利用者の認証は関係しない。ゾーン転送の許可範囲の問題である。

  6. 利用者から「正規のURLを入力したのに別のサイトが表示される」と報告があった。DNSの攻撃として最も疑われるものはどれか。

    1. 増幅攻撃は被害者への応答の集中で、利用者が別サイトへ誘導される現象は説明できない。

    2. 正解。偽の応答を覚えたキャッシュサーバに問い合わせた利用者は、偽サイトへ誘導されうる。

    3. ゾーン転送の悪用は構成情報の漏えいで、表示サイトが変わる現象は説明できない。

    4. ランダムサブドメイン攻撃は負荷が上がる攻撃で、別サイトへの誘導は起こさない。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. DNSへの4つの攻撃を「狙い」で3つに分類し、それぞれに入る攻撃を、頭の中で説明してみよう。

    答えを開く

    答えの正しさを狙うのがキャッシュポイズニング。可用性を狙うのがDNS増幅攻撃とランダムサブドメイン攻撃で、どちらもDoSになる。情報の秘密を狙うのがゾーン転送の悪用で、構成の手がかりが漏れる。

    思い浮かんだ要素にチェック

  2. キャッシュポイズニングが成立する条件と、成立しやすさを左右する点を、頭の中で説明してみよう。

    答えを開く

    正規の応答より先に、問い合わせとの照合を通る偽応答が届くと成立する。照合に使う要素が予測しやすいほど成立しやすい。成立すると、利用者が偽サイトへ誘導される。
