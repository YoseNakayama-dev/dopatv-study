EDR・XDR・SIEM・SOAR 役割の使い分け

  1. EDRは端末を見る。XDRは複数の領域を横断する。SIEMはログを集めて相関分析し、SOARは対応を自動で実行する。
  2. SIEMは時刻同期、取得元の網羅、ルールの調整が前提。入れただけでは見逃しや誤検知が残る。
  3. SOARは検知の代わりにならない。影響の大きい操作は人の承認を挟む。XDRの範囲は製品で異なる。

クイズ

  1. 動画で出た問題セキュリティ運用の道具の説明として、適切なものは？

    1. EDRは端末の動作を見る

    2. ログの集約・相関分析・警報

    3. SOARは対応を自動化する

    4. 体制と調整は必要

  2. SIEMで、ファイアウォールのログとサーバの認証ログをつなぐ相関ルールを作ったが、期待どおりに発火しない。調べると、機器の間で時刻が数分ずれていた。最初に取るべき対応はどれか。

    1. 正解。SIEMは別々の機器のログを時刻でつなぐので、機器の時刻の同期が前提になる。

    2. SOARは定めた対応手順を自動で実行する仕組み。検知そのものの代わりにはならない。

    3. EDRは端末の動作を記録して検知する仕組み。他の機器のログの時刻を補正するものではない。

    4. 取得元を増やしても、時刻がずれていれば、ログを一連の流れとしてつなげない。

  3. XDRを導入したが、クラウドサービスの不審なサインインが検知に出てこない。最も適切な確認はどれか。

    1. XDRの範囲と機能は、製品や事業者で異なる。すべての領域を対象にするとは限らない。

    2. SOARは対応手順を自動で実行する仕組みで、検知の代わりにならない。対象外の領域の検知は増えない。

    3. 正解。XDRの範囲や機能は製品や事業者で異なる。導入した製品が、クラウドを対象にしているか確認する。

    4. EDRが見るのは主に端末の動作。端末の範囲を広げても、クラウドのサインインが検知の対象になるとは限らない。

  4. SOARで、EDRのアラートが出たら端末を自動で隔離する手順を全件に設定した。ところが誤検知で営業部門の端末が一斉に隔離され、業務が止まった。最も適切な見直しはどれか。

    1. 警報を止めると、本当の攻撃も見逃す。問題は検知ではなく、影響の大きい操作を無条件に自動化した点。

    2. 対象を広げると、誤検知の影響がさらに大きくなる。見直すべきは自動化の範囲と条件。

    3. SOARは検知そのものの代わりにならない。検知ルールの調整は引き続き必要。

    4. 正解。影響の大きい操作は、人の承認を挟む。誤検知で業務が止まる恐れへの備えになる。

  5. SIEMを導入したが、重要な業務サーバのログが取り込まれておらず、そのサーバでの不審な操作が警報に出なかった。最も適切な改善はどれか。

    1. 正解。ログの取得元の網羅と、検知ルールの調整が欠かせない。入れただけでは見逃しが残る。

    2. SOARは警報が出たあとの対応を自動化する。取り込まれていないサーバの検知漏れは直らない。

    3. 時刻同期は、取り込んだログをつなぐための前提。未接続のサーバのログが増えるわけではない。

    4. SIEMは取得元に入れた機器のログしか扱えない。サーバが取得元に入っていなければ、ネットワーク機器のログを増やしても、そのサーバの動きは警報に出ない。

  6. 1台のPCで不審なプロセスが起動した。その端末で何が実行されたかをさかのぼって調べ、必要ならその端末を隔離したい。最初に使う仕組みとして、最も適切なものはどれか。

    1. SIEMは検知して担当者に知らせるのが中心。端末の動作を記録して調べ、端末を隔離する仕組みとは役割が違う。

    2. SOARは定めた手順を実行する仕組み。端末の動作の記録や検知の代わりにならない。

    3. 正解。EDRは端末の動作を記録し、検知・調査・端末の隔離ができる。端末で何が起きたかを追うのに向く。

    4. メールの領域の検知結果は、端末の中で実行された内容を直接示すものではない。端末の動作は端末側の記録で追う。

頭の中で考える

  1. EDR・SIEM・SOARを、それぞれ「何を担うか」の一言で言い分けてみよう。さらに、SIEMだけで足りない場面を頭の中で説明してみよう。

    答えを開く

    EDRは端末の動作を見て検知・調査・隔離、SIEMは多くの機器のログを集めて相関分析し警報を出す、SOARは定めた対応手順を自動で実行する。SIEMは検知と通知が中心なので、通知のあとの起票・連絡・隔離の依頼を手作業で行うと初動が遅れ、SOARの出番になる。

    思い浮かんだ要素にチェック

  2. SOARで端末の隔離を完全に自動化するときのリスクと、その備えを頭の中で説明してみよう。

    答えを開く

    誤検知で自動隔離すると、業務が止まる恐れがある。影響の大きい操作は、手順に人の承認を挟む。また、SOARは検知の代わりにならないので、検知側のルールの調整と取得元の網羅は引き続き必要。

    思い浮かんだ要素にチェック

午後問題にチャレンジ

SOCの運用記録（ダミー）
SOCの運用記録。相関ルールは正しく発火している
アラートは、検知から1分以内に担当者へ通知される
その後の起票・連絡・隔離の依頼は、複数ツールを手作業で操作
初動までに、平均40分かかっている
要件: 手作業を減らし、初動の時間を短縮したい

適切な対策は、どれ？

答えを開く

SOARで、定めた対応手順を自動で実行する

よくある誤答

  • SIEMの相関ルールを増やす … 検知と通知は適切。手作業の対応は短くならない
  • EDRを全端末に導入する … 端末の検知や隔離が中心。起票や連絡を含む複数ツールの手順は、まとめて自動実行できない
