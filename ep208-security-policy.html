#108 ・ 第4章 情報セキュリティマネジメントの実践

情報セキュリティポリシー 体系と策定の留意点

  1. ポリシーは基本方針（取組み姿勢と目的）・対策基準（遵守事項）・実施手順（具体的な手順）の三階層で、上位に沿って下位を具体化する。
  2. 策定では、経営層の承認と組織全体への適用、現場で実行できる内容、法令・契約との整合、周知・教育、例外の扱いが要る。
  3. 基本方針は外部に示すことがあり、基準・手順は通常社内限り。文書だけでは守られず、遵守の確認と是正・定期的な見直しが要る。

  1. 動画で出た問題ポリシーの説明として、適切なものは？

    1. 操作手順は実施手順に定める

    2. 経営層が取組み姿勢を示す

    3. 変化に応じて定期的に見直す

    4. 実行できる内容にする

  2. 取引先から、情報セキュリティへの取組みを示す文書の提出を求められた。外部に示すことがある文書として最も適切なものはどれか。

    1. 実施手順は通常は社内に限る。詳細な内容は外へ出さない。

    2. 対策基準も通常は社内に限る。詳細な内容は外へ出さない。

    3. 対策基準と実施手順は通常は社内限りで、詳細な内容は外へ出さない。両方を提出するのは不適切。

    4. 正解。基本方針は、取引先や利用者に示すことがある。

  3. 対策基準の案に「全従業員は、業務外のWebサイトへ一切アクセスしない。例外は認めない」とあった。しかし調達担当は、業務上、外部の多様なサイトを日常的に閲覧する必要がある。対応として最も適切なものはどれか。

    1. 正解。現場で実行できない規則は形骸化する。実行できる内容にし、例外は承認と期限を決めて扱う。

    2. 周知や教育は要るが、現場で実行できない内容は形骸化する。まず実行できる内容にする。

    3. 例外の扱い（承認と期限）を定めておくのが策定の留意事項。一切設けないと、守れない規則が形骸化しうる。

    4. 経営層の承認に加え、現場で実行できる内容であることも必要。実態とのずれを放置すると形骸化する。

  4. 3年前に整備したポリシーについて、監査で、現場では手順書と違うやり方が広まっていることが分かった。整備後に遵守状況の確認は行われていない。対応として最も適切なものはどれか。

    1. 文書があるだけでは守られない。個別の注意だけでは、手順と実態がずれている原因が残る。

    2. 実施手順は、具体的な手順を定める役割を持つ。廃止すると、どう行うかの判断が現場任せになる。

    3. 正解。遵守状況を確認して逸脱は是正し、事業・脅威・法令の変化に応じて定期的に改訂する。

    4. 周知は必要だが、文書を配るだけでは守られない。遵守の確認と是正が要る。

  5. 新しい対策基準の案が、取引先との契約で定めたデータの保管条件と食い違っていることが分かった。対応として最も適切なものはどれか。

    1. ポリシーは、法令・契約・既存の規程と矛盾させない。契約と無関係には定められない。

    2. 正解。策定の留意事項は、法令・契約・既存の規程と矛盾させないこと。

    3. 承認の順序で優先が決まるわけではなく、矛盾させないことが求められる。

    4. 契約は取引先との取り決めで、一方的に変える前提は置けない。まず基準案を見直して矛盾させない。

  6. 開発部から、検証のため一部の端末で対策基準の遵守事項を例外的に外したいと申請があった。例外の扱いとして最も適切なものはどれか。

    1. 正解。例外は、承認と期限を決めておく。

    2. 期限なく残る例外が、基準を形骸化させる。承認と期限を決めておく。

    3. 例外の扱い（承認と期限）を定めたうえで認めるのが留意事項。一切認めないと、守れない規則が形骸化しうる。

    4. 例外も承認と期限を決めて扱う。承認なしに対象外とすると、例外が野放しになる。

頭の中で考える

  1. 対策基準と実施手順の違いを、パスワードを例に頭の中で説明してみよう。

    答えを開く

    対策基準は守るべき事項（遵守事項）を定める文書で、例はパスワードの最低文字数。実施手順は具体的な手順や操作を手順書に定める文書で、例はパスワードを変更する操作の手順。どちらも上位の基本方針に沿って具体化する。

  2. ポリシーを整備したのに守られない組織で、原因の候補と取るべき対応を頭の中で挙げてみよう。

    答えを開く

    現場で実行できない内容だと形骸化する。周知・教育の不足や、例外の扱いの曖昧さも原因になる。文書があるだけでは守られないので、遵守状況を確認して逸脱は是正し、事業・脅威・法令の変化に応じて定期的に見直す。

  • 実施手順 … 操作の手順は別の文書Yにあり、Xは守る条件を定めている
