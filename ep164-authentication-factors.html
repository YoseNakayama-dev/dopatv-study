#64 ・ 第6章 情報セキュリティ対策技術（2）アクセス制御と認証

認証の分類 知識・所持・生体を重ねる

  1. 認証は知識・所持・生体に分けられ、分類ごとに破られ方（弱点）が異なる。
  2. 多要素認証は異なる分類を2つ以上組み合わせる。同じ分類を重ねても多要素にならない。
  3. 生体認証は忘れない反面、誤りはゼロにできず変更もできない。許容度の調整と代替手段が要る。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題生体認証の説明として、適切なのは？

    1. 誤りはゼロにならない

    2. 身体の特徴は変更できない

    3. 本人拒否の誤りも起こりうる

    4. 紛失・盗難で悪用されうる

  2. 社内システムが、ログイン時にパスワードに加えて「秘密の質問」への回答も求めるようにした。これで多要素認証になったと言えるかについて、適切な説明はどれか。

    1. 手順が増えても、同じ分類を重ねただけ。多要素認証は異なる分類を2つ以上組み合わせることをいう。

    2. 本人しか知らない情報は知識に分類される。台本でも、パスワードと秘密の質問はどちらも知識と説明している。

    3. 長く複雑にしても知識のまま。分類が変わらないので、多要素認証にはならない。

    4. 正解。パスワードも秘密の質問も知識で、同じ分類を重ねても多要素にならない。

  3. 入退室は、ICカードの提示と暗証番号の入力の両方を求める方式にしている。カードを拾った第三者が暗証番号を知らない場合の説明として、適切なものはどれか。

    1. 正解。暗証番号は知識、ICカードは所持で、異なる分類の組み合わせ。カードを落としても、暗証番号を知らなければ使えない。

    2. 暗証番号は知識に分類される。所持にあたるのはICカードのほう。

    3. 知識と所持は異なる分類。同じ分類を重ねたときに多要素にならない。

    4. ICカードは所持、暗証番号は知識。生体情報は使っておらず、暗証番号の入力も必要。

  4. 指紋認証の入室管理で、登録済みの本人が拒否される事象が起きた。今後の運用の考え方として、適切なものはどれか。

    1. 本人を拒否する誤りも他人を受け入れる誤りも、完全にはゼロにできない。

    2. 正解。誤りはゼロにできないので、誤りの許容度を調整し、代替手段を用意しておく。

    3. 再登録で誤りが起きなくなる保証はない。誤りは完全にはゼロにできない。

    4. 生体認証には忘れない・なくさない利点がある。誤りは許容度の調整と代替手段で備えるもの。

  5. 顔認証で本人確認する社内システムで、登録してある顔の特徴データが漏えいした。パスワードが漏えいした場合と比べた説明として、適切なものはどれか。

    1. 身体の特徴は変更できない。パスワードのように、あとから新しい値へ変えることができない。

    2. 固有であることは悪用されない根拠にならない。漏えいすると取り返しがつかない。

    3. 顔などの身体の特徴は生体に分類される。所持はICカードや認証用の装置など。

    4. 正解。身体の特徴は変えられず、漏えいすると取り返しがつかない。

  6. 次の3件を、課題となる分類に対応づけた。(1) 短いパスワードを推測された。(2) 従業員証を盗まれた。(3) 指紋が本人と認識されなかった。正しい組み合わせはどれか。

    1. パスワードは知識、従業員証は所持。(1)と(2)の分類が入れ替わっている。

    2. 正解。知識は推測や漏えい、所持は紛失や盗難、生体は誤認識が課題になる。

    3. パスワードは知識、従業員証は所持、指紋は生体。3件とも分類がずれている。

    4. パスワードは知識で、従業員証は所持、指紋は生体。3件とも分類がずれている。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 「パスワードに秘密の質問を足したが、多要素認証にならない」と言われる理由を、頭の中で説明してみよう。

    答えを開く

    多要素認証は、知識・所持・生体のうち異なる分類を2つ以上組み合わせるもの。パスワードも秘密の質問も知識で同じ分類なので、重ねても多要素にならない。ICカードなど別の分類を加える必要がある。

  2. 生体認証を導入するときの課題と、その備えを頭の中で整理してみよう。

    答えを開く

    本人拒否・他人受入の誤りはゼロにできない。また身体の特徴は変更できず、漏えいすると取り返しがつかない。そのため誤りの許容度を調整し、代替手段を用意する。

午後問題にチャレンジ

ログイン方式の見直しに関する検討記録（ダミー）
現状: 社内システムのログインは、パスワードのみで行っている
全端末に読み取り装置が接続済み。配布できる所持物は従業員証のみ
社内規程で、生体情報は取得しないと定めている
パスワードの文字数は、すでに十分に長く設定されている
要件: 異なる分類の要素を加え、多要素認証にしたい

多要素認証にする方法として、適切なのは？

答えを開く

ICカードの読み取りを、パスワードに加えて求める

よくある誤答

  • パスワードに加え、秘密の質問への回答を求める … どちらも知識で、異なる分類にならない
  • 指紋で認証し、パスワードと組み合わせる … 生体情報は、社内規程で取得しない
