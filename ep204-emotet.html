#104 ・ 第2章 情報セキュリティにおける脅威

Emotet 返信を装うメールと感染拡大

  1. 取引先を装う返信メールの添付でマクロを有効化させ、感染すると情報を窃取して次のメールを送る。
  2. Emotetは後続マルウェアの入口。暗号化は後続が行う場合がある。パスワード付きZIPで検査を避けることもある。
  3. 対策は別手段での確認・マクロ停止・検査と監視・感染時の隔離。本物の引用は見分けにくく、単独では足りない。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題Emotetの説明として、適切なものは？

    1. 主な入口はメールの添付

    2. 暗号化は後続のマルウェア

    3. アカウント・アドレス帳・本文

    4. 窃取した情報で返信を装う

  2. 経理担当が、取引先の担当者名の返信メールを受け取った。過去の見積のやり取りが正確に引用され、差出人のドメインも取引先と同じ。添付のExcelは「コンテンツの有効化」を求めている。評価として最も適切なものはどれか。

    1. 引用は窃取された本文などが使われうる。乗っ取りなら同じドメインで届くので、一致は本物の根拠にならない。

    2. 正解。乗っ取りなら同じドメインで届く。有効化を求める添付は、開く前に別の連絡手段で確認する。

    3. 有効化すると不正なコードが動く。ドメインの一致は、有効化しても安全という保証にはならない。

    4. 過去のやり取りを引用した返信形式こそ、Emotetが疑いにくくするための手口。特徴から外れるとは言えない。

  3. 社員の端末がEmotetに感染していたと判明した。メールアカウントの情報などが窃取された可能性がある。まず取るべき対応として最も適切なものはどれか。

    1. 正解。感染時は端末の隔離・パスワード変更・関係先への連絡を行う。自分のアドレスを装うメールが出回る可能性を知らせる。

    2. 感染が判明している以上、検出の有無にかかわらず通常業務を続けず、隔離とパスワード変更が先になる。

    3. 初期化しても、すでに窃取された情報は戻らない。窃取情報を使った次のメールが出回りうるので、連絡は必要。

    4. 暗号化は後続のマルウェアが行う場合があるだけで、被害が出ていないことは後続がいない根拠にならない。Emotetは他のマルウェアの入口になる。

  4. 添付ファイルを検査するゲートウェイを導入済みだが、パスワード付きZIPで届く添付が検査を通過していた。次の方針として最も適切なものはどれか。

    1. パスワード付きZIPは、中身を検査しにくいことが狙いで使われる。ルールを厳しくしても、中身を検査できるとは限らない。

    2. 検査をすり抜けるためにパスワード付きZIPが使われる。検査対象から外すと、その狙いどおりになってしまう。

    3. 正解。検査には、中身を検査しにくい添付という限界がある。端末の挙動監視やマクロの既定ブロックを組み合わせ、単独の対策に頼らない。

    4. 本物の引用は見分けにくく、利用者の注意だけでは限界がある。単独の対策に頼らない。

  5. 取引先から、自社を名乗り過去のやり取りを引用した不審なメールが届いたと連絡があった。自社にはそのようなメールを送った覚えがない。考えられる経緯として最も適切なものはどれか。

    1. 受信設定だけでは、自社を名乗り過去のやり取りを引用した内容を説明できない。自社の情報が使われた可能性を調べる。

    2. 暗号化は後続のマルウェアが行う場合がある話で、メールが送られる仕組みとは別。Emotetは窃取した情報で次のメールを送る。

    3. 引用は、窃取されたメール本文などが使われうるもの。取引先のソフトの動作ではなく、自社から窃取された情報の悪用を疑う。

    4. 正解。アカウント情報・アドレス帳・メール本文が窃取され、次のメールに使われる。そのため感染時は、自分のアドレスを装うメールが出回る可能性を関係先へ連絡する。

  6. 情報システム部が、Officeのマクロを既定で止める設定を全社に展開した。この対策の評価として最も適切なものはどれか。

    1. 正解。マクロの既定ブロックは有効な対策だが、単独の対策に頼らない。検査や端末の挙動監視と組み合わせる。

    2. 単独の対策で、添付による感染をすべて防げるとは言えない。言い過ぎの断定。

    3. マクロを既定で止め、有効化しないことは対策に挙げられている。効果が期待できないとは言えない。

    4. 返信の形や本物の引用は安全の根拠にならない。取引先の名で届いても、乗っ取りの可能性がある。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. Emotetが感染を広げる流れを、入口から次の攻撃メールまで頭の中で説明してみよう。

    答えを開く

    取引先等を装う返信形式のメールが届き、過去のやり取りが引用されていることがある。添付のOffice文書がコンテンツ（マクロ）の有効化を促し、有効化すると不正なコードが動く。感染するとアカウント情報・アドレス帳・メール本文を窃取し、その情報で次のメールを送る。

    思い浮かんだ要素にチェック

  2. 差出人ドメインの確認だけではEmotetのメールを見分けられない理由と、代わりに取る手段を頭の中で説明してみよう。

    答えを開く

    乗っ取りなら同じドメインで届くため、ドメインが一致しても本物とは限らず、本物の引用は見分けにくい。添付は開く前に別の連絡手段で確認し、マクロは既定で止めて有効化しない。検査と端末の挙動監視も組み合わせ、一つの対策に頼らない。
