#79 ・ 第7章 情報セキュリティ対策技術（3）暗号

SSH 接続先と利用者を両方確かめる

  1. SSHは遠隔ログインやファイル転送を暗号化する。接続先はホスト鍵、利用者はパスワードか公開鍵で別に確かめる。
  2. 穴は、初回の指紋を確認せず承認すること、パスワードの総当たり、秘密鍵の流出、ポートフォワードの悪用。
  3. 対策は公開鍵認証＋パスワード認証の停止、パスフレーズ、指紋の別経路確認、転送の許可限定とログ。

クイズ

選ぶと、すべての選択肢について「なぜ正しいか・なぜ違うか」が出ます。間違えた問題は復習に入ります。

  1. 動画で出た問題SSHの公開鍵認証の説明として、適切なのは？

    1. 登録するのは公開鍵。秘密鍵は端末に置く

    2. それはパスワード認証

    3. サーバの確認はホスト鍵。利用者認証とは別

    4. 公開鍵を登録し、秘密鍵で署名

  2. 公開鍵認証を設定済みのサーバへ初めて接続すると、ホスト鍵の指紋の確認表示が出た。適切な対応はどれか。

    1. 正解。初回に指紋を確認して記録することで、偽サーバへの接続を防ぐ。確認は電話など別経路で行う。

    2. 公開鍵認証は利用者の認証で、接続先の確認はホスト鍵で行う別の仕組み。承認するだけでは偽サーバを見抜けない。

    3. 初回に指紋を確認して記録するのは利用者側の作業で、サーバ側の設定では済まない。

    4. 初回に指紋を確認しないと、偽サーバにつながる。確認不足が中間者の入口になる。

  3. パスワード認証を止め、公開鍵認証だけにしたサーバがある。管理者のノートPCから、パスフレーズの無い秘密鍵が盗まれた。起きうることはどれか。

    1. 秘密鍵が盗まれると本人になりすませる。パスワード認証の停止は、この流出を防がない。

    2. 正解。秘密鍵が流出すると本人になりすませ、パスフレーズが無いとそのまま使われる。だから秘密鍵はパスフレーズで守り、端末から出さない。

    3. ホスト鍵はサーバが本物かを示す鍵で、利用者の秘密鍵の流出とは別。今回の影響は利用者へのなりすまし。

    4. パスワード認証を止めれば、総当たりの的にならなくなる。問題になるのは秘密鍵の流出のほう。

  4. SSHサーバのポートフォワードを、社内への抜け道にさせないための対策として最も適切なものはどれか。

    1. ポートフォワードは社内への抜け道にもなる。暗号化されていることは、全員に許可してよい理由にならない。

    2. 認証方式の変更と、転送の許可は別の対策。転送は許可を限定し、ログを残す対策が必要。

    3. 正解。転送は必要な利用者だけに許可し、ログを残す。

    4. 指紋の確認は接続先の確認で、転送の許可とは別。許可していない転送が使われることもある。

  5. Telnetで行っていた保守をSSHに置き換えた。ファイル転送はFTPのままである。評価として適切なものはどれか。

    1. 正解。SFTPやSCPはSSHの道を使い、平文のFTPの代わりに使える。

    2. SSHは遠隔ログインだけでなく、ファイル転送も暗号化する。SFTPやSCPがその道を使う。

    3. FTPは平文で、置き換えただけでは包まれない。他の通信を包めるのはポートフォワードを使う場合。

    4. SFTPやSCPはSSHの道を使う。接続先の確認はSSHのホスト鍵で行うので、省けない。

  6. インターネットから22番に到達できるサーバで、パスワードの認証失敗が大量に記録された。対策として最も適切なものはどれか。

    1. パスワードに頼る認証のままでは、総当たりの試行を受け続ける点は変わらない。

    2. 正解。パスワード認証を止めて公開鍵認証にすれば、総当たりの的にならなくなる。秘密鍵の流出に備え、パスフレーズで守る。

    3. ホスト鍵は接続先の確認に使う鍵で、利用者認証への総当たりとは別。

    4. ポートフォワードは別の通信を運ぶ機能で、パスワード認証への試行とは別。

頭の中で考える

書かなくて大丈夫です。答えを頭の中で組み立ててから開き、要素がそろっていたか確かめます。

  1. 公開鍵認証に切り替え済みなのに、初回の指紋の確認表示をそのまま承認する運用が続いている。残るリスクと直し方を頭の中で説明してみよう。

    答えを開く

    公開鍵認証は利用者の認証で、接続先の確認はホスト鍵と指紋で別に行う。承認するだけでは偽サーバにつながる。初回に指紋を、サーバ管理者に電話など別経路で確認する。

  2. パスワード認証を止めて公開鍵認証にすれば、SSHの認証面は十分か。残る点と対策を頭の中で説明してみよう。

    答えを開く

    総当たりの的にはならなくなるが、秘密鍵が盗まれると本人になりすませる。秘密鍵はパスフレーズで守り、端末から出さない。ほかに、転送は必要な利用者だけに許可してログを残す。

午後問題にチャレンジ

動画の午後問題です。ログを読んで、答えを頭の中で決めてから開いてください。

サーバの遠隔保守に関する調査記録（ダミー）
現状: 管理者が、インターネット越しにサーバへ遠隔ログインする
サーバ管理者は、管理者から渡された情報を登録できる
サーバ管理者とは、電話でも連絡が取れる
要件: 推測や総当たりに頼る認証を使わず、偽サーバに接続しない

要件を満たす方法として、適切なのは？

答えを開く

パスワード認証を無効にして公開鍵認証にし、初回にサーバの指紋を電話で確認する

よくある誤答

  • パスワード認証のまま、長いパスワードを設定する … 推測や総当たりに頼る認証のままで、要件に反する
  • パスワード認証を無効にして公開鍵認証にするが、初回の確認表示はそのまま承認する … 偽のサーバに接続しない要件に反する
