#109 ・ 第4章 情報セキュリティマネジメントの実践

情報資産の洗出し・分類とクライアントPC

  1. 情報と、それを扱う機器・ソフト・保管場所を挙げ、台帳に記録して重要度で区分する。漏れた資産は守る対象から外れる。
  2. 取扱い規則は区分ごとに保管・持出し・送信・廃棄を定める。廃棄は復元できない方法で行い、管理責任者が見直す。
  3. PCは暗号化や権限の制限などを重ねる。紛失や盗難は起きるので保存を絞り遠隔消去も使うが、通信できないと届かない。

クイズ

  1. 動画で出た問題情報資産の管理の説明として、適切なものは？

    1. 分類も変化に応じて見直す

    2. 管理責任者を記録する

    3. 区分ごとに取扱い方法を定める

    4. 暗号化や権限の制限も組み合わせる

  2. 情報資産の台帳に顧客名簿のファイルだけが載っている。区分は文書化した「極秘・社外秘・公開」の3段階で、管理責任者も記入済み。一方、名簿を保存するノートPCや共有サーバ、保管場所の記載はない。この台帳への指摘として最も適切なものはどれか。

    1. 区分名や段階数は組織が基準を文書で定めるもので、3段階であること自体は不備ではない。問題は機器や保管場所の挙げ漏れにある。

    2. 正解。洗出しでは情報だけでなく、それを扱う機器・ソフト・保管場所も漏れなく挙げる。漏れた資産は守る対象から外れる。

    3. 洗出しの段階で機器・ソフト・保管場所まで挙げる。後回しにすると、その間は守る対象から外れたままになりうる。

    4. 管理責任者の記録は台帳の一項目だが、PCや保管場所が台帳に挙がっていなければ、責任者を決めても対策の対象にならない。

  3. 更新で不要になったノートPCを廃棄業者へ渡す。担当者は、利用者がファイルを削除しゴミ箱を空にしたことを確認し、そのまま渡すつもりでいる。台帳上、このPCには社外秘の資料が保存されていた。取扱い規則の観点で適切な判断はどれか。

    1. 削除しただけでは復元できることがある。廃棄では、媒体を復元できない方法で消去または破棄する。

    2. ラベルは区分が分かるようにする表示で、廃棄の方法そのものではない。区分に応じた規則に沿い、復元できない方法を取る。

    3. 廃棄も含め、区分ごとに規則を定め、管理責任者が取扱いを確認して見直す。最後の利用者の判断に任せない。

    4. 正解。削除だけでは復元できることがあるので、復元できない方法で消去・破棄し、管理責任者が取扱いを確認する。

  4. 外出先でノートPCを紛失した。このPCにはディスク全体の暗号化と画面ロックが設定済みで、遠隔消去の指示も出した。ただし端末が通信できる状態かは分からない。対応方針として最も適切なものはどれか。

    1. 正解。暗号化は紛失したPCの中身を読ませないための対策。遠隔消去は通信できないと届かないので、補助として重ねる。

    2. 遠隔消去は通信できないと届かない。指示を出しても、端末側で消去が完了したとは言えない。

    3. 紛失や盗難は起きる前提で、保存を絞り、遠隔消去も組み合わせる。暗号化があっても、対策は重ねて使う。

    4. ディスクを別のPCにつなぐと、ログインを経由せずに中身を読める。中身を読ませない対策としては、ディスク全体の暗号化が要る。

  5. 社内調査で、業務用PCの利用者が管理者権限で私物のソフトを入れ、USBメモリに顧客データを複製して持ち出している例が見つかった。PCの管理策の見直しとして最も適切なものはどれか。

    1. 画面ロックはPCの保護の一つだが、ソフトの導入は管理者権限、複製は外部媒体の接続に関わる。それぞれ権限の制限と接続の制御で扱う。

    2. 不正対策ソフトも保護の一つだが、対策は重ねて使うもの。管理者権限の制限と外部媒体の制御の代わりにはならない。

    3. 正解。管理者権限を絞ると不要なソフトの導入を防ぎやすくなり、外部媒体の接続を制御すると、データの持出しも防ぎやすくなる。

    4. ラベルは区分が分かるようにする表示にとどまる。持出しを抑えるには、区分ごとの規則に加えて外部媒体の接続の制御が要る。

  6. 人事部の給与データは「社外秘」区分で、同じ区分の議事メモと同じ規則で扱われている。しかし、漏えいした場合の影響は議事メモよりはるかに大きいと評価された。見直しの進め方として最も適切なものはどれか。

    1. 正解。機密性の重要度は、漏えいした場合の影響で決める。区分は文書で定めた基準に沿って見直し、区分ごとの規則で扱う。

    2. 区分の基準は文書で定め、区分ごとに規則を決める。担当者の判断に任せると基準の外でぶれ、区分を設ける意味が崩れる。

    3. 管理責任者は、取扱いを確認し見直す役。責任者を変えるだけでは、区分も規則も変わらず、保護の水準は変わらない。

    4. ラベルは区分が分かるようにする表示。区分が高いほど規則が厳しくなることで初めて取扱いに反映されるので、表示だけでは足りない。

頭の中で考える

  1. 紛失したノートPCに顧客名簿の複製があった。暗号化と遠隔消去がそれぞれ何のための対策で、どんな限界があるかを頭の中で説明してみよう。

    答えを開く

    暗号化は紛失したPCの中身を読ませないための対策で、ディスクを別のPCにつないでも読めないようにする。遠隔消去は通信できないと届かない。紛失や盗難は起きる前提で、保存するデータを絞り、対策を重ねて使う。

    思い浮かんだ要素にチェック

  2. 情報資産を洗い出してから、区分ごとの取扱い規則につなげるまでの流れを頭の中で説明してみよう。

    答えを開く

    情報と、それを扱う機器・ソフト・保管場所を漏れなく挙げ、台帳に名称・場所・管理責任者を記録する。機密性・完全性・可用性の重要度を付け、文書で定めた基準で区分を決める。区分ごとに保管・持出し・送信・廃棄の規則を定め、管理責任者が確認して見直す。

午後問題にチャレンジ

ノートPCの管理記録（ダミー）
営業部のノートPCに、業務のため顧客名簿の複製を保存
持出しは業務上継続する。紛失時、PCは通信できないことがある
ディスクを別のPCにつなぐと、中身をそのまま読める
要件: 紛失しても、名簿の内容を読み取られないようにする

適切な対策は、どれ？

答えを開く

ディスク全体を暗号化する

よくある誤答

  • ログインのパスワードを長くする … ディスクを別のPCにつなぐと、ログインを経由せず読める
  • 持出しを禁止する … 業務上、持出しを継続する前提で、禁止はできない
