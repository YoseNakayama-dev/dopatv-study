#89 ・ 第9章 情報セキュリティに関する法制度

サイバーセキュリティ経営ガイドライン 経営者の三原則と十項目

  1. 経営者が認識すべき3原則は、リーダーシップ、サプライチェーン全体の対策、関係者との適切な情報の伝え合い。
  2. 重要10項目は、経営者がCISO等に指示する。管理体制、予算・人材の確保、PDCA、緊急対応・復旧体制などを含む。
  3. 対策を担当部門に任せきりにせず、委託先も含めて進める。対策が不十分だと、経営者の責任が問われうる。

  1. 動画で出た問題経営者がCISO等に指示すべき事項として、適切なものは？

    1. ログ確認は経営者が自ら行う作業ではない

    2. 資源確保は経営者が指示する

    3. 見直しは平時からPDCAで続ける

    4. 緊急対応体制の整備

  2. ある社は、サイバー対策の予算と人員の判断を、情報システム部の現場判断にすべて任せている。ガイドラインに沿った経営者の対応として最も適切なものはどれか。

    1. 予算・人材の確保は、経営者が指示する重要10項目のひとつ。技術的な内容でも、3原則の第1は経営者がリーダーシップをとって進めること。

    2. 正解。資源（予算・人材）の確保は、経営者が責任者に指示して進めさせる項目。担当部門だけに任せきりにしない。

    3. 「資源（予算・人材）の確保」は一つの項目で、人材の確保も経営者が指示する対象に入る。

    4. 重要10項目の資源の確保は、対策に必要な予算と人材を確保すること。必要性と無関係に額や人員を固定する運用は、この項目に合わない。

  3. ある社は、取引先や顧客への情報の伝達を、事故が起きた緊急時だけ行う方針にしている。3原則に照らした評価として最も適切なものはどれか。

    1. リーダーシップの原則は、経営者が先頭に立って対策を進めること。伝達の時期の問題は、第3の原則に当たる。

    2. 第2の原則は、委託先を含むサプライチェーン全体で対策すること。伝達の時期とは別の原則。

    3. 正解。第3の原則は、平時も緊急時も関係者と適切に伝え合うこと（情報開示を含む）。緊急時だけでは満たさない。

    4. 情報開示は緊急時だけでなく、平時にも必要。緊急時だけの方針は第3の原則に合わない。

  4. ある社は、対策を一度整えたあと、重大な事故が起きたときだけ対策を見直している。重要10項目に沿った改善として最も適切なものはどれか。

    1. 正解。重要10項目にはPDCAがあり、対策を実施して見直しを続ける。見直しは事故の後だけでなく、平時から続ける。

    2. 事故が起きた年度に限る運用では、見直しが事故の後だけになる。見直しは平時から続ける。

    3. PDCAは経営者がCISO等に指示する重要10項目のひとつ。3原則の第1も、経営者のリーダーシップによる対策。

    4. 情報共有活動への参加は別の項目で、攻撃情報を活用するためのもの。対策を実施して見直し続けるPDCAの代わりにはならない。

  5. 経営会議で、担当者が「3原則は現場に実行を指示する項目で、重要10項目は経営者が心得る考え方だ」と説明した。この説明への評価として最も適切なものはどれか。

    1. 3原則は経営者が認識すべき考え方で、CISO等に指示するのは重要10項目。説明は逆になっている。

    2. 重要10項目は、経営者がCISO等に指示する項目。指示の対象にならないという説明は誤り。

    3. 3原則の第1は、経営者がリーダーシップをとって対策を進めること。現場任せで承認だけを行う運用は、この原則に合わない。

    4. 正解。3原則は経営者が認識すべき考え方、重要10項目は経営者がCISO等に指示すべき項目。

  6. 自社内の管理体制・予算・PDCAは重要10項目に沿って整備済み。一方、業務を委託している取引先の対策状況は確認していない。次に経営者が指示すべきことはどれか。

    1. 3原則の第2は、委託先を含むサプライチェーン全体で対策すること。委託先の弱点も自社のリスクになる。

    2. 正解。委託先を含めてサプライチェーン全体の状況を把握し、対策を進める。

    3. 委託先の弱点も自社のリスクになる。緊急対応体制は重要10項目のひとつだが、委託先の確認を後回しにする理由にならない。

    4. PDCAは対策を実施し、見直しを続けるもの。整備した時点で終了にはならない。

頭の中で考える

  1. 「対策は情報システム部に任せてある」という経営者の説明が、ガイドラインの観点で不十分な理由を、頭の中で整理してみよう。

    答えを開く

    3原則の第1は、経営者がリーダーシップをとって対策を進めること。予算や人材は経営者が指示して確保させ、担当部門だけに任せきりにしない。対策が不十分だと、経営者の責任が問われうる。

    思い浮かんだ要素にチェック

  2. 委託先に重要データを預けている企業の経営者が押さえるべき点を、原則と項目の両面から説明してみよう。

    答えを開く

    3原則の第2は、委託先を含むサプライチェーン全体での対策。委託先の弱点も自社のリスクになるので、状況を把握する。重要10項目にもサプライチェーン対策があり、経営者がCISO等に指示する。第3の原則として、平時から関係者と伝え合う。

現状: 責任者は情報システム部長。対策はその部門に任せきり
業務の一部を委託し、委託先に重要データを預けている
経営者は、対策や委託先の状況を、把握していない
要件: ガイドラインに沿った、経営者の対応を決めたい

ガイドラインに沿った、経営者の対応として、適切なのは？

答えを開く

経営者が責任者に指示し、委託先を含めて対策を進める

よくある誤答

  • 技術的な内容なので、引き続き情報システム部門に一任する … 経営者がリーダーシップをとり、対策を進める必要がある
  • 委託先の対策は委託先の責任なので、自社では把握しない … 委託先を含むサプライチェーン全体の対策が必要

本で読む

  • 9.3.5 サイバーセキュリティ経営ガイドライン

3原則（認識）と重要10項目（指示）の区別、任せきりにしない点、委託先を含む対策と平時の情報開示を確かめながら読む。
