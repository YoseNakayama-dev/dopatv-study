POP3の脆弱性と対策 平文の認証を守る

  1. POP3の基本の認証は平文で、暗号化がないと経路上の盗聴でパスワードやメール内容が漏れる。
  2. APOPはパスワードを送らないが古いハッシュ関数に依存し、総当たりや使い回しの影響も受ける。
  3. 対策はTLSと平文認証の無効化に回数制限・監視を重ねる。端末が感染していれば通信路を守っても漏れる。

クイズ

  1. 動画で出た問題POP3の認証情報の盗聴への対策として、適切なのは？

    1. 短く単純で、破られやすい

    2. 平文のままなら、盗聴できる

    3. 通信路をTLSで保護

    4. 認証情報の盗聴を防がない

  2. 社員Aが無料の公衆無線LANからPOP3（ポート110、USER/PASS、TLSなし）で受信した直後、別のIPから1回目のログインで成功された。端末は手元にあり感染もなく、パスワードの使い回しもない。再発防止として最も適切なものはどれか。

    1. 正解。平文の認証情報が経路上で盗聴された事象。TLSで通信路を保護し、平文の認証を無効にする。

    2. APOPは本文を暗号化しない。認証だけでなく通信路の保護も必要。

    3. 1回目で成功しており、総当たりではない。回数制限は総当たりへの備えで、盗聴は防げない。

    4. 端末のマルウェア検査は感染なしで、端末も手元にある。原因は端末ではなく経路。

  3. POP3の認証にAPOPを使っている。評価として最も適切なものはどれか。

    1. APOPのとき、本文は暗号化されない。

    2. 本文が暗号化されず、通信路の保護も必要。信頼できない経路ではリスクが高い。

    3. パスワード方式は、総当たりや使い回しの影響を受ける。

    4. 正解。パスワードそのものは送らないが、古いハッシュ関数に依存して推奨しにくく、本文は暗号化されない。

  4. POP3で、途中でTLSに切り替える方式（STLS）を使っているが、TLSの利用は強制していない。評価として最も適切なものはどれか。

    1. 切り替える方式は、強制しないと平文のまま続けられる余地が残る。最初から使う方式とは違う。

    2. 正解。切り替え方式は強制しないと平文が続く余地があり、平文の認証の無効化とあわせて必須にする。

    3. 暗号化の効果がないとは言えない。強制しないことが問題。

    4. 平文の認証を有効にしたままでは、平文で続けられる余地が残る。無効にする。

  5. POP3の通信路はTLSで保護し、平文の認証も無効にした。それでも、ある社員のパスワードが漏れた。端末の感染が確認された場合の判断として最も適切なものはどれか。

    1. 正解。端末が感染していれば、通信路を保護しても漏れる。端末側の対策もあわせて必要。

    2. 原因は端末の感染で、通信路の問題ではない。

    3. 回数制限は総当たりへの備え。端末からの漏えいとは別。

    4. APOPは古いハッシュ関数に依存し推奨しにくい。端末の感染という限界の解決にもならない。

  6. ログに、同一アカウントへのログイン失敗が短時間に多数あり、その後に成功が記録されていた。総当たりへの備えとして最も適切なものはどれか。

    1. TLSは通信路を守る対策で、総当たりへの備えは別に要る。

    2. ポートを変えても平文のままなら盗聴でき、総当たりへの備えにもならない。

    3. APOPでもパスワード方式は総当たりの影響を受ける。

    4. 正解。回数制限とログ監視、強いパスワードが総当たりへの備えになる。

頭の中で考える

  1. 公衆無線LANでPOP3を使うと特に危ない理由と、有効な対策を頭の中で説明してみよう。

    答えを開く

    基本の認証はパスワードを平文で送るため、暗号化がないと経路上の盗聴でパスワードやメール内容が漏れる。信頼できない経路ほどリスクが高い。TLSで通信を保護して平文の認証を無効にし、公衆の回線では利用を避ける運用も有効。

    思い浮かんだ要素にチェック

  2. TLSで保護しても残るリスクと、あわせて必要な対策を頭の中で説明してみよう。

    答えを開く

    端末が感染していれば通信路を保護しても漏れる。総当たりや使い回しにはTLSは効かない。端末側の対策に加え、ログイン失敗の回数制限とログの監視、強いパスワードを重ねる。
