#66 ・ 第6章 情報セキュリティ対策技術（2）アクセス制御と認証

ワンタイムパスワードとチャレンジレスポンス 一度きりの合言葉

  1. ワンタイムパスワードは一度使った値を再び使えず、盗聴された値の再利用を防ぐ。
  2. チャレンジレスポンスは、毎回異なるチャレンジと秘密情報から応答を計算する。秘密情報は流れない。
  3. 偽の画面へのその場の入力や、応答の中継は防げない。暗号化や接続先の確認を併用する。

クイズ

  1. 動画で出た問題チャレンジレスポンス方式の説明として、適切なのは？

    1. 毎回異なる値から応答を計算

    2. 秘密情報は通信路に流さない

    3. 同じ値と固定の応答は再利用される

    4. 送られた値を使って計算する

  2. チャレンジレスポンス方式のサーバが、チャレンジに前回の値に1を足した連番を使っていた。この実装の問題として、適切なものはどれか。

    1. チャレンジは予測されにくい乱数を使う。連番のような予測できる値だと、先回りして応答を集められる。

    2. 正解。予測できる値だと、応答を先回りして集められ、あとで再利用されるおそれがある。

    3. チャレンジレスポンス方式では、秘密情報そのものは通信路に流れない。問題はチャレンジの予測しやすさ。

    4. チャレンジが連番かどうかで、応答の計算の負荷が変わるわけではない。問題は予測できること。

  3. 利用者が偽の画面にワンタイムパスワードを入力し、その値がすぐに本物のサイトへ入力されてログインされた。ワンタイムパスワードの性質として、適切な説明はどれか。

    1. ワンタイムパスワードは、使われる前に奪われてその場で使われる悪用までは防げない。実装の不備とは限らない。

    2. チャレンジレスポンス方式でも、本物の応答をその場で転送されると防げない。

    3. 正解。再利用は防げるが、偽の画面にその場で入力させられる悪用は防げない。

    4. 暗号化は通信の盗聴への備え。偽の画面に入力した値は、接続先の確認を併用しないと守れない。

  4. チャレンジレスポンス方式を導入するにあたり、秘密情報の管理方針を決める。適切なものはどれか。

    1. 通信路に流れないことと、サーバ側で守らなくてよいことは別。サーバも同じ計算をするので、両方で守る。

    2. サーバも同じ計算をして照合するので、サーバ側も秘密情報を持つ。サーバ側も守る必要がある。

    3. 送られるのはチャレンジだけ。秘密情報そのものは通信路に流れない。

    4. 正解。秘密情報は利用者側とサーバ側の両方で守り、推測されにくいものにする。

  5. サーバの不具合で、チャレンジが常に同じ値で送られていた。通信を盗聴して過去の応答を記録している者がいた場合に起こりうることとして、適切なものはどれか。

    1. 秘密情報そのものは通信路に流れない。起こりうるのは、同じ応答の再利用。

    2. チャレンジが同じだと応答も同じになり、盗聴した応答が再利用される。

    3. 同じ秘密情報と同じチャレンジからは同じ応答になる。影響がないとは言えない。

    4. 正解。チャレンジが同じだと、盗聴した応答が再利用されうる。

  6. 秘密情報そのものが通信路に流れない、チャレンジレスポンス方式の認証の流れとして、適切なものはどれか。

    1. 秘密情報をそのまま送る流れでは、通信路に秘密情報が流れる。チャレンジレスポンス方式ではない。

    2. 毎回同じ値と固定の応答では、盗聴されると再利用される。チャレンジは毎回異なる値にする。

    3. 正解。秘密情報とチャレンジから応答を計算して返し、サーバも同じ計算で照合する。

    4. チャレンジを返すだけでは、秘密情報を使っておらず、本人確認にならない。

頭の中で考える

  1. ワンタイムパスワードが防げることと防げないことを、頭の中で説明してみよう。

    答えを開く

    一度使った値は再び使えないので、通信の盗聴で得た値の再利用は防げる。一方、偽の画面にその場で入力させられるなど、使われる前に奪われてその場で悪用されるものは防げない。通信の暗号化や接続先の確認を併用する。

    思い浮かんだ要素にチェック

  2. チャレンジレスポンス方式で、チャレンジを毎回変え、予測されにくい乱数にする理由を頭の中で説明してみよう。

    答えを開く

    チャレンジが同じだと応答も同じになり、盗聴された応答が再利用される。連番など予測できる値だと、応答を先回りして集められる。毎回異なる予測されにくい値にすることで、盗聴した応答を次の認証に使えなくする。

午後問題にチャレンジ

リモート接続の認証に関する調査記録（ダミー）
現状: 利用者は固定のパスワードを入力し、そのまま通信路へ送る
通信路上で盗聴された認証データが、再度使われた恐れがある
通信路の暗号化は、一部の旧機器が未対応で適用できない
利用者側の装置は、計算機能と記憶領域を備える
要件: 盗聴された認証データがあっても、再利用で認証されないこと

再利用による不正な認証を防ぐ方法として、適切なのは？

答えを開く

認証のたびに異なる値を送り、秘密情報から計算した応答を返させる

よくある誤答

  • パスワードを、より長く複雑なものに変更する … 固定のままで、盗聴された値は再利用できる
  • 毎回同じ値を送り、応答を返させる … 値が同じだと、盗聴した応答を再利用できる
