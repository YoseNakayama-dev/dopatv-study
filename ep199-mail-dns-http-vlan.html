#99 ・ 第1章 情報セキュリティ及びITの基礎

メール・DNS・HTTP・VLAN ネットワーク技術の基礎

  1. メールはSMTPで送り、宛先のサーバはDNSのMXで探す。受信者はPOP3かIMAPで取り出す。
  2. DNSの結果はTTLの間保持される。HTTPは状態を覚えずCookieが補い、HTTPSはTLSで保護する。
  3. VLANは網を論理的に分けブロードキャストを絞るが、通信は絞れない。制御はVLAN間の中継点で行う。

クイズ

  1. 動画で出た問題電子メールの仕組みとして、適切なものは？

    1. 宛先のサーバはMXで調べる

    2. 取り出しはPOP3かIMAP

    3. PTRは逆引き

    4. SMTPは本人確認が必須ではない

  2. 自社ドメインのメールサーバを移転し、DNSのMXレコードを新サーバに変更した。変更直後、一部の送信元からのメールが数時間のあいだ旧サーバに届き続けた。最も適切な説明はどれか。

    1. POP3やIMAPは受信者がサーバから取り出す段階で、送信元が配送先を探す段階とは別。送信元ごとに配送先が分かれる原因にはならない。

    2. 正解。DNSの結果はTTLの間保持され、変更の反映に時間がかかる。保持が切れた送信元から順に新サーバへ届くようになる。

    3. PTRは逆引きのレコードで、配送先は決めない。宛先のサーバはMXレコードで探す。

    4. MUAからMTAへの送信がSMTPなのは正しいが、宛先ドメインのサーバはMXで探す。端末側の設定が原因ではない。

  3. Webアプリで、利用者がログインした直後は成功するが、次のページへ移動すると再びログイン画面に戻る。サーバは各要求に200を返しており、通信はHTTPSである。最も疑うべき点はどれか。

    1. TLSの役割は通信の暗号化と接続先サーバの確認で、状態を補うのはCookie。HTTPSにしたことが、状態が続かない原因とは言えない。

    2. HTTPは前の要求を覚えないが、Cookieで状態を補える。保持できない設計と言い切るのは言い過ぎ。

    3. 正解。HTTPは状態を覚えず、Cookieで補う。Cookieが付いていなければ、サーバは同じ利用者だと判断できずログイン画面に戻す。

    4. ステータスコードは要求の処理結果を示すもので、同じ利用者と判断できているかとは別。200だから本文の誤りだけが原因とは言えない。

  4. 拠点のネットワークでブロードキャストが多く通信が重いので、スイッチでVLANを分割する計画を立てた。分割に期待できる効果と限界として適切なものはどれか。

    1. VLAN間の通信はルータやL3スイッチが中継する。制御するなら、その中継点で行う。

    2. VLANは論理的に網を分けるもので、物理的に分けたのと同じではない。VLAN間は中継されるので、設定がなければ遮断される保証もない。

    3. 分けただけでは通信は絞れない。VLAN間の通信を絞るには、中継点での制御が要る。

    4. 正解。VLANでブロードキャストの届く範囲を絞れる。一方、分けただけでは通信は絞れず、VLAN間を中継する場所で制御する。

  5. ログに不審な接続元のIPアドレスが記録されている。このIPアドレスに対応するホスト名を調べたい。使う方法として最も適切なものはどれか。

    1. 正解。IPアドレスから名前を引くのが逆引きで、PTRレコードを使う。

    2. 正引きは名前からIPアドレスを引く方向で、IPアドレスから名前を調べる用途には向かない。

    3. MXは宛先ドメインのメールサーバを示すレコードで、IPアドレスの名前を調べるものではない。

    4. SMTPはメールを送る方向のプロトコルで、IPアドレスから名前を引く手段ではない。名前の問い合わせはDNSで行う。

  6. 社内の入力フォームをHTTPからHTTPSに切り替えた。HTTPSによって得られるものと、変わらないものの組合せとして適切なのはどれか。

    1. TLSは暗号化と接続先の確認を担う。HTTPが状態を覚えない点はHTTPSでも変わらず、Cookieなどで補う必要がある。

    2. 経路上の盗聴は防げても、サーバ側の処理に問題があれば、その影響はHTTPSでも残る。心配がなくなるとは言えない。

    3. 正解。HTTPSはTLSで通信を暗号化し、接続先サーバを確認する。HTTPの性質である、状態を覚えない点は変わらない。

    4. HTTPSは暗号化に加えて、接続先サーバの確認も行う。確認が行われないという説明は誤り。

頭の中で考える

  1. メールが送信者から受信者に届くまでの流れを、使うプロトコルとDNSの役割を入れて頭の中で説明してみよう。

    答えを開く

    送信側はSMTPでメールサーバへ渡し、宛先ドメインのメールサーバはDNSのMXレコードで探す。サーバ間もSMTPで中継して届け、受信者はPOP3かIMAPで取り出す。SMTPは送る方向のプロトコルで、取り出しには使わない。

    思い浮かんだ要素にチェック

  2. HTTPは前の要求を覚えないのに、ログイン状態が保てるのはなぜか。HTTPSが担う役割と区別して頭の中で説明してみよう。

    答えを開く

    HTTPは状態を覚えないが、Cookieを要求に付けて状態を補う。HTTPSはTLSで通信を暗号化し、接続先サーバを確認するもので、状態を覚えさせる役割ではない。

午後問題にチャレンジ

部門ネットワークの構成記録（ダミー）
営業はVLAN10、経理はVLAN20。スイッチは共通
営業PCから、経理サーバへ通信が届いてしまう
VLAN間は、L3スイッチが中継。制限の設定はない
要件: 営業から経理への通信を、必要最小限にしたい

L3スイッチで行う対応として、適切なのは？

答えを開く

L3スイッチで、VLAN間の通信を許可する範囲を絞る

よくある誤答

  • VLANを一つにまとめる … 要件は通信を絞ることで、まとめると、部門間の通信を区別できなくなる
  • 営業と経理を、別のスイッチに移す … スイッチを分けても、L3スイッチが中継する限り、通信は届く
