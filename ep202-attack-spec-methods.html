#102 ・ 第2章 情報セキュリティにおける脅威

攻撃の記述仕様と主な手法 STIX・TAXII・CVE・攻撃手法の整理

  1. STIXは脅威情報の形式、TAXIIは交換の手順。CVE・CWE・CAPECはそれぞれ指すものが違う。
  2. 攻撃手法は、人・待ち受け・仕組み・組織と、狙う場所で整理し、対策に対応づける。
  3. 形式がそろっても、受け取った情報の質は保証されない。古い・誤りがありうるので、自組織で確認する。

クイズ

  1. 動画で出た問題攻撃の記述仕様と手法の説明として、適切なものは？

    1. 交換の手順はTAXII

    2. 攻撃パターンの一覧

    3. 標的が使うサイトを改ざん

    4. CVEは脆弱性の識別番号

  2. 他組織からSTIX形式の脅威情報を受け取り、内容を確認せずに自動で遮断ルールへ反映している。過去の情報が混じり、業務で使う通信が遮断された。再発防止として最も適切なものはどれか。

    1. 正解。受け取った情報は古い・誤りがありうる。自組織で確認してから使う。

    2. 形式が同じでも、情報の質は保証されない。形式の検証を強めても、内容の古さや誤りは見つからない。

    3. TAXIIは交換の手順で、情報の信頼度を高めるものではない。手順が標準でも内容の質は保証されない。

    4. CVEは個々の脆弱性の識別番号。番号が付いていることは、情報が新しいことや正しいことの根拠にならない。

  3. 標的とされた企業の社員が日常的に閲覧する業界団体のWebサイトが改ざんされ、閲覧した社員の端末で不審なプログラムが動いた。社員にメールは送られていない。この手法の呼称として最も適切なものはどれか。

    1. フィッシングは人をだます手口。今回は偽サイトへの誘導ではなく、実在のサイトが改ざんされている点が違う。

    2. DoSは過負荷にして止める攻撃。サイトを止めるのではなく、改ざんして閲覧者の端末で動かしている点が違う。

    3. 正解。標的が使うサイトを改ざんし、標的が自分から訪れるのを待つのが水飲み場攻撃。

    4. 管理者アカウントを破る行為は改ざんの手段になりうるが、標的が訪れるのを待つ点を表していない。呼称としては水飲み場攻撃が当たる。

  4. 複数の製品で、入力値の検証が不十分という同じ種類の弱点が見つかった。個々の脆弱性ではなく、弱点の型として分類して傾向を分析したい。参照する体系はどれか。

    1. CVEは個々の脆弱性を指す番号で、型ごとの分類ではない。個別の脆弱性の追跡に向く。

    2. CAPECは攻撃パターンの一覧。弱点の型ではなく、攻撃の側の整理である。

    3. STIXは脅威情報を表す形式で、弱点の型を定める体系ではない。

    4. 正解。CWEはソフトウェアの弱点の型の一覧で、同じ種類の弱点をまとめて扱える。

  5. 取引先を装ったメールで従業員をだまし、IDとパスワードを入力させる手口の被害が増えている。特定の組織に限らず広く送られている。手法を狙う場所で整理して対策の軸を決めるとき、最も適切なものはどれか。

    1. 仕組みを狙う手法は脆弱性の悪用・認証の突破・DoS。今回の手口は従業員をだますもので、狙う場所が違う。

    2. 正解。だます相手は人。人には教育が基本。ほかの層の対策を併用しないという意味ではない。

    3. 待ち受けは水飲み場攻撃のように、標的が使うサイトを改ざんして訪れるのを待つ手口。メールで入力させる手口とは違う。

    4. DoSは過負荷で止める攻撃で、今回の被害（入力させて盗む）とは原因が違う。原因に合わない対策は効かない。

  6. 特定の脆弱性は使われていないが、大量の要求でサーバが応答しなくなった。攻撃手法の整理上の扱いとして最も適切なものはどれか。

    1. 仕組みを狙う手法には、脆弱性の悪用や認証の突破のほか、DoSも含まれる。脆弱性を使わなくても含まれる。人をだます手口でもない。

    2. 水飲み場攻撃は、標的が使うサイトを改ざんして訪れるのを待つ手口。大量の要求で止める攻撃とは違う。

    3. 組織を狙う手法として挙げているのは標的型攻撃とサプライチェーン攻撃。大量の要求で止めるDoSは、仕組みを狙う手法に整理する。

    4. 正解。過負荷にして止めるDoSも、仕組みを狙う手法に入れて整理する。

  1. CVE・CWE・CAPECが、それぞれ何を指すかを、頭の中で一文ずつ説明してみよう。

    答えを開く

    CVEは個々の脆弱性に付く識別番号。CWEはソフトウェアの弱点の型の一覧。CAPECは攻撃パターンの一覧。いずれも別のものを指す。

    思い浮かんだ要素にチェック

  2. 攻撃手法を「狙う場所」で整理すると、対策選びにどう役立つか。また、整理だけでは足りない点は何か。頭の中で説明してみよう。

    答えを開く

    人には教育、仕組みには修正と設定のように、手法を狙う場所に対応づけて対策を選べる。限界として、受け取った攻撃情報は古い・誤りがありうるので、自組織で確認してから使う。形式が同じでも質は保証されない。

午後問題にチャレンジ

攻撃情報の受領記録（ダミー）
他組織から、攻撃情報を毎日受け取っている
受け取りは、共有サーバからの自動取得で済んでいる
内容は文章のファイルで、担当者が手で転記する
要件: 受けた情報を、システムが自動で照合したい

このあとの対応として、適切なのは？

答えを開く

機械が読める共通の形式で表す（代表がSTIX）

よくある誤答

  • TAXIIを導入して交換を自動化する … 取得はすでに自動化済みで、問題は内容の形式にある
  • 各情報にCVE番号を付ける … CVEは脆弱性の識別番号で、攻撃情報全体を表す形式ではない
