#57 ・ 第5章 情報セキュリティ対策技術（1）予防・検知・防御

WAFの種類と主な機能 Webアプリの手前で中身を見る門番

  1. WAFはWebアプリの手前で、HTTP/HTTPSのリクエストの中身を検査し、脆弱性を狙う通信を遮断・検知する。
  2. 一般的なFWはIPアドレスとポート番号が中心で、許可した通信の中身は見ない。見る層が違う。
  3. 形態はネットワーク型・ホスト型・クラウド型など。暗号化通信は復号できる位置で検査する必要がある。

クイズ

  1. 動画で出た問題WAFの説明として、適切なのは？

    1. HTTP通信の内容を検査して遮断

    2. それは、パケットフィルタ型のFW

    3. それは、ソースコードの解析

    4. それは、認証

  2. FWでHTTPSのポートを許可している。その通信に載ったWebアプリの脆弱性を狙うリクエストがFWを通過した。FWが止められなかった理由として最も適切なものはどれか。

    1. FWは暗号化の有無にかかわらず、許可した通信の中身は見ないのが普通。

    2. 正解。FWは主にIPアドレスとポート番号で判断し、許可した通信の中身は見ない。WAFとは見る層が違う。

    3. FWはもともと通信の中身を見ないので、設定を直しても同じ検査はできない。

    4. パケットフィルタ型は主にIPアドレスとポート番号で判断する方式で、リクエストの内容は検査しない。

  3. Webサーバが多数あり、自社の設備に専用機器を置ける。事業者への通信の中継は規程で認められておらず、サーバごとの導入・管理は避けたい。適切な形態はどれか。

    1. ホスト型はサーバごとに導入と管理が要る。避けたい条件に合わない。

    2. クラウド型は事業者のサービスに通信を中継させる。中継が認められていない条件に合わない。

    3. 正解。ネットワーク型は専用機器をWebサーバの手前に置き、複数のサーバをまとめて守りやすい。

    4. FWは主にIPアドレスとポート番号で判断し、中身は見ない。設定を強化しても中身の検査にはならない。

  4. 入力欄に「数字6桁だけ」を受け付ける仕様がある。この形から外れた入力を止めたい。検査方式と特徴として最も適切なものはどれか。

    1. シグネチャ型は既知の攻撃パターンとの一致を調べる方式。入力の形を定義する方式ではない。

    2. 入力の形を定義するのはホワイトリスト型で、設定に手間がかかる。ブラックリスト型は既知のパターンを調べる方式。

    3. 検知のみは動作の選択肢の一つで、検査方式ではない。外れた入力を止めたい条件にも合わない。

    4. 正解。正常な入力の形を定義し、外れたら止めるのがホワイトリスト型。設定に手間がかかる。

  5. WAFをHTTPS通信が暗号化されたまま通る位置に置き、復号の仕組みは用意しなかった。この構成に対する評価として最も適切なものはどれか。

    1. 暗号化通信は、復号できる位置で検査しないと中身が見えない。

    2. 正解。暗号化通信は、復号できる位置で検査しないと中身が見えない。

    3. HTTPSの通信もWAFの対象になる。FWは中身を見ないので、追加しても同じ検査にはならない。

    4. IPアドレスだけでは通信の中身は分からない。中身の検査には復号が要る。

  6. WAFを導入した直後に、正常な入力が誤検知で遮断される事態を避けたい。最初の動作設定として最も適切なものはどれか。

    1. 最初から遮断すると、誤検知で正常な通信が止まる事態を避けられない。

    2. 通過のみでは誤検知の確認もできず、検査の意味がなくなる。

    3. 正解。最初は検知のみで動かし、誤検知を確認する運用がある。

    4. ホワイトリスト型は設定に手間がかかる。導入直後から遮断してよい根拠にはならない。

頭の中で考える

  1. FWがあるのにWebアプリを狙う攻撃が届いた。FWとWAFの役割の違いを、頭の中で説明してみよう。

    答えを開く

    一般的なFWは主にIPアドレスとポート番号で判断し、許可した通信の中身は見ない。WAFは利用者とWebアプリの間でHTTP/HTTPSのリクエストの中身まで検査するので、見る層が違う。

    思い浮かんだ要素にチェック

  2. WAFの導入形態を選ぶとき、何を基準にするか。条件の例を挙げて、頭の中で説明してみよう。

    答えを開く

    構成、性能、運用体制、暗号化通信の扱いで選ぶ。例えば、専用機器を置けるならネットワーク型、サーバごとにソフトを入れられるならホスト型、機器を置けず事業者への中継が許されるならクラウド型。

WAFの導入方式として、適切なのは？

答えを開く

DNSの設定で事業者のサービスに中継させ、そこで検査して遮断する

よくある誤答

  • Webサーバにソフトを導入し、サーバ上で検査して遮断する … 契約で、サーバへの追加が認められていない
  • 自社の設備に専用機器を置き、手前で検査して遮断する … 自社には、置く場所も設備もない
