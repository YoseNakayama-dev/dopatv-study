#87 ・ 第9章 情報セキュリティに関する法制度

個人情報保護法とマイナンバー法 扱いの線引き

  1. 個人情報は利用目的の範囲で扱う。超えるなら原則、本人の同意が要る。第三者提供も原則、本人の同意が要る。
  2. 委託先への提供は第三者提供に当たらないが、委託元の責任は残り、委託先を監督する。安全管理措置も行う。
  3. マイナンバーは、本人が同意しても法定事務以外には使えない。取得時は本人確認をし、不要になれば廃棄・削除する。

用語カード

クイズ

  1. 動画で出た問題要配慮個人情報に当たるものは、どれ？

    1. 購入履歴は要配慮個人情報ではない

    2. 部署や役職は要配慮個人情報ではない

    3. 病歴は要配慮個人情報

    4. メールアドレスは通常の個人情報

  2. 通販事業者が、会員の氏名と住所を、発送業務の委託先に渡す。本人の同意は取っていない。扱いとして適切なのはどれか。

    1. 委託先への提供は、第三者提供に当たらない。

    2. 正解。委託は第三者提供に当たらない。ただし委託先を選び、安全管理が行われるよう監督する必要がある。

    3. 委託しても、委託元の責任は残る。

    4. 委託先を選び、監督する必要がある。

  3. 懸賞の応募で取得した氏名とメールアドレスを、利用目的に含めていなかった新商品のメール広告に使いたい。扱いとして適切なのはどれか。

    1. 社内であっても、個人情報は利用目的の範囲を超えて使えない。超えるなら原則、本人の同意が要る。

    2. 通知か公表は、利用目的を特定したときに行うもの。範囲を超えるなら原則、本人の同意が要る。

    3. メールアドレスは通常の個人情報で、要配慮個人情報ではない。

    4. 正解。個人情報は利用目的の範囲を超えて使えない。超えるなら、原則、本人の同意が要る。

  4. 源泉徴収のために取得した従業員のマイナンバーが、退職後も人事システムに残っている。法定事務で使う予定はなく、保管を続ける必要もない。対応として適切なのはどれか。

    1. 正解。不要になった番号は保管し続けず、廃棄や削除をして、漏えいの危険を減らす。

    2. 本人が同意しても、法定事務以外には利用できない。不要になれば廃棄・削除する。

    3. 管理番号への利用は法定事務ではなく、同意があっても使えない。

    4. 安全管理措置を行っても、不要になった番号は保管し続けず、廃棄・削除する。

  5. 委託先の誤操作により、委託元が保有する個人データが漏えいした。委託元の対応として適切なのはどれか。

    1. 委託しても、委託元の責任は残る。

    2. 報告と通知が必要になるのは、一定の場合。

    3. 正解。委託元の責任は残る。漏えいが起きたとき、一定の場合に報告と通知が必要になる。

    4. 利用目的の通知・公表は、漏えいの報告・通知とは別。漏えいは一定の場合に報告と通知が必要になる。

  6. 採用応募者から、持病の病歴が書かれた書類を受け取って取得したい。扱いとして適切なのはどれか。

    1. 病歴は要配慮個人情報で、取得は原則、本人の同意が要る。

    2. 正解。病歴は要配慮個人情報に当たり、取得は原則として本人の同意が要る。

    3. 要配慮個人情報の取得は原則、本人の同意が要る。「例外なく」とは言えない。

    4. 病歴は要配慮個人情報で、個人情報の一種として扱われる。

頭の中で考える

  1. 「本人が同意すれば、何にでも使える」と言えるか。個人情報とマイナンバーで違いを、頭の中で説明してみよう。

    答えを開く

    個人情報は、利用目的の範囲を超えるなら原則、本人の同意が要るが、同意を得て使える場合がある。マイナンバーは、本人が同意しても、法律で定めた事務以外には使えない。だからマイナンバーは特に厳しい。

    思い浮かんだ要素にチェック

  2. 名簿の発送を外部の業者に任せるとき、委託元が押さえる点を、頭の中で説明してみよう。

    答えを開く

    委託先への提供は第三者提供に当たらず、本人の同意は要らない。ただし委託元の責任は残るので、委託先を選び、安全管理が行われるよう監督する。自社でも安全管理措置を行い、漏えいが起きたら、一定の場合に報告と通知をする。

午後問題にチャレンジ

マイナンバーの取扱いに関する調査記録（ダミー）
現状: 従業員のマイナンバーを、源泉徴収のために取得した
番号は、人事システムに、全従業員分が登録されている
人事部門から、社内の管理番号にも使いたいと依頼があった
要件: 法令に沿った、番号の扱いを判断したい

この依頼への対応として、適切なのは？

答えを開く

法律で定めた事務ではないので、管理番号には使わない

よくある誤答

  • 社内の部署からの依頼なので、利用を認める … 社内であっても、法律で定めた事務以外には使えない
  • 従業員本人の同意を得て、管理番号に使う … 本人が同意しても、定めた事務以外には使えない
